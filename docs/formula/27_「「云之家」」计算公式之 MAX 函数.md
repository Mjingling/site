# 「「云之家」」计算公式之 MAX 函数

## 一、函数作用

`MAX` 函数用来**找出最大值**，简单来说就是：
- 从多个数字中找出最大的那个
- 可以比较多个单独的数字
- 可以从明细表字段中找出最大值
- 可以从数组中找出最大值

常用于找最高分、最高销售额、最大库存等场景。

---

## 二、语法格式

```
MAX(参数1, 参数2, ...参数N)
```

或

```
MAX(明细表.字段)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 参数1, 参数2... | 要比较的数字，可以是：<br>• 直接写数字<br>• 数字控件<br>• 金额控件<br>• 运算控件<br>• 明细表字段<br>• 数组 | ✅ 至少1个 | MAX(80, 90, 70) |

### 返回值

- **正常情况**：返回所有参数中的最大值
- **特殊情况**：如果所有参数都为空，返回 **null**

---

## 三、实用示例

### 示例 1：比较固定数字

```js
MAX(80, 90, 70)              // 返回：90
MAX(100, 200, 150, 180)      // 返回：200
MAX(5, 3, 8, 1, 9, 2)        // 返回：9
MAX(-5, -3, -8)              // 返回：-3（负数中最大的）
```

### 示例 2：找出最高成绩

假设有【语文成绩】【数学成绩】【英语成绩】三个控件：

```js
MAX(语文成绩, 数学成绩, 英语成绩)
```

### 示例 3：明细表中找最大值

假设有【销售记录明细】表：

| 销售员 | 销售额 |
|--------|--------|
| 张三 | 5000 |
| 李四 | 8000 |
| 王五 | 6000 |
| 赵六 | 7500 |

```js
// 找出最高销售额
MAX(销售记录明细.销售额)  // 返回：8000
```

### 示例 4：数组中找最大值

```js
MAX([100, 200, 150, 180])    // 返回：200
MAX([3.5, 2.8, 4.2, 3.9])    // 返回：4.2
```

### 示例 5：混合使用

可以混合数字、控件、明细表：

```js
// 比较本月目标和实际销售额，取较大值
MAX(月度目标, 实际销售额)

// 比较固定值和控件值
MAX(100, 商品价格)  // 确保价格不低于100
```

## 五、常见问题

### 如果某个参数为空怎么办？

空值会被**忽略**，不参与比较。

```js
// 假设【数学成绩】为空
MAX(语文成绩, 数学成绩, 英语成绩)
// 实际只比较：语文成绩 和 英语成绩
```

**示例：**

| 语文 | 数学 | 英语 | 最高分 |
|------|------|------|-------|
| 80 | 90 | 70 | 90（三门中最高） |
| 80 | 空 | 70 | 80（只比较两门） |

### 所有参数都为空会怎样？

返回 **null**。

```js
MAX("", "", "")   // 返回：0
MAX(空明细表.数量)  // 返回：null
```

### 能混合数字和控件吗？

可以！

```js
MAX(100, 数学成绩, 英语成绩)  // ✅ 可以
MAX(0, 销售额)                // 确保结果不为负数
```

### 如何找出最大值对应的记录？

MAX 只返回数值，不返回对应的记录。如果需要找到对应的销售员，需要配合其他逻辑：

```js
// 先找出最大值
MAX(销售明细.销售额)  // 假设返回 8000

// 然后在明细表中筛选出销售额=8000的记录
```

### 负数比较怎么处理？

负数也正常比较，值越大（越接近0）越大：

```js
MAX(-5, -3, -8)   // 返回：-3
MAX(-10, 5, -2)   // 返回：5
MAX(0, -5, 3)     // 返回：3
```

## 六、搭配使用技巧

### 技巧 1：判断是否达到目标

```js
// 判断是否达标（最高分≥85分）
IF(MAX(语文, 数学, 英语) >= 85, "优秀", "良好")
```

### 技巧 2：计算超出目标的金额

```js
// 超出目标的金额
MAX(实际销售额 - 销售目标, 0)
// 如果实际大于目标，显示差值；否则显示0
```

### 技巧 3：确保最小值

```js
// 确保价格不低于成本
MAX(成本价格, 市场价格)

// 确保库存预警值至少为10
MAX(10, 计算的预警值)
```

### 技巧 4：对比多个时间段

```js
// 找出季度最高销售额
MAX(一月销售额, 二月销售额, 三月销售额)

// 计算增长率（用最高月份对比）
(MAX(一月, 二月, 三月) - MIN(一月, 二月, 三月)) / MIN(一月, 二月, 三月) * 100
```

### 技巧 5：结合 ROUND 格式化

```js
// 找出最高价格并保留2位小数
ROUND(MAX(报价明细.单价), 2)
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **MAX** | 找最大值 | MAX(10, 20, 15) | 20 |
| **MIN** | 找最小值 | MIN(10, 20, 15) | 10 |
| **AVERAGE** | 求平均值 | AVERAGE(10, 20, 15) | 15 |
| **SUM** | 求和 | SUM(10, 20, 15) | 45 |

**详细对比**：

假设销售明细表有以下数据：

| 销售员 | 销售额 |
|--------|--------|
| 张三 | 5000 |
| 李四 | 8000 |
| 王五 | 6000 |

```js
MAX(销售明细.销售额)       // 返回：8000（最大值）
MIN(销售明细.销售额)       // 返回：5000（最小值）
AVERAGE(销售明细.销售额)   // 返回：6333.33（平均值）
SUM(销售明细.销售额)       // 返回：19000（总和）
COUNT(销售明细.销售额)     // 返回：3（记录数）
```

**记忆方法**：
- MAX = 最大值（Maximum）
- MIN = 最小值（Minimum）
- AVERAGE = 平均值（Average）
- SUM = 总和（Sum）

## 八、MAX 和 MIN 的组合使用

### 计算极差（最大值 - 最小值）

```js
// 计算成绩波动范围
MAX(语文, 数学, 英语) - MIN(语文, 数学, 英语)
```

**示例：**

| 语文 | 数学 | 英语 | 极差 |
|------|------|------|------|
| 85 | 92 | 78 | 14（92-78） |
| 90 | 88 | 94 | 6（94-88） |

### 判断数据分布

```js
// 如果极差小于10，说明成绩稳定
IF((MAX(语文, 数学, 英语) - MIN(语文, 数学, 英语)) < 10, "稳定", "波动大")
```
