# 「「云之家」」计算公式之 COUNT 函数

## 一、函数作用

`COUNT` 函数用来**统计数量**，根据参数类型不同有不同的作用：
- 如果是明细表字段：统计有多少行数据
- 如果是数组：返回数组中元素的个数
- 如果是文本：返回文本的字符数（长度）
- 如果是数字：返回数字的位数

常用于统计明细表行数、数组长度等场景。

---

## 二、语法格式

```
COUNT(参数)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 参数 | 可以是：<br>• 明细表字段<br>• 数组<br>• 文本<br>• 数字 | ✅ 必填 | COUNT(订单明细.商品名称) |

### 返回值

- **明细表字段**：返回明细表的行数
- **数组**：返回数组元素个数
- **文本**：返回字符串长度
- **数字**：返回数字位数
- **空值**：返回 0

---

## 三、实用示例

### 示例 1：统计明细表行数

假设有【订单明细】表：

| 商品名称 | 数量 | 单价 |
|---------|------|------|
| 苹果 | 10 | 5 |
| 香蕉 | 20 | 3 |
| 橙子 | 15 | 4 |

```js
COUNT(订单明细.商品名称)  // 返回：3（共3行数据）
COUNT(订单明细.数量)      // 返回：3（共3行数据）
```

### 示例 2：统计数组长度

```js
COUNT([1, 2, 3, 4, 5])              // 返回：5
COUNT(["苹果", "香蕉", "橙子"])      // 返回：3
COUNT([])                           // 返回：0（空数组）
```

### 示例 3：计算文本长度

```js
COUNT("云之家")          // 返回：3
COUNT("Hello")          // 返回：5
COUNT("不包含")          // 返回：3
COUNT("不包含aa")        // 返回：5
COUNT("")               // 返回：0
```

### 示例 4：计算数字位数

```js
COUNT(2023)    // 返回：4
COUNT(12345)   // 返回：5
COUNT(0)       // 返回：1
```

### 示例 5：统计明细表数据

假设有【员工明细】表：

| 员工姓名 | 部门 | 工资 |
|---------|------|------|
| 张三 | 技术部 | 10000 |
| 李四 | 销售部 | 8000 |
| 王五 | 技术部 | 9000 |
| 赵六 | 人事部 | 7000 |

```js
// 统计员工总数
COUNT(员工明细.员工姓名)  // 返回：4
```

## 五、常见问题

### 如果参数为空会怎样？

返回 **0**。

```js
COUNT("")           // 返回：0
COUNT([])           // 返回：0
COUNT(空明细表)      // 返回：0
```

### COUNT 和 LEN 有什么区别？

COUNT 和 LEN 在处理文本时功能相同，都是计算字符长度：

```js
COUNT("云之家")   // 返回：3
LEN("云之家")     // 返回：3
```

但 COUNT 功能更多，还可以统计明细表行数和数组长度：

```js
COUNT(订单明细.商品名称)  // 统计行数
COUNT([1, 2, 3])         // 统计数组长度
```

**建议**：
- 统计明细表行数或数组长度时，用 **COUNT**
- 纯粹计算文本长度时，用 **LEN** 更语义化

### 如何统计明细表中非空行数？

可以结合 COUNTIF 函数：

```js
// 统计商品名称不为空的行数
COUNTIF(订单明细.控件自身, NOT_NULL(订单明细.商品名称))
```

### 中英文字符计算有区别吗？

没有区别，每个字符都算一个长度：

```js
COUNT("abc")       // 返回：3
COUNT("中文字")     // 返回：3
COUNT("a中b文c")    // 返回：5
```

## 六、搭配使用技巧

### 技巧 1：判断明细表是否为空

```js
// 判断是否有明细数据
IF(COUNT(订单明细.商品名称) > 0, "有商品", "无商品")
```

### 技巧 2：计算平均值

```js
// 平均单价 = 总金额 / 商品种类数
SUM(订单明细.金额) / COUNT(订单明细.商品名称)
```

### 技巧 3：验证文本长度

```js
// 判断密码长度是否符合要求
IF(COUNT(密码) >= 6, "符合", "密码至少6位")

// 判断用户名长度
IF(COUNT(用户名) >= 3 && COUNT(用户名) <= 20, "合格", "用户名需3-20个字符")
```

### 技巧 4：统计商品种类并显示

```js
// 显示：共3种商品
CONCATENATE("共", COUNT(订单明细.商品名称), "种商品")
```

### 技巧 5：计算比例

```js
// 完成率 = 已完成数 / 总任务数 * 100
ROUND(已完成数 / COUNT(任务列表.任务名称) * 100, 2)
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **COUNT** | 统计数量/长度 | COUNT(订单明细.商品名称) | 3（行数） |
| **COUNTIF** | 条件统计 | COUNTIF(订单明细.控件自身, 订单明细.数量 > 10) | 2（符合条件的行数） |
| **LEN** | 计算文本长度 | LEN("云之家") | 3 |
| **SUM** | 求和 | SUM(订单明细.数量) | 45（总和） |

**详细对比**：

```js
// 假设订单明细有3行数据，数量分别是 10, 20, 15

COUNT(订单明细.商品名称)    // 返回：3（统计行数）
SUM(订单明细.数量)          // 返回：45（求和）
AVERAGE(订单明细.数量)      // 返回：15（平均值）

// 统计数量大于10的行数
COUNTIF(订单明细.控件自身, 订单明细.数量 > 10)  // 返回：2
```

**记忆方法**：
- COUNT = 数量（Count）
- COUNTIF = 条件数量（Count If）
- SUM = 总和（Sum）
- LEN = 长度（Length）
