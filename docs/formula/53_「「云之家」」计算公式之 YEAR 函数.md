# 「「云之家」」计算公式之 YEAR 函数

## 一、函数作用

`YEAR` 函数用来**从日期中提取年份**,简单来说就是:
- 从完整日期中提取出年份部分(四位数)
- 可以处理日期控件、日期字符串等
- 返回值是纯数字,如 2023、2024

常用于年度统计、年份分组、计算年龄等场景。

---

## 二、语法格式

```
YEAR(日期)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期 | 要提取年份的日期,可以是日期控件、日期字符串、时间戳 | ✅ 必填 | YEAR("2023-10-15") |

### 返回值

- **正常情况**:返回四位数的年份(如 2023)
- **特殊情况**:如果日期无效,返回**空**或错误

---

## 三、实用示例

### 示例 1:基本用法

```js
YEAR("2023-10-15")        // 返回:2023
YEAR("2024-01-01")        // 返回:2024
YEAR("2020-12-31")        // 返回:2020
YEAR(NOW())               // 返回:当前年份(如 2023)
```

### 示例 2:提取订单年份

假设有【订单表】,提取订单创建的年份:

```js
YEAR(订单创建时间)
```

### 示例 3:计算年龄

结合今年年份计算年龄:

```js
YEAR(TODAY()) - YEAR(出生日期)
```

### 示例 4:判断是否为今年

```js
IF(YEAR(日期) == YEAR(TODAY()), "今年", "往年")
```

### 示例 5:生成年度编号

```js
CONCATENATE(YEAR(TODAY()), "-", 序号)
```

**示例:**

```js
CONCATENATE(YEAR(TODAY()), "-", "001")  // 返回:"2023-001"
CONCATENATE(YEAR(订单日期), "-ORD-", 订单序号)  // 返回:"2023-ORD-12345"
```

## 四、实际业务场景

### 场景 1:年度销售统计

按年份统计销售数据:

```js
// 【销售年份】的计算公式
YEAR(销售日期)
```

然后可以按"销售年份"字段分组统计。

### 场景 2:员工工龄计算

计算员工工作年限:

```js
// 【工龄(年)】的计算公式
YEAR(TODAY()) - YEAR(入职日期)
```

### 场景 3:合同年度分类

按合同签订年份分类管理:

```js
// 【合同年度】的计算公式
CONCATENATE(YEAR(签订日期), "年度合同")
```

### 场景 4:证件年份提醒

检查证件是否即将过期(按年份判断):

```js
// 【证件状态】的计算公式
IF(YEAR(有效期) < YEAR(TODAY()), "已过期",
   IF(YEAR(有效期) == YEAR(TODAY()), "今年到期", "有效"))
```

## 五、常见问题

### ❓ 如果日期为空会怎样?

如果日期字段没有填写,函数返回**空**:

```js
YEAR("")        // 返回:空
YEAR(空控件)    // 返回:空
```

### ❓ 返回值是什么格式?

返回值是纯数字(四位整数):

```js
YEAR("2023-10-15")  // 返回:2023(数字类型,不是文本"2023")
```

可以直接用于数学运算:

```js
YEAR(TODAY()) - YEAR(出生日期)  // 可以直接相减
```

### ❓ 能处理两位年份吗?

建议使用四位年份,两位年份可能有歧义:

```js
YEAR("23-10-15")    // 可能识别为 2023 或 0023,取决于系统
YEAR("2023-10-15")  // ✅ 推荐:明确的四位年份
```

### ❓ 时间部分会影响结果吗?

不会!YEAR 只提取年份,忽略时间部分:

```js
YEAR("2023-10-15 00:00:00")  // 返回:2023
YEAR("2023-10-15 23:59:59")  // 返回:2023(时间不影响年份)
```

### ❓ 如何获取今年?

使用 TODAY() 或 NOW():

```js
YEAR(TODAY())  // 返回:当前年份(如 2023)
YEAR(NOW())    // 返回:当前年份(如 2023)
```

## 六、搭配使用技巧

### 技巧 1:结合 IF 判断年份范围

```js
// 判断是否为近3年的数据
IF(YEAR(TODAY()) - YEAR(日期) <= 3, "近期数据", "历史数据")

// 判断是否为指定年份
IF(YEAR(日期) == 2023, "2023年数据", "其他年份")
```

### 技巧 2:结合 CONCATENATE 生成编号

```js
// 生成年度编号
CONCATENATE(YEAR(TODAY()), "-", 部门代码, "-", 序号)
// 返回:"2023-IT-001"

// 生成财年编号
CONCATENATE("FY", YEAR(日期))
// 返回:"FY2023"
```

### 技巧 3:计算跨年天数

```js
// 计算从某日期到今年年底还有多少天
DAYS(CONCATENATE(YEAR(TODAY()), "-12-31"), TODAY())
```

### 技巧 4:按年份分组标签

```js
// 生成年份标签
CASE(
  YEAR(日期) == YEAR(TODAY()), "今年",
  YEAR(日期) == YEAR(TODAY()) - 1, "去年",
  YEAR(日期) == YEAR(TODAY()) - 2, "前年",
  "更早"
)
```

### 技巧 5:计算精确年龄(考虑月日)

```js
// 粗略计算年龄(只看年份)
YEAR(TODAY()) - YEAR(出生日期)

// 更精确的年龄计算(结合月日)
IF(MONTH(TODAY()) < MONTH(出生日期) ||
   (MONTH(TODAY()) == MONTH(出生日期) && DAY(TODAY()) < DAY(出生日期)),
   YEAR(TODAY()) - YEAR(出生日期) - 1,
   YEAR(TODAY()) - YEAR(出生日期))
```

## 七、相关函数对比

| 函数 | 作用 | 返回值示例 | 使用场景 |
|------|------|-----------|---------|
| **YEAR(日期)** | 提取年份 | 2023 | 年度统计、计算年龄 |
| **MONTH(日期)** | 提取月份 | 10(1-12) | 月度统计、季度判断 |
| **DAY(日期)** | 提取日期(几号) | 15(1-31) | 按日统计、工资发放日 |
| **QUARTER(日期)** | 提取季度 | 4(1-4) | 季度统计、季报 |
| **WEEKDAY(日期)** | 提取星期几 | 0(0-6) | 判断工作日/周末 |
| **DATEFORMAT(日期)** | 格式化日期 | "2023年10月" | 自定义显示格式 |

**详细对比:**

```js
// 假设日期为:2023-10-15 14:30:25

YEAR("2023-10-15")              // 返回:2023
MONTH("2023-10-15")             // 返回:10
DAY("2023-10-15")               // 返回:15
QUARTER("2023-10-15")           // 返回:4(第4季度)
WEEKDAY("2023-10-15")           // 返回:0(周日)
DATEFORMAT("2023-10-15", "YYYY年MM月")  // 返回:"2023年10月"

// 组合使用
CONCATENATE(YEAR("2023-10-15"), "年", MONTH("2023-10-15"), "月")
// 返回:"2023年10月"
```

## 八、注意事项

### ⚠️ 返回值是数字类型

YEAR 返回的是数字,不是文本:

```js
YEAR("2023-10-15")  // 返回:2023(数字)

// ✅ 可以直接用于数学运算
YEAR(TODAY()) - YEAR("1990-01-01")  // 33

// ⚠️ 如果需要文本,使用 TEXT 或 CONCATENATE
TEXT(YEAR("2023-10-15"))  // 返回:"2023"(文本)
CONCATENATE(YEAR("2023-10-15"), "年")  // 返回:"2023年"
```

### ⚠️ 日期格式要正确

日期参数必须是有效的日期格式:

```js
// ✅ 正确格式
YEAR("2023-10-15")
YEAR("2023/10/15")
YEAR(TODAY())

// ❌ 错误格式
YEAR("2023年10月15日")  // 可能无法识别
YEAR("10/15/2023")      // 可能识别错误
```

### ⚠️ 计算年龄的简化方式

YEAR 相减只是粗略计算:

```js
// ⚠️ 简化计算(可能不准确)
YEAR(TODAY()) - YEAR("1990-12-31")
// 如果今天是 2023-01-01,会返回 33
// 但实际上生日还没到,应该是 32 岁

// ✅ 更准确的方式:结合月日判断(见技巧5)
```

### ⚠️ 时区问题

YEAR 提取的是系统当地时区的年份:

```js
// 中国时间:2023-12-31 23:00
YEAR(NOW())  // 返回:2023

// UTC时间:2024-01-01 01:00(同一时刻)
YEAR(NOW())  // 返回:2024
```

### ⚠️ 与 DATEFORMAT 的区别

```js
YEAR("2023-10-15")                    // 返回:2023(数字)
DATEFORMAT("2023-10-15", "YYYY")       // 返回:"2023"(文本)

// 两者都能获取年份,但类型不同
// 用于计算时用 YEAR
// 用于显示时用 DATEFORMAT
```
