# 「「云之家」」计算公式之 NOT_NULL 函数

## 一、函数作用

`NOT_NULL` 函数用来**判断值是否不为空**,简单来说就是:
- 检查值是否已填写(不为空)
- 返回 true(不为空)或 false(为空)
- 是 ISNULL 函数的相反判断
- 常用于必填项检查、数据完整性验证

---

## 二、语法格式

```
NOT_NULL(值)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 值 | 要判断是否不为空的值,可以是:<br>• 文本字符串<br>• 数字<br>• 数组<br>• 对象<br>• 控件值 | ✅ 必填 | NOT_NULL(客户名称) |

### 返回值

- **不为空时**:返回 **true**
- **为空时**:返回 **false**

---

## 三、实用示例

### 示例 1:基本用法

```js
NOT_NULL("客户A")        // 返回:true(有值)
NOT_NULL("")             // 返回:false(空字符串)
NOT_NULL(100)            // 返回:true(数字)
NOT_NULL(0)              // 返回:true(0也是有效值)
NOT_NULL(null)           // 返回:false(null)
```

### 示例 2:检查文本是否填写

```js
NOT_NULL("云之家")        // 返回:true
NOT_NULL("")             // 返回:false
NOT_NULL("   ")          // 返回:true(有空格,不算空)
```

### 示例 3:检查数组是否为空

```js
NOT_NULL([1, 2, 3])      // 返回:true(非空数组)
NOT_NULL([])             // 返回:false(空数组)
NOT_NULL(["a"])          // 返回:true
```

### 示例 4:检查表单必填项

假设有【订单信息】表单:

| 订单号 | 客户名称 | 备注 | 客户名称是否填写 | 备注是否填写 |
|-------|---------|------|----------------|------------|
| 001 | 客户A | | NOT_NULL("客户A") = **true** | NOT_NULL("") = **false** |
| 002 | 客户B | 特殊订单 | NOT_NULL("客户B") = **true** | NOT_NULL("特殊订单") = **true** |
| 003 | | 紧急 | NOT_NULL("") = **false** | NOT_NULL("紧急") = **true** |

```js
// 检查客户名称是否填写
NOT_NULL(客户名称)

// 检查备注是否填写
NOT_NULL(备注)
```

### 示例 5:检查数字字段

```js
NOT_NULL(100)            // 返回:true
NOT_NULL(0)              // 返回:true(0是有效数字)
NOT_NULL(-5)             // 返回:true(负数也有效)
NOT_NULL("")             // 返回:false
```

## 五、常见问题

### 0 算不算空值?

不算,0 是有效的数字值。

```js
NOT_NULL(0)              // 返回:true(0是有效值)
NOT_NULL("")             // 返回:false(空字符串才是空)
```

### 空格算不算空?

只包含空格的字符串不算空。

```js
NOT_NULL("")             // 返回:false(真正的空)
NOT_NULL("   ")          // 返回:true(有空格)
NOT_NULL(" ")            // 返回:true(单个空格)
```

### NOT_NULL 和 ISNULL 有什么区别?

NOT_NULL 是 ISNULL 的相反判断:

```js
NOT_NULL("云之家")       // 返回:true(不为空)
ISNULL("云之家")         // 返回:false(不是空)

NOT_NULL("")             // 返回:false(为空)
ISNULL("")               // 返回:true(是空)

// 两者关系
NOT_NULL(值) == !ISNULL(值)
```

### 如何同时检查多个字段?

使用 `&&`(且)运算符:

```js
// 所有字段都不为空
NOT_NULL(字段1) && NOT_NULL(字段2) && NOT_NULL(字段3)

// 至少有一个不为空
NOT_NULL(字段1) || NOT_NULL(字段2) || NOT_NULL(字段3)
```

### 空数组算不算空?

空数组算空值。

```js
NOT_NULL([])             // 返回:false(空数组)
NOT_NULL([1])            // 返回:true(非空数组)
NOT_NULL([1, 2, 3])      // 返回:true
```

## 六、搭配使用技巧

### 技巧 1:结合 IF 显示提示

```js
// 必填项提示

// 完整性提示
IF(NOT_NULL(备注), CONCATENATE("备注:", 备注), "未填写备注")
```

### 技巧 2:必填项统一检查

```js
// 检查所有必填项是否都填写

   "✓ 信息完整",
   "✗ 请完善必填信息")
```

### 技巧 3:条件计算

```js
// 只有填写了折扣才计算折扣价
IF(NOT_NULL(折扣),
   原价 * (100 - 折扣) / 100,
   原价)
```

### 技巧 4:在 COUNTIF 中使用

```js
// 统计填写了备注的记录数
COUNTIF(订单明细.控件自身, NOT_NULL(订单明细.备注))

// 统计信息完整的记录数
COUNTIF(客户明细.控件自身,
        NOT_NULL(客户明细.姓名) &&
        NOT_NULL(客户明细.手机号) &&
        NOT_NULL(客户明细.地址))
```

### 技巧 5:数据完整度计算

```js
// 计算填写率
COUNTIF(订单明细.控件自身, NOT_NULL(订单明细.备注)) / COUNT(订单明细.备注) * 100
// 返回:备注的填写率百分比
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **NOT_NULL** | 判断不为空 | NOT_NULL("云之家") | true |
| **ISNULL** | 判断是否为空 | ISNULL("") | true |
| **LEN** | 计算长度 | LEN("云之家") | 3 |
| **COUNT** | 统计数量 | COUNT(明细.字段) | 5 |

**详细对比:**

```js
// NOT_NULL:判断不为空
NOT_NULL("云之家")        // 返回:true(有值)
NOT_NULL("")             // 返回:false(空值)

// ISNULL:判断是否为空
ISNULL("云之家")         // 返回:false(有值,不是空)
ISNULL("")               // 返回:true(是空)

// LEN:计算长度(可间接判断是否为空)
LEN("云之家")            // 返回:3
LEN("")                  // 返回:0

// 关系
NOT_NULL(值) == !ISNULL(值)
NOT_NULL(值) == (LEN(值) > 0)  // 对文本有效
```

**使用建议:**
- **判断不为空**:用 NOT_NULL
- **判断是否为空**:用 ISNULL
- **计算长度**:用 LEN

**记忆方法:**
- NOT_NULL = 不是空(Not Null)
- ISNULL = 是空(Is Null)

## 十、与 LEN 的配合使用

### 区别说明

NOT_NULL 和 LEN 都可以用来判断是否为空,但有细微差别:

```js
// NOT_NULL:判断是否有值
NOT_NULL("")             // 返回:false
NOT_NULL("   ")          // 返回:true(有空格)

// LEN:计算长度
LEN("")                  // 返回:0
LEN("   ")               // 返回:3(3个空格)

// 可以结合使用
LEN(值) > 0              // 等同于 NOT_NULL(值)(对文本)
```

### 配合使用示例

```js
// 检查是否填写了有效内容(不是纯空格)
NOT_NULL(备注) && LEN(TRIM(备注)) > 0

// 检查字段填写且达到最小长度
NOT_NULL(说明) && LEN(说明) >= 10
```
