# 「「云之家」」计算公式之 WEEKDAY 函数

## 一、函数作用

`WEEKDAY` 函数用来**获取日期是星期几（0-6）**,简单来说就是:
- 根据输入的日期返回该日期是星期几
- 返回值为0-6的数字
- 0表示周日,1表示周一,...,6表示周六
- 方便进行工作日和周末的判断

常用于按星期统计数据、判断工作日、排班管理等场景。

---

## 二、语法格式

```
WEEKDAY(日期)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期 | 需要获取星期的日期 | ✅ 必填 | 2024-03-15 |

### 返回值

- **正常情况**:返回0-6的数字（0=周日,1=周一,...,6=周六）
- **特殊情况**:如果日期无效则返回空值

---

## 三、实用示例

### 示例 1:基本用法

```js
// 获取日期是星期几
WEEKDAY("2024-01-01")  // 返回: 1 (周一)
WEEKDAY("2024-01-07")  // 返回: 0 (周日)
```

### 示例 2:判断是否为周末

```js
// 判断是否为周末（周日=0 或 周六=6）
IF(WEEKDAY("2024-01-06") = 6 OR WEEKDAY("2024-01-06") = 0, "周末", "工作日")  // 返回: 周末
```

### 示例 3:显示星期名称

```js
// 将数字转换为星期名称
IF(WEEKDAY("2024-01-15") = 1, "周一",
   IF(WEEKDAY("2024-01-15") = 2, "周二",
      IF(WEEKDAY("2024-01-15") = 3, "周三",
         IF(WEEKDAY("2024-01-15") = 4, "周四",
            IF(WEEKDAY("2024-01-15") = 5, "周五",
               IF(WEEKDAY("2024-01-15") = 6, "周六", "周日"))))))  // 返回: 周一
```

### 示例 4:获取当前日期的星期

```js
// 获取今天是星期几
WEEKDAY(NOW())  // 如果今天是周三,返回: 3
```

### 示例 5:计算工作日数量

```js
// 判断是否为工作日（周一到周五）
IF(WEEKDAY([日期]) >= 1 AND WEEKDAY([日期]) <= 5, 1, 0)  // 工作日返回1,周末返回0
```

### 示例 6:按星期分类

```js
// 按星期分类显示（使用 CONCATENATE 拼接）
CONCATENATE("星期", TEXT(WEEKDAY("2024-01-15")))  // 返回: 星期1
```

## 四、实际业务场景

### 场景 1:员工排班管理

根据日期判断员工的排班类型（工作日班次或周末班次）。

```js
// 【班次类型】的计算公式
IF(WEEKDAY([排班日期]) >= 1 AND WEEKDAY([排班日期]) <= 5, "工作日班次", "周末班次")
```

### 场景 2:订单发货时间预估

根据下单日期判断是否为工作日,预估发货时间。

```js
// 【发货提示】的计算公式
IF(WEEKDAY([下单日期]) >= 1 AND WEEKDAY([下单日期]) <= 5, "1-2个工作日发货", "周一发货")
```

### 场景 3:会议室使用统计

统计会议室在工作日和周末的使用情况。

```js
// 【使用时段】的计算公式
IF(WEEKDAY([预订日期]) >= 1 AND WEEKDAY([预订日期]) <= 5, "工作日", "周末")
```

### 场景 4:客服排班表

根据星期几安排不同的客服人员值班。

```js
// 【值班提示】的计算公式
IF(WEEKDAY([值班日期]) = 1, "周一值班",
   IF(WEEKDAY([值班日期]) = 2, "周二值班",
      IF(WEEKDAY([值班日期]) >= 6, "周末值班", "其他工作日值班")))
```

## 五、常见问题

### ❓ WEEKDAY函数返回的数字是从0开始还是从1开始？

在云之家计算公式中,WEEKDAY返回0-6,0代表周日,1代表周一,...,6代表周六。

```js
// ✅ 正确理解
WEEKDAY("2024-01-01")  // 返回: 1 (周一)
WEEKDAY("2024-01-07")  // 返回: 0 (周日)

// ❌ 错误理解
// 不是1-7,也不是从周一开始
```

### ❓ 如何判断是否为周末？

判断WEEKDAY返回值是否等于0或6。

```js
// ✅ 正确:判断周末
IF(WEEKDAY([日期]) = 0 OR WEEKDAY([日期]) = 6, "周末", "工作日")

// ❌ 错误:错误的判断条件
IF(WEEKDAY([日期]) = 7, "周末", "工作日")  // WEEKDAY不会返回7
```

### ❓ WEEKDAY函数能处理文本日期吗？

可以,只要文本日期格式规范。

```js
// ✅ 正确:处理文本日期
WEEKDAY("2024-03-15")  // 返回: 5 (周五)
WEEKDAY("2024/03/15")  // 返回: 5 (周五)

// ❌ 错误:格式不规范
WEEKDAY("2024年3月15日")  // 可能无法正确解析
```

### ❓ 如何处理空值日期？

使用IF函数进行空值判断。

```js
// ✅ 正确:处理空值
IF(ISNULL([日期]), "", WEEKDAY([日期]))

// ❌ 错误:不处理空值
WEEKDAY([日期])  // 空值时可能出错
```

### ❓ 如何计算两个日期之间有多少个工作日？

需要结合其他函数进行逐日判断和统计。

```js
// ✅ 正确:判断单个日期是否为工作日
IF(WEEKDAY([日期]) >= 1 AND WEEKDAY([日期]) <= 5, 1, 0)  // 工作日返回1,周末返回0

// 注意:计算区间内工作日总数需要更复杂的公式或循环逻辑
```

### ❓ WEEKDAY函数支持设置周一为第一天吗？

WEEKDAY返回0-6（0=周日）。如需从1开始显示,可以加1。

```js
// ✅ 正确:标准用法（0=周日,1=周一）
WEEKDAY("2024-01-01")  // 周一返回1

// 如需显示为1-7（1=周日,2=周一...）,可以+1
WEEKDAY([日期]) + 1
```

## 八、注意事项

### ⚠️ 注意返回值范围

WEEKDAY返回0-6,0代表周日,1代表周一,...,6代表周六。

```js
// ❌ 错误:认为返回1-7
IF(WEEKDAY([日期]) = 7, "周日", "其他")  // WEEKDAY不会返回7

// ✅ 正确:正确的判断
IF(WEEKDAY([日期]) = 0, "周日", "其他")  // 0代表周日
```

### ⚠️ 注意空值处理

对可能为空的日期字段进行空值判断。

```js
// ❌ 错误
WEEKDAY([日期字段])  // 如果日期字段为空会出错

// ✅ 正确
IF(ISNULL([日期字段]), "", WEEKDAY([日期字段]))
```

### ⚠️ 日期格式必须规范

确保输入的日期格式规范。

```js
// ❌ 错误
WEEKDAY("2024年3月15日")  // 格式不规范

// ✅ 正确
WEEKDAY("2024-03-15")    // 规范的日期格式
```

### ⚠️ 工作日判断要考虑节假日

WEEKDAY只能判断是否为周末,不能判断是否为法定节假日。

```js
// ❌ 错误:认为非周末就是工作日
IF(WEEKDAY([日期]) >= 1 AND WEEKDAY([日期]) <= 5, "工作日", "休息日")  // 没考虑法定节假日

// ✅ 正确:需要额外判断是否为法定节假日
IF(WEEKDAY([日期]) >= 1 AND WEEKDAY([日期]) <= 5 AND NOT([是否节假日]), "工作日", "休息日")
```

### ⚠️ 不同地区的周起始日可能不同

WEEKDAY默认0=周日。某些地区习惯不同,请注意调整。

```js
// ✅ 正确:标准用法（0=周日）
WEEKDAY([日期])

// 如需显示为1-7（1=周日,7=周六）,可以加1
WEEKDAY([日期]) + 1
```
