# 校验公式写法规范

## 一、校验公式基本语义

### 返回值含义

| 返回值 | 含义 |
|--------|------|
| `true` | **阻断** — 校验不通过，阻止提交 |
| `false` | **放行** — 校验通过，允许提交 |

> ⚠️ **关键**：校验公式写的是「什么情况下报错」，而不是「什么情况下通过」。   
> 例如「请假天数超过 5 天时报错」写 `请假天数 > 5`（超过时返回 true，触发阻断）。

### 常见错误

```js
// ❌ 逻辑反了：意图是"大于 5 就报错"，但写成 true 时通过
IF(请假天数 > 5, false, true)

// ✅ 正确：直接写阻断条件
请假天数 > 5

// ✅ 或者
IF(请假天数 > 5, true, false)
```

## 二、提交校验 vs 控件校验

| 维度 | 提交校验 | 控件校验 |
|------|---------|---------|
| 触发时机 | 提交时、同意时、流程修改时 | 表单编辑时（非 5s 暂存） |
| 提示方式 | **弹框**提示 | 在**对应控件**上显示错误 |
| 是否阻断 | 是 | 是 |
| 适用场景 | 主表单跨字段、明细合计 | 明细内控件、主表单单控件 |

### 选择建议

```js
// 控件校验：错误显示在控件下方
// 适用场景：手机号格式、邮箱格式、必填校验

// 提交校验：弹框提示
// 适用场景：
//   1. 报销金额小于发票金额
//   2. 限制合同类型提交（如"销售合同请用专用表单"）
//   3. 请假天数合计超限
```

## 三、常见校验模式

### 1. 必填校验

```js
// 单个必填
ISNULL(姓名)

// A 或 B 任意一个必填
ISNULL(A控件) AND ISNULL(B控件)
```

### 2. 格式校验

```js
// 手机号 11 位
LEN(TEXT(数字输入框)) != 11

// 数字范围
金额 < 0 OR 金额 > 1000000
```

### 3. 条件必填

```js
// 合同类型为商务合同时，附件必填
IF(合同类型 == "商务合同" AND ISNULL(附件), true, false)

// 简写
合同类型 == "商务合同" AND ISNULL(附件)
```

### 4. 日期范围校验

```js
// 只能填写当月日期
IF(MONTH(日期) != MONTH(NOW()) OR YEAR(日期) != YEAR(NOW()), true, false)

// 每月 25 号后不允许提交
DAY(NOW()) >= 25

// 一次性请假不超过 5 天
DATEDIF(开始日期, 结束日期, 'd') > 5
```

### 5. 人员限制

```js
// 特定人员不允许提交
TEXTUSER(主表单.提交人, "name") == "孙悟空"

// 特定部门不允许提交
TEXTDEPT(主表单.所属部门, "name") == "财务部"
```

### 6. 明细表校验

```js
// 明细条数限制
COUNT(明细.控件自身) > 10

// 明细必须至少有一条
COUNT(明细.控件自身) == 0

// 明细内校验（提交校验用 MAP）
MAP(明细.控件自身, 明细.金额 < 0, true)
```

### 7. 数量金额校验

```js
// 数量必须大于 0
数量 <= 0

// 金额不能超过预算
金额 > 预算金额

// 折扣率范围
折扣率 < 0 OR 折扣率 > 1
```

## 四、注意事项

### 1. 单选框用 `==` 比较，多选框不行

```js
// ✅ 单选框
主表单.单选框 == "已转正"

// ❌ 多选框不能用 ==
主表单.多选框 == "已转正"
```

### 2. 日期必须用日期函数比较

```js
// ❌ 错误
主表单.日期 < 2023-07-31

// ✅ 正确
主表单.日期 < ADDDAY("2023-07-31", 0)
```

### 3. 所有符号必须为英文

```js
// ❌ 错误（中文标点）
IF(主表单.单选框 == "已转正"，true，false)

// ✅ 正确
IF(主表单.单选框 == "已转正", true, false)
```

### 4. 数字比较不带单位

```js
// ❌ 错误
主表单.请假时长 >= 8小时

// ✅ 正确
主表单.请假时长 >= 8
```

### 5. 开关控件直接用真/假判断

```js
// 开关控件值就是 true/false
IF(是否包邮, 0, 10)         // ✅
IF(是否包邮 == true, 0, 10)  // 也行但多余
```
