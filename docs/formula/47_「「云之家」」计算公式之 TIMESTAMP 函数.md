# 「「云之家」」计算公式之 TIMESTAMP 函数

## 一、函数作用

`TIMESTAMP` 函数用来**将日期时间转换为Unix时间戳（毫秒）**,简单来说就是:
- 将日期时间转换为从1970年1月1日00:00:00 UTC起的毫秒数
- 时间戳是一个长整数,方便进行时间计算
- 时间戳可以跨系统、跨平台使用
- 便于精确计算时间差

常用于时间数据的存储、传输和计算。

---

## 二、语法格式

```
TIMESTAMP(日期时间)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期时间 | 需要转换的日期或日期时间 | ✅ 必填 | 2024-03-15 14:30:00 |

### 返回值

- **正常情况**:返回以毫秒为单位的时间戳（长整数）
- **特殊情况**:如果日期无效则返回空值或错误

---

## 三、实用示例

### 示例 1:基本用法

```js
// 将日期转换为时间戳
TIMESTAMP("2024-01-01")  // 返回: 1704038400000

// 将日期时间转换为时间戳
TIMESTAMP("2024-01-01 12:00:00")  // 返回: 1704081600000
```

### 示例 2:获取当前时间的时间戳

```js
// 获取当前时间的时间戳
TIMESTAMP(NOW())  // 返回当前时间的时间戳,如: 1710489600000
```

### 示例 3:计算两个时间点的毫秒差

```js
// 计算两个日期之间的毫秒差
TIMESTAMP("2024-01-02") - TIMESTAMP("2024-01-01")  // 返回: 86400000 (1天=86400000毫秒)
```

### 示例 4:将时间戳转换为秒

```js
// 转换为秒级时间戳（除以1000）
TIMESTAMP("2024-01-01") / 1000  // 返回: 1704038400 (秒级时间戳)
```

### 示例 5:判断时间先后顺序

```js
// 通过时间戳比较时间先后
IF(TIMESTAMP([日期1]) > TIMESTAMP([日期2]), "日期1更晚", "日期2更晚或相同")
```

### 示例 6:计算小时差

```js
// 计算两个时间之间的小时差
(TIMESTAMP([结束时间]) - TIMESTAMP([开始时间])) / 3600000  // 3600000毫秒=1小时
```

## 四、实际业务场景

### 场景 1:计算订单处理时长

计算从下单到发货的时间差（小时）。

```js
// 【处理时长（小时）】的计算公式
(TIMESTAMP([发货时间]) - TIMESTAMP([下单时间])) / 3600000
```

### 场景 2:员工打卡时长统计

计算员工当天的工作时长（小时）。

```js
// 【工作时长（小时）】的计算公式
ROUND((TIMESTAMP([下班时间]) - TIMESTAMP([上班时间])) / 3600000, 2)
```

### 场景 3:会议时长计算

计算会议的持续时间（分钟）。

```js
// 【会议时长（分钟）】的计算公式
(TIMESTAMP([结束时间]) - TIMESTAMP([开始时间])) / 60000
```

### 场景 4:项目进度监控

判断项目是否超期（对比当前时间和截止时间）。

```js
// 【是否超期】的计算公式
IF(TIMESTAMP(NOW()) > TIMESTAMP([截止时间]), "已超期", "未超期")
```

## 五、常见问题

### ❓ TIMESTAMP函数返回的是毫秒还是秒？

返回的是毫秒级时间戳,如需秒级需除以1000。

```js
// ✅ 正确:毫秒级时间戳
TIMESTAMP("2024-01-01")  // 返回: 1704038400000

// ✅ 正确:转换为秒级
TIMESTAMP("2024-01-01") / 1000  // 返回: 1704038400
```

### ❓ 如何将时间戳转换回日期？

使用DATEFORMAT或TEXT函数配合时间戳。

```js
// ✅ 正确:时间戳转日期（注意格式中 YYYY/MM/DD 是大写）
DATEFORMAT(1704038400000, "YYYY-MM-DD")  // 返回: 2024-01-01

// 注意:具体实现方式可能因系统而异
```

### ❓ TIMESTAMP函数考虑时区吗？

TIMESTAMP基于UTC时区,使用时需注意本地时区转换。

```js
// ✅ 正确:理解时区影响
TIMESTAMP("2024-01-01 00:00:00")  // UTC时间的时间戳

// 注意:如果输入的是本地时间,可能需要时区调整
```

### ❓ 如何计算两个日期相差多少天？

用时间戳差值除以86400000（一天的毫秒数）。

```js
// ✅ 正确:计算天数差
(TIMESTAMP([日期2]) - TIMESTAMP([日期1])) / 86400000

// 示例
(TIMESTAMP("2024-01-08") - TIMESTAMP("2024-01-01")) / 86400000  // 返回: 7
```

### ❓ 如何处理空值日期？

使用IF函数进行空值判断。

```js
// ✅ 正确:处理空值
IF(ISNULL([日期]), "", TIMESTAMP([日期]))

// ❌ 错误:不处理空值
TIMESTAMP([日期])  // 空值时会出错
```

### ❓ TIMESTAMP函数能处理未来日期吗？

可以,时间戳可以表示任何有效的日期时间。

```js
// ✅ 正确:处理未来日期
TIMESTAMP("2025-12-31")  // 返回未来日期的时间戳
TIMESTAMP("2030-01-01")  // 返回更远未来的时间戳
```

## 六、搭配使用技巧

### 技巧 1:计算精确到秒的时间差

结合ROUND函数计算精确的秒数差。

```js
ROUND((TIMESTAMP([结束时间]) - TIMESTAMP([开始时间])) / 1000, 0)  // 返回秒数
```

### 技巧 2:判断是否在指定时间范围内

判断某个时间是否在两个时间之间。

```js
IF(TIMESTAMP([当前时间]) >= TIMESTAMP([开始时间]) AND TIMESTAMP([当前时间]) <= TIMESTAMP([结束时间]), "在范围内", "不在范围内")
```

### 技巧 3:计算工作效率

通过时间戳计算任务完成速度。

```js
[任务数量] / ((TIMESTAMP([结束时间]) - TIMESTAMP([开始时间])) / 3600000)  // 每小时完成数量
```

### 技巧 4:时间排序

使用时间戳进行时间排序比较。

```js
TIMESTAMP([日期])  // 用于排序字段,时间戳数值越大时间越晚
```

### 技巧 5:计算剩余时间

计算距离某个时间点还有多少时间。

```js
(TIMESTAMP([截止时间]) - TIMESTAMP(NOW())) / 3600000  // 剩余小时数
```

## 八、注意事项

### ⚠️ 时间戳单位是毫秒

TIMESTAMP返回的是毫秒级时间戳,不是秒。

```js
// ❌ 错误:误以为是秒级时间戳
TIMESTAMP("2024-01-01")  // 返回1704038400000,不是1704038400

// ✅ 正确:转换为秒级
TIMESTAMP("2024-01-01") / 1000  // 返回1704038400
```

### ⚠️ 注意时区问题

时间戳基于UTC时区,与本地时区可能有差异。

```js
// ❌ 错误:忽略时区差异
TIMESTAMP("2024-01-01 00:00:00")  // 可能不是本地的午夜时间

// ✅ 正确:理解时区影响
// 根据实际情况进行时区转换
```

### ⚠️ 注意空值处理

对可能为空的日期字段进行空值判断。

```js
// ❌ 错误
TIMESTAMP([日期字段])  // 空值时会出错

// ✅ 正确
IF(ISNULL([日期字段]), "", TIMESTAMP([日期字段]))
```

### ⚠️ 计算天数时注意精度

直接除以86400000可能因为时间部分产生小数。

```js
// ❌ 错误:可能有小数
(TIMESTAMP("2024-01-02 12:00:00") - TIMESTAMP("2024-01-01 08:00:00")) / 86400000  // 返回1.166...

// ✅ 正确:使用ROUND处理
ROUND((TIMESTAMP([日期2]) - TIMESTAMP([日期1])) / 86400000, 0)
```

### ⚠️ 大数值运算注意精度

时间戳是很大的数字,运算时注意精度问题。

```js
// ❌ 错误:直接显示可能超出范围
TIMESTAMP("2024-01-01")  // 返回1704038400000,显示时注意格式

// ✅ 正确:根据需要转换单位
TIMESTAMP("2024-01-01") / 1000  // 转为秒更易读
```
