# 「「云之家」」计算公式之 MINUTE 函数

## 一、函数作用

`MINUTE` 函数用来**从日期时间中提取分钟数**,简单来说就是:
- 从完整的时间中取出分钟部分
- 返回 0-59 之间的整数
- 例如:14点30分25秒 → 返回 30

常用于精确时间判断、考勤分钟级统计、会议时间计算等场景。

---

## 二、语法格式

```
MINUTE(日期时间)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期时间 | 要提取分钟的日期时间,可以是日期时间控件、时间字符串、NOW()等 | ✅ 必填 | MINUTE("2023-10-15 14:30:25") |

### 返回值

- **正常情况**:返回 0-59 之间的整数,表示分钟数
- **特殊情况**:如果参数不是有效的时间,返回空或错误

---

## 三、实用示例

### 示例 1:基本用法

```js
MINUTE("2023-10-15 14:30:25")    // 返回:30
MINUTE("2023-10-15 09:15:30")    // 返回:15
MINUTE("2023-10-15 18:45:00")    // 返回:45
MINUTE("2023-10-15 10:00:00")    // 返回:0(整点)
MINUTE("2023-10-15 23:59:59")    // 返回:59
```

### 示例 2:提取当前分钟

使用 NOW() 函数获取当前分钟:

```js
MINUTE(NOW())  // 返回当前的分钟数
```

**示例:**

| 当前时间 | MINUTE(NOW()) |
|---------|--------------|
| 2023-10-15 09:30:25 | 30 |
| 2023-10-15 14:15:25 | 15 |
| 2023-10-15 18:00:25 | 0 |

### 示例 3:精确判断迟到

判断是否在9点整之后打卡(9:00为准):

```js
IF(HOUR(打卡时间) > 9, "迟到",
   IF(HOUR(打卡时间) == 9 && MINUTE(打卡时间) > 0, "迟到", "准时"))
```

### 示例 4:按15分钟时段统计

将时间归类到15分钟时段:

```js
// 计算属于哪个15分钟时段
CASE(
  MINUTE(时间) < 15, "00-15分",
  MINUTE(时间) < 30, "15-30分",
  MINUTE(时间) < 45, "30-45分",
  "45-60分"
)
```

### 示例 5:显示友好时间格式

```js
CONCATENATE(HOUR(时间), ":",
  IF(MINUTE(时间) < 10, CONCATENATE("0", MINUTE(时间)), MINUTE(时间)))
```

### 示例 6:判断会议是否在半点开始

```js
IF(MINUTE(会议时间) == 0 || MINUTE(会议时间) == 30, "整点或半点", "其他时间")
```

## 四、实际业务场景

### 场景 1:计算迟到分钟数

计算员工迟到了多少分钟(上班时间9:00):

```js
// 【迟到分钟数】的计算公式
IF(HOUR(打卡时间) < 9, 0,
   IF(HOUR(打卡时间) == 9, MINUTE(打卡时间),
      (HOUR(打卡时间) - 9) * 60 + MINUTE(打卡时间)))
```

### 场景 2:服务响应时间分析

计算客服响应的分钟数:

```js
// 【响应时长(分钟)】的计算公式
(HOUR(响应时间) - HOUR(提交时间)) * 60 +
(MINUTE(响应时间) - MINUTE(提交时间))
```

### 场景 3:停车计费(按30分钟计费)

根据停车时长计算费用(每30分钟10元):

```js
// 【停车费用】的计算公式
ROUNDUP(((HOUR(离开时间) - HOUR(进入时间)) * 60 +
        (MINUTE(离开时间) - MINUTE(进入时间))) / 30) * 10
```

### 场景 4:会议时间规范检查

检查会议是否在规定时间点开始(整点或半点):

```js
// 【时间规范】的计算公式
IF(MINUTE(会议时间) == 0 || MINUTE(会议时间) == 30,
   "符合规范", "建议调整到整点或半点")
```

## 五、常见问题

### ❓ MINUTE 返回值的范围是什么?

返回 **0-59** 之间的整数:

```js
MINUTE("14:00:00")  // 返回:0(整点)
MINUTE("14:30:00")  // 返回:30
MINUTE("14:59:00")  // 返回:59
```

### ❓ 如何判断是否在某个时间点之后?

结合 HOUR 和 MINUTE 一起判断:

```js
// 判断是否在9:30之后
HOUR(时间) > 9 || (HOUR(时间) == 9 && MINUTE(时间) >= 30)

// 判断是否在14:45之前
HOUR(时间) < 14 || (HOUR(时间) == 14 && MINUTE(时间) < 45)
```

### ❓ 如何计算两个时间相差多少分钟?

同一小时内可以直接相减:

```js
MINUTE(结束时间) - MINUTE(开始时间)
```

跨小时需要完整计算:

```js
(HOUR(结束时间) - HOUR(开始时间)) * 60 +
(MINUTE(结束时间) - MINUTE(开始时间))
```

### ❓ 整点时 MINUTE 返回什么?

整点时返回 0:

```js
MINUTE("14:00:00")  // 返回:0
MINUTE("09:00:00")  // 返回:0
```

### ❓ 如何显示两位数的分钟(如05而不是5)?

使用 IF 函数补零:

```js
IF(MINUTE(时间) < 10,
   CONCATENATE("0", MINUTE(时间)),
   MINUTE(时间))

// 示例:
// MINUTE("14:05:00") → "05"
// MINUTE("14:30:00") → "30"
```

## 六、搭配使用技巧

### 技巧 1:结合 HOUR 进行精确时间判断

```js
// 判断是否在9:30到18:00之间
(HOUR(时间) > 9 || (HOUR(时间) == 9 && MINUTE(时间) >= 30)) &&
(HOUR(时间) < 18 || (HOUR(时间) == 18 && MINUTE(时间) == 0))
```

### 技巧 2:格式化显示时间

```js
// 显示为 HH:MM 格式
CONCATENATE(
  IF(HOUR(时间) < 10, CONCATENATE("0", HOUR(时间)), HOUR(时间)),
  ":",
  IF(MINUTE(时间) < 10, CONCATENATE("0", MINUTE(时间)), MINUTE(时间))
)
// 返回:"09:05" 或 "14:30"
```

### 技巧 3:按时间段分组

```js
// 按10分钟时段分组
CONCATENATE(HOUR(时间), ":",
  ROUNDDOWN(MINUTE(时间) / 10) * 10, "-",
  ROUNDDOWN(MINUTE(时间) / 10) * 10 + 10)

// 14:23 → "14:20-30"
// 14:57 → "14:50-60"
```

### 技巧 4:计算时长并显示

```js
// 显示工作时长
CONCATENATE(
  HOUR(结束时间) - HOUR(开始时间), "小时",
  MINUTE(结束时间) - MINUTE(开始时间), "分钟"
)
```

### 技巧 5:判断时间是否为整5分钟

```js
// 判断分钟是否为5的倍数
IF(MINUTE(时间) % 5 == 0, "整5分钟", "非整5分钟")
```

## 七、相关函数对比

| 函数 | 作用 | 返回值示例 | 使用场景 |
|------|------|-----------|---------|
| **MINUTE(时间)** | 提取分钟(0-59) | 30 | 精确到分钟的判断 |
| **HOUR(时间)** | 提取小时(0-23) | 14 | 按小时统计、时段判断 |
| **SECOND(时间)** | 提取秒(0-59) | 25 | 精确到秒的判断 |
| **NOW()** | 获取当前时间 | 2023-10-15 14:30:25 | 获取实时时间 |
| **DATEFORMAT(时间, 格式)** | 格式化时间 | 14:30 | 自定义时间显示格式 |

**详细对比:**

```js
// 假设时间为:2023-10-15 14:30:25

HOUR("2023-10-15 14:30:25")      // 返回:14
MINUTE("2023-10-15 14:30:25")    // 返回:30
SECOND("2023-10-15 14:30:25")    // 返回:25

// 格式化显示
DATEFORMAT("2023-10-15 14:30:25", "HH:mm")  // 返回:"14:30"

// 组合判断:是否在9:30之后
HOUR(时间) > 9 || (HOUR(时间) == 9 && MINUTE(时间) >= 30)
```

## 八、注意事项

### ⚠️ 返回值范围是0-59

分钟数不会超过59:

```js
MINUTE("14:59:00")  // 返回:59(不是60)
MINUTE("15:00:00")  // 返回:0(新的一小时)
```

### ⚠️ 整点时返回0

整点时分钟为0:

```js
MINUTE("14:00:00")  // 返回:0

// ❌ 错误判断
IF(MINUTE(时间), "有分钟", "没有分钟")
// 0会被判断为false

// ✅ 正确判断
IF(MINUTE(时间) > 0, "有分钟", "整点")
```

### ⚠️ 跨小时计算要注意

简单相减只适用于同一小时:

```js
// ❌ 错误:跨小时计算
MINUTE("10:10:00") - MINUTE("09:50:00")
// 返回:-40,但实际过了20分钟

// ✅ 正确:完整计算
(HOUR("10:10:00") - HOUR("09:50:00")) * 60 +
(MINUTE("10:10:00") - MINUTE("09:50:00"))
// 返回:20
```

### ⚠️ 只提取分钟,不包含秒

MINUTE 不包含秒的信息:

```js
MINUTE("14:30:25")  // 返回:30(不包含25秒)
MINUTE("14:30:59")  // 返回:30(不包含59秒)

// 如需精确到秒,使用 SECOND 函数
```

### ⚠️ 参数必须是有效时间

无效时间会导致错误:

```js
MINUTE("abc")        // 错误或返回空
MINUTE("")           // 错误或返回空

// ✅ 使用前先判断
IF(ISNULL(时间), 0, MINUTE(时间))
```
