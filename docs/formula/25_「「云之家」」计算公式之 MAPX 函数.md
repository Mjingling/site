# 「「云之家」」计算公式之 MAPX 函数

## 一、函数作用

`MAPX` 函数用来**根据映射关系查找值**，支持：
- 在控件选项中查找匹配值
- 根据条件返回对应的值
- 支持多种操作类型（count、max、min 等）

常用于选项映射、条件查询、数据转换等场景。

---

## 二、语法格式


MAPX(操作类型, 映射字段, 匹配值, 结果字段)


### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 操作类型 | 要执行的操作 | ✅ 必填 | "count"、"max"、"min" |
| 映射字段 | 要映射的控件 | ✅ 必填 | 单选框、下拉框等 |
| 匹配值 | 要匹配的值 | ✅ 必填 | "选项1"、"选项2" |
| 结果字段 | 要返回的字段 | ✅ 必填 | 数字控件、文本控件 |

### 返回值

- **正常情况**：返回匹配的结果值
- **特殊情况**：
  - 如果没有匹配项，返回空字符串
  - 如果参数不完整，返回空

---

## 三、实用示例

### 示例 1：统计匹配数量


VALUE(MAPX("count", 文本框, "6", 文本框)) >= 3


### 示例 2：获取最大值


MAPX("max", 单选框, "单选框选项1", 金额)


### 示例 3：条件映射


MAPX("count", 状态, "进行中", 任务数)

## 四、实际业务场景

### 场景 1：统计符合条件的数据


IF(VALUE(MAPX("count", 任务状态, "已完成", 任务ID)) >= 10,
    "已完成任务超过10个",
    "继续努力")


### 场景 2：获取极值


MAPX("max", 商品类别, "电子产品", 销售额)


### 场景 3：条件判断


IF(VALUE(MAPX("count", 审批状态, "已通过", 审批ID)) > 0,
    "审批已通过",
    "审批中")


### 场景 4：数据验证


IF(MAPX("count", 状态, "已提交", 表单ID) != "",
    "已提交",
    "未提交")

## 五、常见问题

### ❓ 支持哪些操作类型？

根据测试用例，支持的操作类型包括：
- `"count"`：统计数量
- `"max"`：获取最大值
- `"min"`：获取最小值

具体支持的操作类型可能因版本而异。

### ❓ 如何判断是否匹配成功？

如果匹配成功，返回对应的值；如果未匹配，返回空字符串：


MAPX("count", 状态, "不存在", 数量)  // 返回：''


### ❓ 为什么返回空值？

可能的原因：
1. 匹配值不存在
2. 控件没有选择值
3. 操作类型不支持
4. 参数不完整

### ❓ MAPX 和 MAP 有什么区别？

- `MAPX`：根据条件映射查找值，类似数据库查询
- `MAP`：遍历数组并对每一项执行表达式，类似数组的 map 方法


MAPX("max", 类别, "水果", 价格)

MAP(商品明细, "价格")

## 六、搭配使用技巧

### 技巧 1：结合 IF 判断


IF(VALUE(MAPX("count", 状态, "已完成", ID)) >= 3,
    "已完成多个任务",
    "继续完成")


### 技巧 2：数值比较


VALUE(MAPX("count", 文本框, "6", 文本框)) >= 3


### 技巧 3：多个 MAPX 组合


VALUE(MAPX("count", 控件1, "值1", 目标1)) + 
VALUE(MAPX("max", 控件2, "值2", 目标2)) + 15

## 七、注意事项

1. **操作类型**：确保使用正确的操作类型（"count"、"max"、"min"）
2. **参数顺序**：参数顺序必须正确，否则无法正常工作
3. **匹配值**：匹配值必须完全一致，区分大小写
4. **返回值类型**：返回值可能是字符串或数字，需要时使用 VALUE 转换
5. **后端支持**：此函数可能需要后端支持，确保系统配置正确

## 九、常见错误

### ❌ 错误用法


MAPX(count, 控件, "值", 目标)  // ❌

MAPX("count", 控件, "值", 目标)  // ✅

MAPX("count", "值", 控件, 目标)  // ❌

MAPX("count", 控件, "值", 目标)  // ✅
