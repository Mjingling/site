# 「「云之家」」计算公式之 UNIQ 函数

## 一、函数作用

`UNIQ` 函数用来**去除数组中的重复元素**,简单来说就是:
- 将数组中重复的元素删除,只保留唯一值
- 返回一个去重后的新数组
- 保留元素首次出现的顺序
- 常用于数据去重、统计唯一值数量等场景

---

## 二、语法格式

```
UNIQ(数组)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 数组 | 要去重的数组,可以是:<br>• 数组字面量<br>• 明细表字段<br>• 数组类型控件 | ✅ 必填 | UNIQ(["张三", "李四", "张三"]) |

### 返回值

- **正常情况**:返回去除重复元素后的新数组
- **空数组**:返回空数组 []
- **无重复**:返回原数组

---

## 三、实用示例

### 示例 1:基本用法

```js
// 去除重复的姓名
UNIQ(["张三", "李四", "张三", "王五", "李四"])
// 返回:["张三", "李四", "王五"]

// 去除重复的数字
UNIQ([1, 2, 1, 3, 2])
// 返回:[1, 2, 3]

// 去除重复的布尔值
UNIQ([true, false, true, false])
// 返回:[true, false]
```

### 示例 2:去除明细表重复数据

假设有【员工列表】明细表:

| 员工姓名 | 部门 |
|---------|------|
| 张三 | 技术部 |
| 李四 | 销售部 |
| 张三 | 技术部 |
| 王五 | 人事部 |
| 李四 | 销售部 |

```js
// 去除重复的员工姓名
UNIQ(员工列表.员工姓名)
// 返回:["张三", "李四", "王五"]

// 去除重复的部门
UNIQ(员工列表.部门)
// 返回:["技术部", "销售部", "人事部"]
```

### 示例 3:统计唯一值数量

```js
// 统计有多少个不同的员工
COUNT(UNIQ(员工列表.员工姓名))
// 如果有重复,返回实际人数

// 统计有多少个不同的部门
COUNT(UNIQ(员工列表.部门))
// 返回部门数量
```

### 示例 4:去除重复的标签

```js
// 去除重复的标签
UNIQ(["新品", "促销", "新品", "热销", "促销"])
// 返回:["新品", "促销", "热销"]

// 从明细表去重标签
UNIQ(商品列表.标签)
```

### 示例 5:空数组和无重复

```js
// 空数组
UNIQ([])
// 返回:[]

// 没有重复元素
UNIQ([1, 2, 3, 4, 5])
// 返回:[1, 2, 3, 4, 5](原数组)
```

## 五、常见问题

### 如果数组为空会怎样?

返回空数组。

```js
UNIQ([])                 // 返回:[]
UNIQ(空明细表.字段)       // 返回:[]
```

### 去重后的顺序如何?

保留元素首次出现的顺序。

```js
UNIQ(["c", "a", "b", "a", "c"])
// 返回:["c", "a", "b"](保持首次出现的顺序)
```

### 不同类型的值如何去重?

不同类型被视为不同的值:

```js
UNIQ([1, "1", 1, "1"])
// 返回:[1, "1"](数字1和字符串"1"不同)

UNIQ([true, 1, true, 1])
// 返回:[true, 1](布尔值和数字不同)
```

### null 和空字符串如何处理?

null 和空字符串被视为不同的值:

```js
UNIQ([null, "", null, ""])
// 返回:[null, ""](两者不同)

UNIQ(["", "a", "", "b"])
// 返回:["", "a", "b"]
```

### 能去除对象数组的重复吗?

这取决于系统的实现,通常对象可能按引用比较:

```js
// 如果是简单值数组,可以去重
UNIQ([1, 2, 1, 3])       // 返回:[1, 2, 3]

// 复杂对象的去重可能需要其他方法
```

## 六、搭配使用技巧

### 技巧 1:统计唯一值数量

```js
// 统计不重复的数量
COUNT(UNIQ(数组))

// 示例:统计参与的部门数
COUNT(UNIQ(员工明细.部门))
```

### 技巧 2:计算重复率

```js
// 计算数据重复率
(COUNT(原数组) - COUNT(UNIQ(原数组))) / COUNT(原数组) * 100

// 示例:访客重复访问率
(COUNT(访问记录.用户ID) - COUNT(UNIQ(访问记录.用户ID))) / COUNT(访问记录.用户ID) * 100
```

### 技巧 3:判断是否有重复

```js
// 判断是否有重复数据
IF(COUNT(数组) == COUNT(UNIQ(数组)), "无重复", "有重复")

// 示例:检查员工姓名是否重复
IF(COUNT(员工明细.姓名) == COUNT(UNIQ(员工明细.姓名)),
   "✓ 姓名唯一",
   "✗ 存在重名")
```

### 技巧 4:显示去重列表

```js
// 显示唯一部门列表
CONCATENATE("涉及部门:", COUNT(UNIQ(员工明细.部门)), "个")

// 拼接显示
// 注意:这里需要系统支持数组转字符串
```

### 技巧 5:在条件中使用

```js
// 判断唯一值数量是否达标
IF(COUNT(UNIQ(商品明细.分类)) >= 5, "分类丰富", "分类不足")

// 判断是否有多个供应商
IF(COUNT(UNIQ(采购明细.供应商)) > 1, "多供应商", "单一供应商")
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **UNIQ** | 数组去重 | UNIQ([1, 2, 1, 3]) | [1, 2, 3] |
| **COUNT** | 统计数量 | COUNT([1, 2, 1, 3]) | 4 |
| **SUM** | 求和 | SUM([1, 2, 1, 3]) | 7 |
| **AVERAGE** | 求平均 | AVERAGE([1, 2, 1, 3]) | 1.75 |

**详细对比:**

假设数组为 [1, 2, 1, 3, 2]:

```js
// UNIQ:去重
UNIQ([1, 2, 1, 3, 2])           // 返回:[1, 2, 3]

// COUNT:计数(包含重复)
COUNT([1, 2, 1, 3, 2])          // 返回:5

// COUNT + UNIQ:唯一值数量
COUNT(UNIQ([1, 2, 1, 3, 2]))    // 返回:3

// SUM:求和(包含重复)
SUM([1, 2, 1, 3, 2])            // 返回:9

// AVERAGE:平均值(包含重复)
AVERAGE([1, 2, 1, 3, 2])        // 返回:1.8
```

**记忆方法:**
- UNIQ = 唯一(Unique)
- COUNT = 计数(Count)
- SUM = 求和(Sum)

## 十、与 COUNT 的组合使用

### 统计模式对比

```js
// 原始数据:["A", "B", "A", "C", "B", "D"]

// 1. 总数量(包含重复)
COUNT(数组)                    // 返回:6

// 2. 唯一值数量
COUNT(UNIQ(数组))              // 返回:4(A,B,C,D)

// 3. 重复数量
COUNT(数组) - COUNT(UNIQ(数组)) // 返回:2

// 4. 重复率
(COUNT(数组) - COUNT(UNIQ(数组))) / COUNT(数组) * 100
// 返回:33.33%
```

### 实际应用示例

```js
// 订单去重统计
// 总订单数
COUNT(订单明细.订单号)           // 100个

// 唯一客户数
COUNT(UNIQ(订单明细.客户))       // 35个

// 平均每客户订单数
COUNT(订单明细.订单号) / COUNT(UNIQ(订单明细.客户))
// 100 / 35 ≈ 2.86 单/客户

// 复购率
(COUNT(订单明细.订单号) - COUNT(UNIQ(订单明细.客户))) / COUNT(订单明细.订单号) * 100
// (100 - 35) / 100 = 65%
```

## 十一、注意事项

### 1. 性能考虑

去重操作需要遍历整个数组,数据量大时可能影响性能:

```js
// 对于大数据集,去重可能较慢
UNIQ(大规模明细表.字段)  // 数据量大时需注意
```

### 2. 数据类型

确保数组元素类型一致:

```js
// 推荐:类型一致
UNIQ([1, 2, 3, 4])           // ✓

// 注意:混合类型可能产生意外结果
UNIQ([1, "1", 2, "2"])       // 可能保留 [1, "1", 2, "2"]
```

### 3. null 值处理

注意 null 值的保留:

```js
UNIQ([null, 1, null, 2])     // 返回:[null, 1, 2]
UNIQ(["", 1, "", 2])         // 返回:["", 1, 2]
```
