# 「「云之家」」计算公式之 CONCATENATE 函数

## 一、函数作用

`CONCATENATE` 函数用来**拼接文本**，简单来说就是：
- 将多个文本连接成一个文本
- 可以连接文本、数字、日期等各种类型
- 自动将非文本类型转换为文本再拼接

常用于生成完整地址、拼接编号、组合信息等场景。

---

## ⚠️ 使用限制

- **对象/数组类型的控件值直接拼接会变成 `[object Object]`**：人员、部门、多选框等控件值不是字符串，需先用 `TEXTUSER`、`TEXTDEPT`、`TEXTENUM` 提取文本后再拼接
- **空值当作空字符串**，不会自动跳过

---

## 二、语法格式

```
CONCATENATE(文本1, 文本2, ...文本N)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 文本1, 文本2... | 要连接的内容，可以是：<br>• 文本字符串<br>• 数字<br>• 布尔值<br>• 日期<br>• 控件值 | ✅ 至少1个 | CONCATENATE("你好", "世界") |

### 返回值

- **正常情况**：返回拼接后的文本字符串
- **空值处理**：空值会被当作空字符串""处理

---

## 三、实用示例

### 示例 1：基本拼接

```js
CONCATENATE("你好", "世界")                // 返回："你好世界"
CONCATENATE("Hello", " ", "World")        // 返回："Hello World"
CONCATENATE("云", "之", "家")              // 返回："云之家"
```

### 示例 2：拼接姓名

假设有【姓】和【名】两个字段：

| 姓 | 名 |
|----|---|
| 张 | 三 |
| 李 | 四 |
| 王 | 五 |

```js
// 拼接完整姓名
CONCATENATE(姓, 名)  // 返回："张三"
```

### 示例 3：拼接地址

假设有【省】【市】【区】【详细地址】：

```js
// 生成完整地址
CONCATENATE(省, 市, 区, 详细地址)
// 例如："广东省深圳市南山区科技园"

// 带分隔符的地址
CONCATENATE(省, "-", 市, "-", 区, "-", 详细地址)
// 例如："广东省-深圳市-南山区-科技园"
```

### 示例 4：拼接编号

```js
// 生成订单编号
CONCATENATE("ORD", "-", "2023", "-", "001")  // 返回："ORD-2023-001"

// 生成带前缀的工号
CONCATENATE("EMP", 工号)  // 例如："EMP10086"
```

### 示例 5：拼接多种类型

```js
// 拼接文本和数字
CONCATENATE("订单金额：", 1000, "元")  // 返回："订单金额：1000元"

// 拼接多个信息
CONCATENATE(员工姓名, "(", 员工工号, ")")  // 例如："张三(10086)"
```

### 示例 6：生成描述性文本

```js
// 生成商品描述
CONCATENATE(商品名称, " - ", 颜色, " - ", 尺寸)
// 例如："iPhone14 - 黑色 - 128G"

// 生成任务标题
CONCATENATE("[", 优先级, "] ", 任务名称)
// 例如："[高] 完成项目报告"
```

## 四、实际业务场景

### 场景 1：生成完整地址

```js
// 【完整收货地址】
CONCATENATE(省, 市, 区, 街道, 详细地址)

// 【带邮编的地址】
CONCATENATE(省, 市, 区, 详细地址, "（邮编：", 邮编, "）")
```

### 场景 2：订单编号生成

```js
// 【订单编号】格式：ORD-年份-月份-流水号
CONCATENATE("ORD-", YEAR(订单日期), "-", MONTH(订单日期), "-", 流水号)
// 例如："ORD-2023-12-001"

// 【产品编号】格式：类别代码-顺序号
CONCATENATE(类别代码, "-", 顺序号)
// 例如："A-001"
```

### 场景 3：员工信息展示

```js
// 【员工完整信息】
CONCATENATE(姓名, " | ", 部门, " | ", 职位, " | ", 工号)
// 例如："张三 | 技术部 | 工程师 | 10086"

// 【联系方式】
CONCATENATE("手机：", 手机号, " 邮箱：", 邮箱)
```

### 场景 4：商品描述生成

```js
// 【商品完整描述】
CONCATENATE(品牌, " ", 商品名称, " ", 规格, " ", 颜色)
// 例如："苹果 iPhone14 Pro 256G 深空黑"

// 【价格标签】
CONCATENATE("原价：", 原价, "元 现价：", 现价, "元")
```

### 场景 5：提示信息生成

```js
// 【库存提示】
CONCATENATE("当前库存：", 库存数量, "件，库存", IF(库存数量 < 10, "不足", "充足"))
// 例如："当前库存：5件，库存不足"

// 【进度提示】
CONCATENATE("已完成 ", 已完成数量, "/", 总数量, " 项任务")
// 例如："已完成 8/10 项任务"
```

## 五、常见问题

### 空值会怎样？

空值会被当作空字符串处理，不影响拼接：

```js
CONCATENATE("你好", "", "世界")      // 返回："你好世界"
CONCATENATE("姓名：", 空控件)        // 返回："姓名："
```

### 能拼接数字吗？

可以，数字会自动转换为文本：

```js
CONCATENATE("数量：", 100)           // 返回："数量：100"
CONCATENATE("订单", 123, "号")       // 返回："订单123号"
```

### 如何添加换行？

在云之家中可能需要使用特定的换行符（具体根据平台支持）：

```js
CONCATENATE("第一行", "\n", "第二行")  // 可能支持换行
```

### CONCATENATE 和 + 号的区别？

很多系统中可以用 `+` 号直接拼接字符串，效果类似：

```js
// 使用 CONCATENATE
CONCATENATE("你好", "世界")   // 返回："你好世界"

// 使用 + 号（如果支持）
"你好" + "世界"                // 返回："你好世界"
```

**建议**：使用 CONCATENATE 函数更规范，兼容性更好。

### 如何拼接很多个字段？

可以连续写参数，没有数量限制：

```js
CONCATENATE(字段1, 字段2, 字段3, 字段4, 字段5, 字段6)
```

### ❓ 能直接拼接人员、部门等复杂控件值吗？

不建议。人员、部门等控件值格式为对象数组，直接拼接会出现 "[object Object]"：

```js
// ❌ 错误
CONCATENATE("审批人：", 审批人)  // 返回："审批人：[object Object]"

// ✅ 正确：先用 TEXTUSER、TEXTDEPT 提取文本
CONCATENATE("审批人：", TEXTUSER(审批人, 'name'))  // 返回："审批人：张三"
CONCATENATE("部门：", TEXTDEPT(所属部门, 'name'))   // 返回："部门：技术部"
```

同样，多选框控件值拼接时会被逗号连接，建议也先用函数提取：

```js
// 多选框直接拼接
CONCATENATE("标签：", 多选框)  // 可能返回："标签：重要,紧急"

// 建议先提取后再拼接
CONCATENATE("标签：", TEXTENUM(标签, 'name'))  // 返回："标签：重要"（只取第一个）
```

## 六、搭配使用技巧

### 技巧 1：结合 IF 动态拼接

```js
// 根据条件拼接不同内容
CONCATENATE(
  商品名称,
  IF(是否促销, " [促销]", ""),
  IF(是否新品, " [新品]", "")
)
// 例如："iPhone14 [促销] [新品]"
```

### 技巧 2：拼接明细表内容

```js
// 拼接所有商品名称（需要配合其他函数）
CONCATENATE("商品清单：", 商品1, "、", 商品2, "、", 商品3)
```

### 技巧 3：生成URL链接

```js
// 生成商品详情链接
CONCATENATE("https://shop.com/product/", 商品ID)
// 例如："https://shop.com/product/12345"
```

### 技巧 4：格式化金额显示

```js
// 显示带单位的金额
CONCATENATE("￥", ROUND(金额, 2), "元")
// 例如："￥1,234.56元"
```

### 技巧 5：生成CSV格式数据

```js
// 生成逗号分隔的数据
CONCATENATE(字段1, ",", 字段2, ",", 字段3)
// 例如："张三,技术部,10000"
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **CONCATENATE** | 拼接文本 | CONCATENATE("你好", "世界") | "你好世界" |
| **LEFT** | 提取左侧文本 | LEFT("你好世界", 2) | "你好" |
| **RIGHT** | 提取右侧文本 | RIGHT("你好世界", 2) | "世界" |
| **FIND** | 提取中间文本 | FIND("你好世界", "你好", "") | "世界" |

**详细对比**：

```js
// CONCATENATE：拼接
CONCATENATE("云", "之", "家")  // 返回："云之家"

// LEFT：提取左侧
LEFT("云之家", 1)              // 返回："云"

// RIGHT：提取右侧
RIGHT("云之家", 1)             // 返回："家"

// LEN：计算长度
LEN("云之家")                  // 返回：3
```

## 八、常见应用模式

### 模式 1：生成带格式的文本

```js
// 带序号的列表
CONCATENATE(序号, ". ", 项目名称)
// 例如："1. 项目启动会"

// 带标签的内容
CONCATENATE("[", 标签, "] ", 标题)
// 例如："[重要] 年度总结报告"
```

### 模式 2：生成复合编号

```js
// 格式：部门代码-年份-月份-序号
CONCATENATE(部门代码, "-", YEAR(NOW()), "-", MONTH(NOW()), "-", 序号)
// 例如："IT-2023-12-001"
```

### 模式 3：生成提示语

```js
// 根据数据生成提示
CONCATENATE(
  "您的订单 ",
  订单编号,
  " 已于 ",
  发货日期,
  " 发货，预计 ",
  预计送达日期,
  " 送达"
)
```
