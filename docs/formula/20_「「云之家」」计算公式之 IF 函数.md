# 「「云之家」」计算公式之 IF 函数

## 一、函数作用

`IF` 函数用来**根据条件判断返回不同的值**，简单来说就是：
- 条件为真时，返回第一个值
- 条件为假时，返回第二个值
- 类似于生活中的"如果...那么...否则..."

常用于根据条件显示不同结果、进行数据分类等场景。

---

## 二、语法格式

```
IF(条件, 条件为真时的返回值, 条件为假时的返回值)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 条件 | 要判断的条件表达式 | ✅ 必填 | IF(分数 >= 60, "及格", "不及格") |
| 条件为真时的返回值 | 当条件为真时返回的值 | ✅ 必填 | IF(分数 >= 60, "及格", "不及格") |
| 条件为假时的返回值 | 当条件为假时返回的值 | ✅ 必填 | IF(分数 >= 60, "及格", "不及格") |

### 返回值

- 根据条件判断，返回对应的值

---

## 三、实用示例

### 示例 1：基本用法

```js
IF(分数 >= 60, "及格", "不及格")

// 示例数据
IF(85 >= 60, "及格", "不及格")   // 返回："及格"
IF(45 >= 60, "及格", "不及格")   // 返回："不及格"
```

### 示例 2：判断成绩是否及格

假设有【成绩表】，包含【分数】字段：

```js
IF(分数 >= 60, "及格", "不及格")
```

### 示例 3：判断销售是否达标

```js
IF(实际销售额 >= 目标销售额, "达标", "未达标")
```

### 示例 4：根据条件返回数值

```js
// 达标奖励1000，未达标0
IF(实际销售额 >= 10000, 1000, 0)
```

## 四、实际业务场景

### 场景 1：成绩等级判断

在成绩管理中，判断是否及格：

```js
// 【是否及格】的计算公式
IF(分数 >= 60, "及格", "不及格")

// 【是否优秀】的计算公式
IF(分数 >= 90, "优秀", "良好")
```

### 场景 2：员工考勤状态

判断是否迟到：

```js
// 【考勤状态】的计算公式
IF(打卡时间 > "09:00", "迟到", "正常")
```

### 场景 3：库存预警

判断库存是否不足：

```js
// 【库存状态】的计算公式
IF(库存数量 < 安全库存, "需补货", "充足")
```

### 场景 4：折扣计算

根据金额判断是否打折：

```js
// 【实付金额】的计算公式
IF(订单金额 >= 1000, 订单金额 * 0.9, 订单金额)
```

## 五、常见问题

### ❓ 可以嵌套使用吗？

可以！通过嵌套 IF 可以实现多层条件判断。

```js
// 成绩等级判断
IF(分数 >= 90, "优秀",
  IF(分数 >= 80, "良好",
    IF(分数 >= 60, "及格", "不及格")
  )
)
```

**示例：**
- 分数 95 → "优秀"
- 分数 85 → "良好"
- 分数 70 → "及格"
- 分数 50 → "不及格"

### ❓ 条件中可以使用哪些运算符？

支持常见的比较运算符：

```js
// 等于
IF(性别 == "男", "先生", "女士")

// 不等于
IF(状态 != "完成", "进行中", "已完成")

// 大于、小于
IF(年龄 > 18, "成年", "未成年")
IF(分数 < 60, "不及格", "及格")

// 大于等于、小于等于
IF(分数 >= 60, "及格", "不及格")
IF(库存 <= 10, "紧急", "正常")
```

### ❓ 条件为空会怎样？

如果条件无法判断，通常视为 false。

```js
IF(空控件 > 100, "大于100", "不大于100")   // 返回："不大于100"
```

### ❓ 能判断多个条件吗？

可以使用 && (且) 或 || (或) 组合多个条件：

```js
// 且：两个条件都满足
IF(分数 >= 60 && 出勤率 >= 80, "通过", "不通过")

// 或：满足任一条件
IF(VIP会员 || 订单金额 >= 1000, "享受折扣", "原价")
```

## 六、搭配使用技巧

### 技巧 1：多层嵌套判断

```js
// 成绩等级：优秀、良好、中等、及格、不及格
IF(分数 >= 90, "优秀",
  IF(分数 >= 80, "良好",
    IF(分数 >= 70, "中等",
      IF(分数 >= 60, "及格", "不及格")
    )
  )
)
```

### 技巧 2：结合数学运算

```js
// 满1000打9折，否则原价
IF(订单金额 >= 1000, 订单金额 * 0.9, 订单金额)

// 超额奖励
IF(实际销售额 > 目标销售额, (实际销售额 - 目标销售额) * 0.1, 0)
```

### 技巧 3：组合多个条件

```js
// 两个条件都满足
IF(分数 >= 60 && 出勤天数 >= 20, "合格", "不合格")

// 任一条件满足
IF(VIP会员 == "是" || 消费金额 >= 5000, "金卡会员", "普通会员")
```

### 技巧 4：返回空值

```js
// 如果不满足条件，返回空（不显示任何内容）
IF(分数 < 60, "需要补考", "")
```

## 七、与 CASE 函数的区别

| 函数 | 适用场景 | 示例 |
|------|---------|------|
| IF | 简单的二选一判断 | IF(分数 >= 60, "及格", "不及格") |
| CASE | 多个条件的复杂判断 | CASE(分数 >= 90, "优秀", 分数 >= 80, "良好", 分数 >= 60, "及格", "不及格") |

**选择建议**：
- 只有2个结果 → 用 IF
- 有3个或更多结果 → 用 CASE（更清晰）

## 八、注意事项

### ⚠️ 条件表达式必须返回真或假

条件必须是可以判断真假的表达式：

```js
// ✅ 正确
IF(分数 >= 60, "及格", "不及格")
IF(状态 == "完成", "已完成", "未完成")

// ❌ 错误
IF(分数, "有分数", "无分数")   // 应该明确判断条件
```

### ⚠️ 返回值类型可以不同

两个返回值可以是不同类型：

```js
// ✅ 可以：返回文本和数字
IF(达标, "达标", 0)

// ✅ 可以：返回文本和空
IF(有问题, "需要处理", "")
```

### ⚠️ 嵌套层数不要太多

虽然支持嵌套，但层数太多会难以维护：

```js
// ❌ 不推荐：嵌套太多层
IF(条件1, 值1, IF(条件2, 值2, IF(条件3, 值3, IF(条件4, 值4, 值5))))

// ✅ 推荐：使用 CASE 函数
CASE(条件1, 值1, 条件2, 值2, 条件3, 值3, 条件4, 值4, 值5)
```
