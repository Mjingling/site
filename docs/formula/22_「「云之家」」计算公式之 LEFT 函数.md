# 「「云之家」」计算公式之 LEFT 函数

## 一、函数作用

`LEFT` 函数用来**从文本左侧提取字符**,简单来说就是:
- 从文本开头提取指定数量的字符
- 就像从左边"剪切"文本
- 常用于提取编号前缀、代码分类等

---

## 二、语法格式

```
LEFT(文本, 字符数量)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 文本 | 要提取字符的原始文本,可以是:<br>• 文本字符串<br>• 文本控件<br>• 编号控件 | ✅ 必填 | LEFT("A001-2023", 4) |
| 字符数量 | 要提取的字符个数,必须是正整数 | ✅ 必填 | 4 |

### 返回值

- **正常情况**:返回文本左侧指定数量的字符
- **字符数量超过文本长度**:返回完整文本
- **字符数量为0**:返回空字符串
- **文本为空**:返回空字符串

---

## 三、实用示例

### 示例 1:基本用法

```js
LEFT("云之家", 1)              // 返回:"云"
LEFT("云之家", 2)              // 返回:"云之"
LEFT("Hello World", 5)        // 返回:"Hello"
LEFT("2023-12-25", 4)         // 返回:"2023"
```

### 示例 2:提取产品编码前缀

假设有【产品编码】字段:

| 产品名称 | 产品编码 | 类别代码 |
|---------|---------|---------|
| iPhone | A001-2023 | LEFT("A001-2023", 1) = **"A"** |
| iPad | B002-2023 | LEFT("B002-2023", 1) = **"B"** |
| MacBook | C003-2023 | LEFT("C003-2023", 1) = **"C"** |

```js
// 提取类别代码(第一个字符)
LEFT(产品编码, 1)

// 提取完整编号(前4位)
LEFT(产品编码, 4)  // 例如:"A001"
```

### 示例 3:提取订单年份

假设订单编号格式为"年份-月份-序号":

| 订单编号 | 年份 |
|---------|------|
| 2023-01-001 | LEFT("2023-01-001", 4) = **"2023"** |
| 2024-06-102 | LEFT("2024-06-102", 4) = **"2024"** |

```js
// 提取订单年份(前4位)
LEFT(订单编号, 4)
```

### 示例 4:提取区号

```js
// 从手机号提取运营商代码(前3位)
LEFT("13812345678", 3)  // 返回:"138"

// 从身份证提取地区码(前6位)
LEFT("440305199001011234", 6)  // 返回:"440305"
```

### 示例 5:提取姓氏

```js
// 提取中文姓名的姓氏(通常1-2个字)
LEFT("张三", 1)        // 返回:"张"
LEFT("欧阳修", 2)      // 返回:"欧阳"
LEFT("司马相如", 2)    // 返回:"司马"
```

## 四、实际业务场景

### 场景 1:商品分类

根据商品编码自动分类:

```js
// 【商品类别】根据编码首字母分类
// A-电子产品 B-服装 C-食品
LEFT(商品编码, 1)

// 【大类编号】提取前两位
LEFT(商品编码, 2)  // 例如:"A0"表示电子产品-手机类
```

### 场景 2:身份证信息提取

```js
// 【地区码】提取身份证前6位
LEFT(身份证号码, 6)  // 例如:"440305"

// 【省份码】提取前2位
LEFT(身份证号码, 2)  // 例如:"44"代表广东省
```

### 场景 3:日期编码解析

```js
// 【年份】从日期编码提取年份
LEFT(日期编码, 4)  // 从"20231225"提取"2023"

// 【年月】提取年月
LEFT(日期编码, 6)  // 从"20231225"提取"202312"
```

### 场景 4:工号管理

```js
// 【部门代码】提取工号前2位
LEFT(员工工号, 2)  // 从"IT10086"提取"IT"

// 【入职年份】提取工号中的年份
LEFT(员工工号, 4)  // 从"2023001"提取"2023"
```

### 场景 5:版本号提取

```js
// 【主版本号】从版本号提取主版本
LEFT(版本号, 1)  // 从"3.2.1"提取"3"

// 【大版本】提取前3位
LEFT(版本号, 3)  // 从"3.2.1"提取"3.2"
```

## 五、常见问题

### 如果字符数量超过文本长度会怎样?

返回完整文本,不会报错。

```js
LEFT("云之家", 10)    // 返回:"云之家"(只有3个字符)
LEFT("abc", 100)     // 返回:"abc"
```

### 如果字符数量为0或负数?

字符数量为0返回空字符串,负数可能报错或返回空。

```js
LEFT("云之家", 0)     // 返回:""(空字符串)
```

### 如果文本为空会怎样?

返回空字符串。

```js
LEFT("", 5)          // 返回:""
LEFT(空控件, 3)      // 返回:""
```

### 中英文字符计算有区别吗?

没有区别,每个字符都算一个长度。

```js
LEFT("abc", 2)       // 返回:"ab"(2个字符)
LEFT("你好", 1)      // 返回:"你"(1个字符)
LEFT("a中b", 2)      // 返回:"a中"(2个字符)
```

### 如何提取固定分隔符前的内容?

结合 FIND 函数查找分隔符位置:

```js
// 方法1:如果格式固定,直接指定位数
LEFT("A001-2023", 4)  // 返回:"A001"

// 方法2:配合其他函数动态查找(如果系统支持)
// 提取"-"之前的内容
```

## 六、搭配使用技巧

### 技巧 1:结合 IF 进行分类

```js
// 根据编码首字母自动分类
IF(LEFT(商品编码, 1) == "A", "电子产品",
   IF(LEFT(商品编码, 1) == "B", "服装",
      IF(LEFT(商品编码, 1) == "C", "食品", "其他")))
```

### 技巧 2:提取并拼接

```js
// 提取年份和月份,生成新编码
CONCATENATE(LEFT(订单编号, 4), "-", LEFT(订单编号, 7))
// 从"20231225001"生成"2023-202312"
```

### 技巧 3:数据验证

```js
// 验证身份证是否为广东省
LEFT(身份证号码, 2) == "44"

// 验证工号是否为技术部
LEFT(员工工号, 2) == "IT"
```

### 技巧 4:提取姓名首字母

```js
// 生成昵称首字母
CONCATENATE(LEFT(姓名, 1), "先生/女士")
// "张三" -> "张先生"
```

### 技巧 5:批量编码规则

```js
// 生成统一编码:部门代码(2位)+年份(4位)+序号
CONCATENATE(LEFT(部门名称, 2), YEAR(NOW()), 序号)
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **LEFT** | 从左侧提取 | LEFT("云之家", 2) | "云之" |
| **RIGHT** | 从右侧提取 | RIGHT("云之家", 2) | "之家" |
| **FIND** | 提取中间内容 | FIND("A-云之家-B", "A-", "-B") | "云之家" |
| **LEN** | 计算长度 | LEN("云之家") | 3 |

**详细对比:**

假设文本为"A001-2023":

```js
LEFT("A001-2023", 4)        // 返回:"A001"(从左边取4个)
RIGHT("A001-2023", 4)       // 返回:"2023"(从右边取4个)
LEN("A001-2023")            // 返回:9(总长度)
```

**记忆方法:**
- LEFT = 左边(Left)
- RIGHT = 右边(Right)
- LEN = 长度(Length)

## 八、LEFT 和 RIGHT 的组合使用

### 提取中间部分(通过排除法)

```js
// 从"2023-12-25"中提取月份"12"
// 思路:跳过前5个字符,取2位
// 实际需要配合其他函数,LEFT/RIGHT单独无法实现
```

### 提取首尾字符

```js
// 提取首字符
LEFT(文本, 1)

// 提取尾字符
RIGHT(文本, 1)

// 拼接首尾
CONCATENATE(LEFT(文本, 1), RIGHT(文本, 1))
// "云之家" -> "云家"
```

### 判断前后缀

```js
// 判断是否以"A"开头
LEFT(编码, 1) == "A"

// 判断是否以"2023"开头
LEFT(编号, 4) == "2023"
```
