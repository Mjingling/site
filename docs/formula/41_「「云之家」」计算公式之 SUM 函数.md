# 「「云之家」」计算公式之 SUM 函数

## 一、函数作用

`SUM` 函数用来**计算总和**，就是把所有数字加起来：
- 可以将多个数字相加
- 可以对明细表中的某一列求和
- 常用于计算总金额、总数量、总分数等

---

## 二、语法格式

```
SUM(参数1, 参数2, ...参数N)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 参数1, 参数2... | 要相加的数字，可以是：<br>• 直接写数字<br>• 数字控件<br>• 金额控件<br>• 运算控件<br>• 明细控件的字段 | ✅ 至少1个 | SUM(100, 200, 300) |

### 返回值

- **正常情况**：返回所有参数的总和
- **特殊情况**：如果所有参数都为空，返回 **0**

---

## 三、实用示例

### 示例 1：计算固定数字的和

```js
SUM(100, 200, 300)        // 返回：600
SUM(50, 50)               // 返回：100
SUM(10, 20, 30, 40, 50)   // 返回：150
```

### 示例 2：计算控件的和

假设有【商品价格1】【商品价格2】【商品价格3】三个金额控件：

```js
SUM(商品价格1, 商品价格2, 商品价格3)
```

### 示例 3：计算明细表中某列的总和

假设有【费用明细】，包含多行费用数据：

| 费用项目 | 金额 |
|---------|-----|
| 交通费  | 200 |
| 餐费    | 150 |
| 住宿费  | 500 |

```js
// 自动计算所有行的金额总和
SUM(费用明细.金额)
```

结果：**850** （200 + 150 + 500）

### 示例 4：混合使用

```js
// 固定金额 + 明细总和
SUM(1000, 费用明细.金额)
```

如果明细总和是 850，结果为：**1850**

## 四、实际业务场景

### 场景 1：报销单总金额

计算多个费用项的总金额：

```js
// 【报销总额】的计算公式
SUM(交通费, 餐费, 住宿费, 其他费用)
```

### 场景 2：订单总金额

在订单明细中计算总价：

```js
// 【订单总额】的计算公式
SUM(订单明细.小计)
```

订单总额 = SUM(订单明细.小计) = **650**

### 场景 3：部门总人数

```js
// 计算多个部门的总人数
SUM(销售部人数, 技术部人数, 行政部人数)
```

### 场景 4：季度销售总额

```js
// 计算第一季度销售总额
SUM(一月销售额, 二月销售额, 三月销售额)
```

## 五、常见问题

### ❓ 如果某个参数为空怎么办？

空值会被视为 **0**，不影响计算。

```js
// 假设【商品价格2】为空
SUM(商品价格1, 商品价格2, 商品价格3)
// 实际计算：商品价格1 + 0 + 商品价格3
```

**示例：**

| 价格1 | 价格2 | 价格3 | 总和 |
|------|------|------|------|
| 100  | 200  | 150  | 450  |
| 100  | 空   | 150  | 250  |

### ❓ 所有参数都为空会怎样？

返回 **0**。

```js
SUM("", "", "")      // 返回：0
SUM(空控件1, 空控件2) // 返回：0
```

### ❓ 能对明细表的多个字段求和吗？

可以，但需要分别计算：

```js
// ❌ 错误：不能这样写
SUM(明细.字段1, 明细.字段2)

// ✅ 正确：分别求和后再相加
SUM(明细.字段1) + SUM(明细.字段2)
```

### ❓ 明细表为空会怎样？

返回 **0**。

```js
SUM(空明细表.金额)   // 返回：0
```

## 六、搭配使用技巧

### 技巧 1：计算应付金额

```js
// 总金额 - 已付金额
SUM(订单明细.小计) - 已付金额
```

### 技巧 2：计算平均值

```js
// 先求和再除以数量
SUM(费用明细.金额) / COUNT(费用明细.控件自身)
```

### 技巧 3：百分比计算

```js
// 计算某项费用占总费用的比例
交通费 / SUM(交通费, 餐费, 住宿费) * 100
```

结果：交通费占比 XX%

### 技巧 4：条件求和（配合 SUMIF）

```js
// 只统计金额大于100的项
SUMIF(费用明细.控件自身, 费用明细.金额 > 100, 费用明细.金额)
```

## 七、与 AVERAGE 的区别

| 函数 | 作用 | 示例结果 |
|------|------|---------|
| SUM(10, 20, 30) | 求和 | 60 |
| AVERAGE(10, 20, 30) | 求平均 | 20 |

**记忆方法**：
- SUM = 总数（加法）
- AVERAGE = 平均数（加法后除以个数）

## 八、注意事项

### ⚠️ 明细表语法

```js
// ✅ 正确：使用 明细.字段名
SUM(订单明细.金额)

// ❌ 错误：不要忘记明细名称
SUM(金额)
```

### ⚠️ 避免重复计算

如果已经有【小计】字段，直接对小计求和：

```js
// ✅ 推荐
SUM(订单明细.小计)

// ❌ 不推荐（可能重复计算）
SUM(订单明细.数量 * 订单明细.单价)
```
