# 「「云之家」」计算公式之 DIVIDE 函数

## 一、函数作用

`DIVIDE` 函数用来**计算商值**，即第一个数依次除以后面的所有数：
- 支持多个参数，从第一个开始连除
- 支持高精度小数运算，避免浮点误差（如 0.3 ÷ 0.1 精确等于 3）
- 适用于计算单价、比率、人均等场景

---

## 二、语法格式

```
DIVIDE(被除数, 除数1, 除数2, ...除数N)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 被除数 | 第一个数字，作为被除数 | ✅ 必填 | DIVIDE(100, 5) |
| 除数1, 除数2... | 要除的数字，可以有多个 | ❌ 可选 | DIVIDE(100, 5, 2) |

### 返回值

- **正常情况**：返回被除数依次除以所有除数后的商
- **单参数**：返回该参数自身
- **除数为 0**：返回空字符串
- **非数字参数**：返回空字符串

---

## 三、实用示例

### 示例 1：基本除法

```js
DIVIDE(10, 2)              // 返回：5
DIVIDE(100, 5, 2)          // 返回：10（100 ÷ 5 ÷ 2）
DIVIDE(100, 3, 2)          // 返回：16.666666666666668（100 ÷ 3 ÷ 2）
```

### 示例 2：高精度小数运算

```js
DIVIDE(0.3, 0.1)           // 返回：3（精确）
DIVIDE(42.6, 3)            // 返回：14.2（精确）
```

### 示例 3：负数运算

```js
DIVIDE(-6, 2)              // 返回：-3
DIVIDE(-6, -2)             // 返回：3
```

### 示例 4：除数为 0

```js
DIVIDE(10, 0)              // 返回：""（空字符串）
DIVIDE(10, 0, 2)           // 返回：""（中间有 0）
DIVIDE(0, 5)               // 返回：0（被除数为 0 正常）
```

## 四、实际业务场景

### 场景 1：计算单价

```js
// 【单价】= 总价 ÷ 数量
DIVIDE(总价, 数量)
```

### 场景 2：计算人均

```js
// 【人均费用】= 总费用 ÷ 人数
DIVIDE(总费用, 参与人数)
```

### 场景 3：计算比率

```js
// 【完成率】= 已完成 ÷ 总任务 × 100
PRODUCT(DIVIDE(已完成数, 总任务数), 100)
```

### 场景 4：多级分摊

```js
// 【每人每天费用】= 总费用 ÷ 天数 ÷ 人数
DIVIDE(总费用, 天数, 人数)
```

## 五、常见问题

### ❓ 除数为 0 会怎样？

返回空字符串，不会报错或返回 Infinity：

```js
DIVIDE(100, 0)             // 返回：""
```

### ❓ 只有一个参数会怎样？

返回该参数自身：

```js
DIVIDE(10)                 // 返回：10
```

### ❓ 能和其它高精度函数搭配吗？

可以，组合使用时精度不会丢失：

```js
// 先乘后除，全程高精度
DIVIDE(PRODUCT(3, 14.2), 3)   // 返回：14.2（精确）
```

## 六、搭配使用技巧

### 技巧 1：配合 PRODUCT 求反向

```js
// 已知数量和单价，求总价
PRODUCT(数量, 单价)

// 已知总价和数量，求单价
DIVIDE(总价, 数量)
```

### 技巧 2：配合 ROUND 保留小数

```js
// 金额保留两位小数
ROUND(DIVIDE(总费用, 人数), 2)
```

### 技巧 3：配合 IF 防除零

```js
// 如果人数大于 0 才计算人均，否则返回 0
IF(人数 > 0, DIVIDE(总费用, 人数), 0)
```

## 七、与其它运算函数的区别

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| SUM(10, 5, 2) | 求和 | 10 + 5 + 2 | 17 |
| SUBTRACT(10, 5, 2) | 求差 | 10 - 5 - 2 | 3 |
| PRODUCT(10, 5, 2) | 求积 | 10 × 5 × 2 | 100 |
| DIVIDE(10, 5, 2) | 求商 | 10 ÷ 5 ÷ 2 | 1 |

---

## 八、注意事项

### ⚠️ 参数顺序很重要

```js
// DIVIDE 不是交换律，顺序影响结果
DIVIDE(100, 5, 2)          // 返回：10
DIVIDE(2, 100, 5)          // 返回：0.004
```

### ⚠️ 除数为 0 时返回空字符串

在进一步运算中注意处理空字符串的情况。
