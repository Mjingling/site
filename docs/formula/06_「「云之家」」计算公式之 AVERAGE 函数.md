# 「「云之家」」计算公式之 AVERAGE 函数

## 一、函数作用

`AVERAGE` 函数用来**计算平均值**，就像Excel中的平均数一样：
- 将所有数字加起来，再除以数字的个数
- 常用于计算平均分、平均销售额、平均工资等

---

## 二、语法格式

```
AVERAGE(参数1, 参数2, ...参数N)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 参数1, 参数2... | 要计算平均值的数字，可以是：<br>• 直接写数字<br>• 数字控件<br>• 金额控件<br>• 运算控件 | ✅ 至少1个 | AVERAGE(80, 90, 70) |

### 返回值

- **正常情况**：返回所有参数的平均值
- **特殊情况**：如果所有参数都为空，返回 **0**

---

## 三、实用示例

### 示例 1：计算固定数字的平均值

```js
AVERAGE(80, 90, 70)           // 返回：80 （因为 (80+90+70)/3 = 80）
AVERAGE(100, 200)             // 返回：150
AVERAGE(10, 20, 30, 40, 50)   // 返回：30
```

### 示例 2：计算控件的平均值

假设有【语文成绩】、【数学成绩】、【英语成绩】三个数字控件：

```js
AVERAGE(语文成绩, 数学成绩, 英语成绩)
```

### 示例 3：计算明细表中的平均值

假设有【学生成绩明细】，包含多行学生成绩：

| 学生姓名 | 成绩 |
|---------|-----|
| 张三    | 80  |
| 李四    | 90  |
| 王五    | 70  |

```js
// 自动计算所有学生的平均成绩
AVERAGE(学生成绩明细.成绩)
```

结果：**80** （所有行的成绩加起来除以行数）

### 示例 4：计算季度平均销售额

假设有【一月销售额】【二月销售额】【三月销售额】：

```js
AVERAGE(一月销售额, 二月销售额, 三月销售额)
```

## 五、常见问题

### ❓ 如果某个参数为空怎么办？

空值会被**忽略**，不参与计算。

```js
// 假设【数学成绩】为空
AVERAGE(语文成绩, 数学成绩, 英语成绩)
// 实际只计算：(语文成绩 + 英语成绩) / 2
```

**示例：**

| 语文 | 数学 | 英语 | 平均分 |
|------|------|------|-------|
| 80 | 90 | 70 | 80 (三门) |
| 80 | 空 | 70 | 75 (只算两门) |

### ❓ 所有参数都为空会怎样？

返回 **0**。

```js
AVERAGE("", "", "")   // 返回：0
```

### ❓ 能混合数字和控件吗？

可以！

```js
AVERAGE(100, 数学成绩, 英语成绩)  // ✅ 可以
```

### ❓ 明细表为空会怎样？

返回 **0**。

```js
AVERAGE(空明细表.成绩)   // 返回：0
```

## 六、搭配使用技巧

### 技巧 1：判断是否达标

```js
IF(AVERAGE(语文, 数学, 英语) >= 85, "优秀", "良好")
```

### 技巧 2：计算高于平均值的人数

先计算平均值，再用 COUNTIF 统计：

```js
// 第一步：计算平均分
AVERAGE(成绩明细.分数)

// 第二步：统计高于平均分的人数
COUNTIF(成绩明细.控件自身, 成绩明细.分数 > AVERAGE(成绩明细.分数))
```

### 技巧 3：计算加权平均（配合运算）

```js
// 语文占40%，数学占30%，英语占30%
(语文成绩 * 0.4 + 数学成绩 * 0.3 + 英语成绩 * 0.3)
```

## 七、与 SUM 的区别

| 函数 | 作用 | 示例结果 |
|------|------|---------|
| SUM(10, 20, 30) | 求和 | 60 |
| AVERAGE(10, 20, 30) | 求平均 | 20 |

**记忆方法**：
- SUM = 总数（Sum）
- AVERAGE = 平均数（Average）
