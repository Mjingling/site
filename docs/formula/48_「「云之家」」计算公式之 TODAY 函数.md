# 「「云之家」」计算公式之 TODAY 函数

## 一、函数作用

`TODAY` 函数用来**获取当前的日期**(不含时间部分),简单来说就是:
- 返回今天的日期,时间部分固定为 00:00:00
- 只包含年、月、日信息,不含时、分、秒
- 每次调用都会返回当天的日期

常用于计算天数差、判断日期、设置默认日期等场景。

---

## 二、语法格式

```
TODAY()
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 无 | 此函数不需要任何参数 | - | TODAY() |

### 返回值

- **正常情况**:返回当前日期(格式通常为 `YYYY-MM-DD 00:00:00` 或 `YYYY-MM-DD`)
- **特殊情况**:返回调用当天的日期,每天都会变化

---

## 三、实用示例

### 示例 1:基本用法

```js
TODAY()  // 返回:2023-10-15 00:00:00(示例日期)
```

**注意**:不同系统可能返回不同格式,但都表示今天的日期。

### 示例 2:计算距今天数

假设有【项目计划表】,计算距离今天还有多少天:

```js
// 计算截止日期距今天的天数
DAYS(截止日期, TODAY())
```

### 示例 3:判断是否过期

结合 IF 函数判断日期是否已过:

```js
// 判断证件是否过期
IF(TODAY() > 有效期, "已过期", "有效")
```

### 示例 4:设置默认日期

```js
// 【提交日期】字段的默认值
TODAY()
```

当用户创建表单时,自动填入今天的日期。

### 示例 5:计算年龄

结合 YEAR 函数计算年龄:

```js
// 计算年龄
YEAR(TODAY()) - YEAR(出生日期)
```

## 四、实际业务场景

### 场景 1:合同到期提醒

判断合同是否即将到期:

```js
// 【合同状态】的计算公式
IF(DAYS(合同到期日, TODAY()) <= 0, "已到期",
   IF(DAYS(合同到期日, TODAY()) <= 30, "即将到期", "正常"))
```

### 场景 2:库存保质期管理

判断产品是否过期:

```js
// 【库存状态】的计算公式
IF(TODAY() > ADDDAY(生产日期, 保质期天数), "已过期", "正常")
```

### 场景 3:员工入职天数

计算员工入职至今的天数:

```js
// 【入职天数】的计算公式
DAYS(TODAY(), 入职日期)
```

### 场景 4:销售目标进度

计算本月已过去的天数:

```js
// 【本月已过天数】的计算公式
DAY(TODAY())

// 【本月剩余天数】
DAYS(ADDMONTH(DATEFORMAT(TODAY(), "YYYY-MM-01"), 1), TODAY())
```

## 五、常见问题

### ❓ TODAY 和 NOW 有什么区别?

主要区别在于是否包含时间部分:

```js
TODAY()  // 返回:2023-10-15 00:00:00(不含具体时间)
NOW()    // 返回:2023-10-15 14:30:25(包含时分秒)
```

**使用场景:**
- **TODAY**:只需要日期的场景(如计算天数、判断日期、默认日期)
- **NOW**:需要精确到时分秒的场景(如记录提交时间、计算时长)

### ❓ TODAY 返回的时间部分是什么?

返回的时间部分固定为 00:00:00:

```js
TODAY()  // 返回:2023-10-15 00:00:00
```

这样设计是为了方便日期比较和计算天数。

### ❓ 每次调用 TODAY 都会变化吗?

是的!每天调用返回不同的日期:

```js
// 2023-10-15 调用
TODAY()  // 返回:2023-10-15 00:00:00

// 2023-10-16 调用
TODAY()  // 返回:2023-10-16 00:00:00
```

### ❓ 如何计算两个日期相差多少天?

使用 DAYS 函数:

```js
// 计算从过去某日期到今天的天数
DAYS(TODAY(), "2023-10-01")  // 返回:14(天)

// 计算从今天到未来某日期的天数
DAYS("2023-10-20", TODAY())  // 返回:5(天)
```

### ❓ 如何获取本月第一天?

可以结合 DATEFORMAT 函数:

```js
// 获取本月第一天
DATEFORMAT(TODAY(), "YYYY-MM-01")
// 返回:2023-10-01
```

## 六、搭配使用技巧

### 技巧 1:结合 DAYS 计算剩余天数

```js
// 计算距离截止日期还有多少天
DAYS(截止日期, TODAY())

// 带提示的剩余天数
CONCATENATE("还剩 ", DAYS(截止日期, TODAY()), " 天")
// 返回:"还剩 5 天"
```

### 技巧 2:结合 IF 判断日期状态

```js
// 判断是否过期
IF(TODAY() > 到期日期, "已过期", "未过期")

// 判断是否即将到期(30天内)
IF(TODAY() > 到期日期, "已过期",
   IF(DAYS(到期日期, TODAY()) <= 30, "即将到期", "正常"))
```

### 技巧 3:结合 ADDDAY 计算相对日期

```js
// 计算30天后的日期
ADDDAY(TODAY(), 30)

// 计算7天前的日期
ADDDAY(TODAY(), -7)

// 计算下周今天
ADDDAY(TODAY(), 7)
```

### 技巧 4:结合 YEAR/MONTH/DAY 提取日期部分

```js
// 获取今年
YEAR(TODAY())  // 返回:2023

// 获取本月
MONTH(TODAY())  // 返回:10

// 获取今天是几号
DAY(TODAY())  // 返回:15
```

### 技巧 5:结合 WEEKDAY 判断星期几

```js
// 判断今天是星期几
WEEKDAY(TODAY())  // 返回:1-7(1=周一, 7=周日)

// 判断今天是否为周末
IF(WEEKDAY(TODAY()) >= 6, "周末", "工作日")
```

## 七、相关函数对比

| 函数 | 作用 | 返回值示例 |
|------|------|-----------|
| **TODAY()** | 获取当前日期(不含时间) | 2023-10-15 00:00:00 |
| **NOW()** | 获取当前日期和时间 | 2023-10-15 14:30:25 |
| **YEAR(TODAY())** | 获取今年 | 2023 |
| **MONTH(TODAY())** | 获取本月 | 10 |
| **DAY(TODAY())** | 获取今天是几号 | 15 |
| **WEEKDAY(TODAY())** | 获取今天星期几 | 7(周日) |
| **ADDDAY(TODAY(), N)** | 获取N天后的日期 | 2023-10-20 |

**详细对比:**

```js
// 当前日期:2023-10-15

TODAY()                  // 返回:2023-10-15 00:00:00
NOW()                    // 返回:2023-10-15 14:30:25
YEAR(TODAY())            // 返回:2023
MONTH(TODAY())           // 返回:10
DAY(TODAY())             // 返回:15
WEEKDAY(TODAY())         // 返回:7(周日)
ADDDAY(TODAY(), 7)       // 返回:2023-10-22
DAYS("2023-10-20", TODAY()) // 返回:5(天)
```

## 八、注意事项

### ⚠️ TODAY 返回值每天变化

每天调用都返回当天的日期:

```js
// ❌ 错误理解:认为 TODAY() 会返回固定日期
创建日期 = TODAY()  // 每天打开表单都会更新

// ✅ 正确做法:使用日期控件存储固定日期
// 在【创建日期】控件的默认值中设置 TODAY()
// 提交后该值就固定了
```

### ⚠️ 时间部分固定为 00:00:00

```js
TODAY()  // 返回:2023-10-15 00:00:00
NOW()    // 返回:2023-10-15 14:30:25

// TODAY 没有具体时间,方便日期比较
TODAY() > "2023-10-14"  // true
TODAY() < "2023-10-16"  // true
```

### ⚠️ 与日期控件的区别

```js
// ✅ TODAY() - 公式字段
// 每天打开表单都会显示当前日期,值会变化

// ✅ 日期控件 - 固定值
// 一旦填写或设置默认值,就不会自动变化
```

### ⚠️ 时区问题

TODAY 返回的是服务器所在时区的日期:

```js
// 中国服务器(UTC+8)
// 2023-10-15 23:30 调用
TODAY()  // 返回:2023-10-15

// 美国服务器(UTC-5)
// 2023-10-15 23:30 调用
TODAY()  // 返回:2023-10-15

// 但如果是跨日时刻,可能不同
```

### ⚠️ 日期计算注意事项

计算天数时注意参数顺序:

```js
// ✅ 正确:结束日期在前,开始日期在后
DAYS("2023-10-20", TODAY())  // 返回:5(还剩5天)

// ⚠️ 注意:如果顺序反了,结果为负数
DAYS(TODAY(), "2023-10-20")  // 返回:-5
```
