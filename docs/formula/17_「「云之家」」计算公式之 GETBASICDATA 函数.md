# 「「云之家」」计算公式之 GETBASICDATA 函数

## 一、函数作用

`GETBASICDATA` 函数用来**从融合中心获取指定基础资料的数据**，主要用于：
- 根据基础资料编码远程查询基础资料信息
- 从融合中心获取物料、客户、供应商等基础资料数据
- 异步获取基础资料详细信息

常用于与ERP系统对接、物料管理、客户管理等需要远程查询基础资料的场景。

---

## 二、语法格式

```
GETBASICDATA(基础资料编码)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 基础资料编码 | 要查询的基础资料编码（字符串） | ✅ 必填 | "M001"、"C001" |

### 返回值

- **正常情况**：返回基础资料数据数组
- **特殊情况**：
  - 如果参数为空，返回空数组
  - 如果查询失败，返回空数组
  - 如果未找到匹配数据，返回空数组

**重要**：此函数是异步函数，需要等待结果返回。

---

## 三、实用示例

### 示例 1：根据编码查询物料

```
GETBASICDATA("M001")
返回：基础资料数组
```

### 示例 2：根据编码查询客户

```
GETBASICDATA("C001")
返回：客户信息数组
```

### 示例 3：使用基础资料控件的编码查询

```
GETBASICDATA(GET_PROPERTY(物料, "FNumber"))
返回：物料的完整信息数组
```

### 示例 4：提取返回数据的属性

```
GET_PROPERTY(GETBASICDATA("M001"), "0.FName")
返回：'苹果'
```

## 四、实际业务场景

### 场景 1：根据编码获取物料详情

```
CONCATENATE("物料名称：", GET_PROPERTY(GETBASICDATA(物料编码), "0.FName"))
返回：'物料名称：苹果'
```

### 场景 2：联动查询客户信息

```
CONCATENATE(
    "客户：", GET_PROPERTY(GETBASICDATA(客户编码), "0.FName"),
    "，联系人：", GET_PROPERTY(GETBASICDATA(客户编码), "0.FContact")
)
返回：'客户：张三公司，联系人：李四'
```

### 场景 3：物料库存查询

```
CONCATENATE("当前库存：", GET_PROPERTY(GETBASICDATA("M001"), "0.FStockQty"), " 件")
返回：'当前库存：100 件'
```

### 场景 4：数据验证

```
IF(LEN(GETBASICDATA(输入的物料编码)) > 0, "物料编码有效", "物料编码不存在")
```

### 场景 5：价格查询

```
CONCATENATE("单价：", GET_PROPERTY(GETBASICDATA(物料编码), "0.FPrice"), " 元")
返回：'单价：10.5 元'
```

## 五、常见问题

### ❓ 为什么返回的是数组？

因为基础资料编码可能对应多条数据，函数统一返回数组格式：

```js
GETBASICDATA("M001")
// 返回：[{ FNumber: "M001", FName: "苹果", ... }]
```

即使只有一条数据，也是数组格式，需要通过索引访问。

### ❓ 如何获取返回数据的某个属性？

结合 `GET_PROPERTY` 或直接使用数组索引：

```js
// 方式1：使用 GET_PROPERTY
GET_PROPERTY(GETBASICDATA("M001"), "0.FName")

// 方式2：直接使用数组索引（需要在表达式环境中）
GETBASICDATA("M001")[0].FName
```

### ❓ 参数必须是字符串吗？

是的，参数只能是字符串格式的基础资料编码：

```js
// ✅ 正确：字符串编码
GETBASICDATA("M001")

// ❌ 错误：数字
GETBASICDATA(001)

// ❌ 错误：对象
GETBASICDATA({ code: "M001" })
```

### ❓ 函数是同步还是异步？

**此函数是异步函数**，会向融合中心发送远程请求，需要等待结果返回。在公式计算时会自动处理异步逻辑。

### ❓ 为什么返回空数组？

可能的原因：
1. 基础资料编码不存在
2. 网络请求失败
3. 融合中心未配置该基础资料
4. 参数为空或格式错误

## 六、搭配使用技巧

### 技巧 1：结合 GET_PROPERTY 提取属性

```
GET_PROPERTY(GETBASICDATA("M001"), "0.FName")
返回：'苹果'
```

### 技巧 2：结合 IF 判断数据是否存在

```
IF(LEN(GETBASICDATA(物料编码)) > 0, 
    GET_PROPERTY(GETBASICDATA(物料编码), "0.FName"),
    "未找到物料")
```

### 技巧 3：与基础资料控件联动

```
GET_PROPERTY(GETBASICDATA(GET_PROPERTY(物料控件, "FNumber")), "0.FSpec")
返回：物料规格
```

### 技巧 4：批量查询

注意：每次调用都会发送一次请求，避免频繁调用

### 技巧 5：数据填充

```
GET_PROPERTY(GETBASICDATA(客户编码), "0.FName")
GET_PROPERTY(GETBASICDATA(客户编码), "0.FContact")
GET_PROPERTY(GETBASICDATA(客户编码), "0.FPhone")
```

## 七、注意事项

1. **异步性质**：此函数是异步函数，会发送远程请求，需要等待响应
2. **参数类型**：参数必须是字符串类型的基础资料编码
3. **返回格式**：返回值始终是数组，即使只有一条数据
4. **网络依赖**：依赖网络和融合中心，确保网络畅通
5. **性能考虑**：每次调用都会发送请求，避免频繁调用
6. **错误处理**：查询失败或无数据时返回空数组，不会报错

## 九、与 GET_PROPERTY 的区别

| 函数 | 数据来源 | 参数 | 返回值 | 用途 |
|------|----------|------|--------|------|
| GETBASICDATA | 融合中心（远程） | 字符串编码 | 数组 | 查询基础资料详情 |
| GET_PROPERTY | 本地数据（对象/数组） | 对象和属性路径 | 属性值 | 提取本地对象属性 |

```js
// GETBASICDATA：远程查询
GETBASICDATA("M001")  // 从融合中心查询编码为 M001 的基础资料

// GET_PROPERTY：本地提取
GET_PROPERTY(物料控件, "FNumber")  // 从本地控件数据中提取编码
```
