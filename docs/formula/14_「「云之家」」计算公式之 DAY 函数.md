# 「「云之家」」计算公式之 DAY 函数

## 一、函数作用

`DAY` 函数用来**从日期中提取日(号)部分**,简单来说就是:
- 获取日期中的天数(1-31)
- 提取某月的第几天
- 判断是否为月初或月末

常用于日期分析、账单日判断、生日提醒等场景。

---

## 二、语法格式

```
DAY(日期)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期 | 要提取日部分的日期,可以是日期控件、日期字符串、时间戳 | ✅ 必填 | DAY("2023-05-20") |

### 返回值

- **正常情况**: 返回1-31之间的数字(表示当月的第几天)
- **特殊情况**: 如果日期参数无效,返回**空**

---

## 三、实用示例

### 示例 1: 基本用法

```js
DAY("2023-05-20")           // 返回: 20
DAY("2023-06-15")           // 返回: 15
DAY("2023-01-01")           // 返回: 1
DAY("2023-12-31")           // 返回: 31
```

### 示例 2: 不同日期格式

```js
DAY("2023-05-20")           // 返回: 20 (YYYY-MM-DD格式)
DAY("2023/05/20")           // 返回: 20 (YYYY/MM/DD格式)
DAY("2023-5-8")             // 返回: 8 (简写格式)
DAY(1684512000000)          // 返回: 20 (时间戳)
```

### 示例 3: 账单日期判断

假设有【还款记录】表,包含【还款日期】字段:

```js
DAY(还款日期)
```

### 示例 4: 判断是否为月初或月末

```js
// 判断是否为月初(前3天)
DAY("2023-05-01")           // 返回: 1 (月初第1天)
DAY("2023-05-02")           // 返回: 2 (月初第2天)
DAY("2023-05-03")           // 返回: 3 (月初第3天)

// 判断是否为月末(后3天)
DAY("2023-05-29")           // 返回: 29
DAY("2023-05-30")           // 返回: 30
DAY("2023-05-31")           // 返回: 31 (月末最后一天)
```

## 四、实际业务场景

### 场景 1: 账单日提醒

在信用卡管理中,判断是否到还款日:

```js
// 【是否到还款日】的计算公式
DAY(TODAY()) == 还款日

// 【是否为每月5号】
DAY(TODAY()) == 5
```

**示例:**
- 还款日设置为每月20号
- 今天是2023-05-20 → DAY(TODAY()) == 20 → **true**(到还款日)
- 今天是2023-05-19 → DAY(TODAY()) == 19 → **false**(未到还款日)

### 场景 2: 生日月份提醒

在员工管理中,提取生日日期:

```js
// 【生日日期】的计算公式
DAY(员工生日)
```

### 场景 3: 考勤统计

统计某日期是当月第几天:

```js
// 【当月第N天】的计算公式
CONCATENATE("当月第", DAY(考勤日期), "天")
```

**示例:**
- 考勤日期: 2023-05-20 → 显示: **"当月第20天"**

### 场景 4: 月初月末判断

判断订单是否在月初下单:

```js
// 【是否月初订单】的计算公式
IF(DAY(下单日期) <= 3, "月初订单", "非月初订单")

// 【是否月末订单】的计算公式
IF(DAY(下单日期) >= 28, "月末订单", "非月末订单")
```

## 五、常见问题

### ❓ 如果日期参数为空会怎样?

函数返回**空**,不会报错。

```js
DAY("")                     // 返回: 空
DAY(空控件)                  // 返回: 空
```

### ❓ 返回值的范围是什么?

返回值范围是**1-31**,取决于该月有多少天:
- 31天的月份(1、3、5、7、8、10、12月): 1-31
- 30天的月份(4、6、9、11月): 1-30
- 2月平年: 1-28
- 2月闰年: 1-29

```js
DAY("2023-01-31")           // 返回: 31 (1月有31天)
DAY("2023-04-30")           // 返回: 30 (4月有30天)
DAY("2023-02-28")           // 返回: 28 (2023年2月有28天)
DAY("2024-02-29")           // 返回: 29 (2024年闰年2月有29天)
```

### ❓ 可以使用时间戳吗?

可以,时间戳(毫秒)会自动转换为日期。

```js
DAY(1684512000000)          // 返回: 20
DAY(NOW())                  // 返回: 当前日期的日部分
DAY(TODAY())                // 返回: 今天是几号
```

### ❓ 带时间的日期会影响结果吗?

不会。DAY函数只提取日期部分,忽略时间。

```js
DAY("2023-05-20 00:00:00")  // 返回: 20
DAY("2023-05-20 12:30:45")  // 返回: 20
DAY("2023-05-20 23:59:59")  // 返回: 20
```

### ❓ 如何判断是否为月初?

可以通过判断DAY的返回值是否小于等于某个数字:

```js
// 判断是否为月初(前5天)
DAY(日期) <= 5

// 判断是否为月初第一天
DAY(日期) == 1
```

### ❓ 如何判断是否为月末?

由于每月天数不同,判断月末需要结合其他函数:

```js
// 简单判断(适用于大部分情况)
DAY(日期) >= 28

// 精确判断(需要比较是否为该月最后一天)
// 方法: 判断当前日期加1天后是否跨月
MONTH(日期) != MONTH(ADDDAY(日期, 1))
```

## 六、搭配使用技巧

### 技巧 1: 结合 TODAY 获取今天是几号

```js
// 获取今天是几号
DAY(TODAY())

// 判断今天是否为月初
DAY(TODAY()) <= 5
```

### 技巧 2: 结合 IF 函数条件判断

```js
// 判断还款日
IF(DAY(TODAY()) == 20, "今天是还款日", "今天不是还款日")

// 判断账单周期
IF(DAY(日期) <= 15, "上半月", "下半月")
```

### 技巧 3: 结合 CONCATENATE 生成文本

```js
// 生成日期描述
CONCATENATE(MONTH(日期), "月", DAY(日期), "日")

// 生成账单日说明
CONCATENATE("每月", DAY(账单日期), "号还款")
```

### 技巧 4: 结合 MONTH 和 YEAR 完整分析日期

```js
// 判断是否为同一天
YEAR(日期1) == YEAR(日期2) && MONTH(日期1) == MONTH(日期2) && DAY(日期1) == DAY(日期2)

// 提取生日(忽略年份)
CONCATENATE(MONTH(生日), "月", DAY(生日), "日")
```

### 技巧 5: 结合 ADDDAY 计算相对日期

```js
// 计算月初到今天过了多少天
DAY(TODAY()) - 1

// 判断距离月初还有几天
DAY(日期)
```

## 七、与其他日期函数的区别

| 函数 | 作用 | 返回值 | 示例 |
|------|------|-------|------|
| DAY(日期) | 提取日(号)部分 | 1-31 | DAY("2023-05-20") = 20 |
| MONTH(日期) | 提取月份部分 | 1-12 | MONTH("2023-05-20") = 5 |
| YEAR(日期) | 提取年份部分 | 四位年份 | YEAR("2023-05-20") = 2023 |
| WEEKDAY(日期) | 提取星期几 | 0-6 | WEEKDAY("2023-05-20") = 6 |
| DATEFORMAT(日期, "DD") | 格式化日期为文本 | 文本 | DATEFORMAT("2023-05-20", "DD") = "20" |

## 八、注意事项

### ⚠️ 返回值是数字类型

DAY 返回的是**数字**,不是文本:

```js
// ✅ 正确: 返回数字20
DAY("2023-05-20")                                 // 返回: 20

// 如需文本格式,使用DATEFORMAT
DATEFORMAT("2023-05-20", "DD")                    // 返回: "20"
```

### ⚠️ 判断月末需谨慎

不同月份天数不同,判断月末时需要注意:

```js
// ⭕ 不够精确
DAY(日期) >= 28                                   // 可能将28-30号也判断为月末

// ✅ 更精确的判断
MONTH(日期) != MONTH(ADDDAY(日期, 1))             // 判断明天是否跨月
```

### ⚠️ 时间戳单位是毫秒

如果使用时间戳,确保单位是毫秒(13位):

```js
// ✅ 正确: 毫秒时间戳
DAY(1684512000000)                                // 正确

// ❌ 错误: 秒级时间戳(10位)
DAY(1684512000)                                   // 错误!需要乘以1000
```

### ⚠️ 与日期控件结合使用

当使用日期控件时,建议先判断是否为空:

```js
// ✅ 推荐: 先判断再提取
IF(ISNULL(日期控件), 0, DAY(日期控件))

// ⭕ 可以但不推荐: 直接使用
DAY(日期控件)                                     // 为空时返回空
```
