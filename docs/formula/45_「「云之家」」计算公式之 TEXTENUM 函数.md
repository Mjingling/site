# 「「云之家」」计算公式之 TEXTENUM 函数

## 一、函数作用

`TEXTENUM` 函数用来**从枚举控件数据中提取文本信息**，支持：
- 提取枚举选项的名称
- 提取枚举选项的值

常用于在公式中获取枚举控件的显示值或实际值。

---

## ⚠️ 使用限制

- **仅适用于枚举控件（enumWidget）**，不适用于单选框（Ra_）、多选框（Cb_）、下拉框
- 枚举控件返回值格式为 `[{name, value}]`，单选框/多选框返回字符串，不兼容
- **多选时只返回第一个**选项

---

## 二、语法格式


TEXTENUM(枚举数组, 属性名)


### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 枚举数组 | 枚举控件的数据（数组格式） | ✅ 必填 | 枚举控件 |
| 属性名 | 要提取的属性，支持 "name" 或 "value" | ✅ 必填 | "name"、"value" |

### 返回值

- **正常情况**：返回枚举选项的名称或值
- **特殊情况**：
  - 如果参数为空，返回空字符串
  - 如果属性名为空，返回空字符串
  - 如果枚举数组为空，返回空字符串

---

## 三、实用示例

### 示例 1：获取枚举选项名称

TEXTENUM(优先级, 'name')
返回：'高'

### 示例 2：获取枚举选项值

TEXTENUM(状态, 'value')
返回：'2'

### 示例 3：处理空值情况

TEXTENUM()
返回：''（无参数）

TEXTENUM(null, 'name')
返回：''（枚举为空）

TEXTENUM(优先级, null)
返回：''（属性名为空）

TEXTENUM([], 'name')
返回：''（空数组）

### 示例 4：枚举控件支持多选

TEXTENUM(标签, 'name')
返回：'重要'

TEXTENUM(标签, 'value')
返回：'1'

## 四、实际业务场景

### 场景 1：在文本中显示状态


"当前状态：" + TEXTENUM(状态, 'name')


### 场景 2：根据枚举值判断


IF(TEXTENUM(状态, 'value') == '2', 
    "进度50%", 
    "进度0%")


### 场景 3：状态数据传递


POST('/api/update', {
    status: TEXTENUM(状态, 'value'),
    statusName: TEXTENUM(状态, 'name')
})


### 场景 4：优先级判断


IF(TEXTENUM(优先级, 'value') == '3',  // 高优先级
    DATEFORMAT(ADDDAY(NOW(), 1), 'yyyy-MM-dd'),  // 1天内完成
    DATEFORMAT(ADDDAY(NOW(), 3), 'yyyy-MM-dd'))  // 3天内完成


### 场景 5：类型映射


"申请类型：" + TEXTENUM(申请类型, 'name') + 
IF(TEXTENUM(申请类型, 'value') == '1', 
    "（需要部门审批）",
    "（需要财务审批）")

## 五、常见问题

### ❓ name 和 value 有什么区别？

- `name`：枚举选项的显示名称，用户在界面上看到的文本
- `value`：枚举选项的实际值，用于数据存储和判断


状态选项：{ name: '进行中', value: '2' }

TEXTENUM(状态, 'name')    // 返回：'进行中'（显示名称）
TEXTENUM(状态, 'value')   // 返回：'2'（实际值）


### ❓ 如果枚举控件选择了多个选项怎么办？

函数只返回第一个选项的信息。


TEXTENUM(多选框, 'name')   // 返回：'选项A'（只取第一个）


如果需要获取所有选项，建议直接使用控件值或使用数组函数。

### ❓ 为什么有时候取不到值？

可能的原因：
1. 枚举控件没有选择值
2. 属性名填写错误（必须是 "name" 或 "value"）
3. 枚举数据格式异常


TEXTENUM(状态, 'name')    // ✅
TEXTENUM(状态, 'label')   // ❌ 错误的属性名


### ❓ TEXTENUM 和直接使用控件值有什么区别？

- `TEXTENUM` 可以明确获取 name 或 value
- 直接使用控件值可能返回 name（取决于控件配置）


TEXTENUM(状态, 'name')    // 明确返回 name
TEXTENUM(状态, 'value')   // 明确返回 value
状态                      // 可能返回 name 或整个对象


### ❓ 能否获取枚举的其他信息？

如果枚举数据包含其他字段，可以使用 GET_PROPERTY 访问：


GET_PROPERTY(枚举控件, '0.description')   // 获取描述

## 六、搭配使用技巧

### 技巧 1：结合 IF 函数进行状态判断


IF(TEXTENUM(审批状态, 'value') == 'approved',
    "已通过",
    "待审批")


### 技巧 2：拼接枚举信息


"优先级：" + TEXTENUM(优先级, 'name') + 
"（级别：" + TEXTENUM(优先级, 'value') + "）"


### 技巧 3：枚举值映射


IF(TEXTENUM(状态, 'value') == '1', "🔴", 
IF(TEXTENUM(状态, 'value') == '2', "🟡", "🟢"))


### 技巧 4：与数值计算结合


SUM(基础分数) * 
IF(TEXTENUM(优先级, 'value') == '3', 1.5,
IF(TEXTENUM(优先级, 'value') == '2', 1.2, 1.0))

## 七、注意事项

1. **单值返回**：只返回第一个选项的信息，不支持多选项
2. **属性名限制**：只支持 "name" 和 "value" 两个属性
3. **数据格式**：枚举控件存储的是数组，即使只选择了一个选项
4. **类型一致**：value 可能是字符串或数字，取决于控件配置
5. **空值处理**：各种异常情况都返回空字符串，不会报错

---

## 八、枚举控件说明

TEXTENUM 适用的控件为**枚举控件**（enumWidget），该控件的值格式为对象数组：

```json
[
    { "name": "高", "value": "3" },
    { "name": "紧急", "value": "2" }
]
```

> **注意**：TEXTENUM 不适用于单选框（Ra_）、多选框（Cb_）等控件，这些控件的值格式为字符串或字符串数组，不符合 TEXTENUM 的对象数组要求。需要获取单选框/多选框的值直接引用该控件即可。
