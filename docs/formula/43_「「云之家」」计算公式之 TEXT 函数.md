# 「「云之家」」计算公式之 TEXT 函数

## 一、函数作用

`TEXT` 函数用来**将值转换为文本字符串**：
- 将数字、布尔等类型转换为文本
- 方便进行文本拼接和显示

> **注意**：TEXT 只做简单的 `String()` 转换，**不支持格式化参数**（如 "0.00"、"yyyy-mm-dd" 等），这些用法实际不会生效。

---

## ⚠️ 使用限制

- **不支持格式化**：`TEXT(123.456, "0.00")` 第二个参数被忽略，返回 `"123.456"`
- **格式化日期请用 DATEFORMAT**

---

## 二、语法格式

```
TEXT(值)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 值 | 要转换为文本的值 | ✅ 必填 | 123, "abc" |

### 返回值

- **非空值**：返回对应的字符串表示
- **空值（null/undefined）**：返回空字符串 `""`

---

## 三、实用示例

### 示例 1：基本转换

```js
TEXT(123)        // 返回: "123"
TEXT(45.67)      // 返回: "45.67"
TEXT(-89)        // 返回: "-89"
TEXT("hello")    // 返回: "hello"
```

### 示例 2：空值处理

```js
TEXT("")         // 返回: ""
TEXT(null)       // 返回: ""
```

### 示例 3：0 和布尔值

```js
TEXT(0)          // 返回: "0"
TEXT(false)      // 返回: "false"
TEXT(true)       // 返回: "true"
```

---

## 四、实际业务场景

### 场景 1：数字拼接为文本

```js
"订单金额：" + TEXT(金额) + " 元"
// 返回: "订单金额：1000 元"
```

### 场景 2：处理空值

TEXT 可直接转换数字 0，无需特殊处理：

```js
TEXT(金额)  // 金额为 0 时返回 "0"
```

---

## 五、常见问题

### ❓ TEXT(0) 返回什么？

返回 `"0"`。TEXT 函数会正确将 0 转换为字符串 "0"。

### ❓ 能使用格式化参数吗？

不能。TEXT 不支持任何格式化参数，只做简单的字符串转换。

```js
TEXT(123.456, "0.00")    // 第二个参数会被忽略，返回: "123.456"
TEXT(0.85, "0%")         // 返回: "0.85"
```

### ❓ TEXT 转换后还能参与运算吗？

不能，转换后是文本类型：

```js
TEXT(100) + TEXT(200)   // 返回: "100200"（文本拼接），不是 300
```

## 六、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **TEXT** | 转文本 | TEXT(123) | "123" |
| **VALUE** | 转数字 | VALUE("123") | 123 |
| **CONCATENATE** | 拼接文本 | CONCATENATE("A", "B") | "AB" |
| **DATEFORMAT** | 日期格式化 | DATEFORMAT(NOW(), "yyyy-MM-dd") | "2024-03-15" |
