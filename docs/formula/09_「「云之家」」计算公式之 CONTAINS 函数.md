# 「「云之家」」计算公式之 CONTAINS 函数

## 一、函数作用

`CONTAINS` 函数用来**检查是否包含**，简单来说就是：
- 检查文本中是否包含某个子文本
- 检查数组中是否包含某个元素
- 返回 true（包含）或 false（不包含）

常用于文本搜索、关键词匹配、数据筛选等场景。

---

## ⚠️ 使用限制

- **搜索值必须为字符串**：`CONTAINS(arr, 3)` 不可用，数字会直接返回 false
- **数组元素也必须是字符串**：不支持数字元素的数组搜索
- **区分大小写**

---

## 二、语法格式

```
CONTAINS(文本或数组, 子文本或元素)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 文本或数组 | 被检查的对象，可以是：<br>• 文本字符串<br>• 数组<br>• 文本控件 | ✅ 必填 | CONTAINS("苹果手机", "手机") |
| 子文本或元素 | 要查找的内容 | ✅ 必填 | "手机" |

### 返回值

- **包含时**：返回 **true**
- **不包含时**：返回 **false**

---

## 三、实用示例

### 示例 1：检查文本包含

```js
CONTAINS("iPhone手机", "手机")       // 返回：true
CONTAINS("运动鞋", "衣服")           // 返回：false
CONTAINS("云之家办公平台", "办公")    // 返回：true
CONTAINS("Hello World", "World")    // 返回：true
CONTAINS("Hello World", "world")    // 返回：false（区分大小写）
```

### 示例 2：检查数组包含

```js
CONTAINS(["苹果", "香蕉", "橙子"], "香蕉")   // 返回：true
CONTAINS(["苹果", "香蕉", "橙子"], "葡萄")   // 返回：false
```

> **注意**：搜索值必须为字符串类型，不支持数字搜索。数组搜索也只支持字符串元素。

### 示例 3：商品分类

假设有【商品列表】：

| 商品名称 | 类别 |
|---------|------|
| iPhone手机 | 电子产品 |
| 运动鞋 | 服装鞋帽 |
| 笔记本电脑 | 电子产品 |
| 苹果MacBook | 电子产品 |

```js
// 检查商品名称是否包含"手机"
CONTAINS(商品名称, "手机")
// iPhone手机 -> true
// 运动鞋 -> false

// 检查商品名称是否包含"电脑"
CONTAINS(商品名称, "电脑")
// 笔记本电脑 -> true
```

### 示例 4：多关键词判断

```js
// 判断是否为电子产品（包含手机、电脑或平板）
CONTAINS(商品名称, "手机") || CONTAINS(商品名称, "电脑") || CONTAINS(商品名称, "平板")
```

### 示例 5：权限检查

```js
// 检查权限列表中是否包含管理员权限
CONTAINS(权限列表, "admin")  // 返回：true 或 false

// 检查用户角色是否包含"管理员"
CONTAINS(用户角色, "管理员")
```

## 四、实际业务场景

### 场景 1：商品筛选

根据关键词筛选商品：

```js
// 【是否为电子产品】
CONTAINS(商品名称, "手机") || CONTAINS(商品名称, "电脑") || CONTAINS(商品名称, "平板")

// 【是否包含品牌名】
CONTAINS(商品名称, "Apple") || CONTAINS(商品名称, "苹果")

// 【是否为促销商品】
CONTAINS(商品标签, "促销")
```

### 场景 2：客户分类

根据客户备注分类客户：

```js
// 【是否为VIP客户】
CONTAINS(客户备注, "VIP") || CONTAINS(客户备注, "重要客户")

// 【是否需要跟进】
CONTAINS(备注, "待跟进") || CONTAINS(备注, "需联系")
```

### 场景 3：订单状态判断

```js
// 【订单是否异常】
CONTAINS(订单状态, "退款") || CONTAINS(订单状态, "投诉") || CONTAINS(订单状态, "异常")

// 【是否已完成】
CONTAINS(订单状态, "已完成") || CONTAINS(订单状态, "已发货")
```

### 场景 4：地址筛选

```js
// 【是否为重点区域】
CONTAINS(收货地址, "北京") || CONTAINS(收货地址, "上海") || CONTAINS(收货地址, "深圳")

// 【是否需要特殊配送】
CONTAINS(收货地址, "偏远") || CONTAINS(收货地址, "山区")
```

### 场景 5：文件类型判断

```js
// 【是否为图片文件】
CONTAINS(文件名, ".jpg") || CONTAINS(文件名, ".png") || CONTAINS(文件名, ".gif")

// 【是否为文档文件】
CONTAINS(文件名, ".doc") || CONTAINS(文件名, ".pdf") || CONTAINS(文件名, ".xls")
```

## 五、常见问题

### CONTAINS 区分大小写吗？

**是的**，CONTAINS 区分大小写。

```js
CONTAINS("Hello World", "World")   // 返回：true
CONTAINS("Hello World", "world")   // 返回：false
CONTAINS("iPhone", "iphone")       // 返回：false
```

如果需要不区分大小写的匹配，可以先转换为小写：

```js
// 使用 TEXT 函数转换为小写后再比较（如果有这个函数）
// 或者同时判断两种情况
CONTAINS(商品名称, "iPhone") || CONTAINS(商品名称, "iphone")
```

### 空值会怎样？

如果被检查的文本为空，返回 **false**。

```js
CONTAINS("", "test")      // 返回：false
CONTAINS(空控件, "test")  // 返回：false
```

### 能检查多个关键词吗？

可以使用逻辑运算符 `||`（或）和 `&&`（且）：

```js
// 包含"手机"或"电脑"
CONTAINS(商品名称, "手机") || CONTAINS(商品名称, "电脑")

// 同时包含"苹果"和"手机"
CONTAINS(商品名称, "苹果") && CONTAINS(商品名称, "手机")
```

### CONTAINS 能匹配部分文本吗？

可以，CONTAINS 会在整个字符串中查找子文本：

```js
CONTAINS("我爱云之家", "云之家")    // 返回：true
CONTAINS("手机壳", "手机")          // 返回：true
CONTAINS("iPhone14手机", "手机")   // 返回：true
```

### 如何检查不包含？

使用 `!`（非）运算符或 NOT_CONTAINS 函数：

```js
// 方法1：使用 ! 运算符
!CONTAINS(商品名称, "手机")

// 方法2：使用 NOT_CONTAINS 函数
NOT_CONTAINS(商品名称, "手机")
```

## 六、搭配使用技巧

### 技巧 1：结合 IF 进行分类

```js
// 根据商品名称自动分类
IF(CONTAINS(商品名称, "手机"), "数码产品",
   IF(CONTAINS(商品名称, "鞋"), "服装鞋帽", "其他"))
```

### 技巧 2：多条件筛选

```js
// 高价值电子产品：包含特定关键词且价格>5000
(CONTAINS(商品名称, "手机") || CONTAINS(商品名称, "电脑")) && 商品价格 > 5000
```

### 技巧 3：设置筛选条件

```js
// 【是否显示】：只显示包含"促销"的商品
CONTAINS(商品标签, "促销")

// 在 COUNTIF 中使用
COUNTIF(商品明细.控件自身, CONTAINS(商品明细.商品名称, "手机"))
```

### 技巧 4：组合判断

```js
// 判断是否为苹果产品
CONTAINS(商品名称, "iPhone") ||
CONTAINS(商品名称, "iPad") ||
CONTAINS(商品名称, "MacBook") ||
CONTAINS(商品名称, "Apple")
```

### 技巧 5：标签匹配

```js
// 检查标签数组中是否包含"新品"
CONTAINS(商品标签数组, "新品")

// 检查分类列表中是否包含"热销"
CONTAINS(分类列表, "热销")
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **CONTAINS** | 检查是否包含 | CONTAINS("iPhone手机", "手机") | true |
| **NOT_CONTAINS** | 检查是否不包含 | NOT_CONTAINS("iPhone手机", "电脑") | true |
| **MATCH** | 正则匹配 | MATCH("13812345678", "^138") | true |
| **FIND** | 提取文本 | FIND("ID:001", "ID:", "") | "001" |

**详细对比**：

```js
// CONTAINS：简单包含判断
CONTAINS("苹果手机", "手机")  // 返回：true

// NOT_CONTAINS：不包含判断
NOT_CONTAINS("苹果手机", "电脑")  // 返回：true

// MATCH：正则表达式匹配（更强大但复杂）
MATCH("13812345678", "^1[3-9]\\d{9}$")  // 返回：true（手机号格式验证）

// FIND：提取文本片段
FIND("价格:100元", "价格:", "元")  // 返回："100"
```

**使用建议**：
- **简单包含判断**：用 CONTAINS
- **排除某些内容**：用 NOT_CONTAINS
- **复杂模式匹配**：用 MATCH
- **提取文本**：用 FIND

## 八、常见应用模式

### 模式 1：关键词高亮/标记

```js
// 标记包含关键词的记录
IF(CONTAINS(商品名称, "促销"), "🔥 " + 商品名称, 商品名称)
```

### 模式 2：智能分类

```js
// 根据多个关键词自动分类
IF(CONTAINS(商品名称, "手机") || CONTAINS(商品名称, "平板"), "移动设备",
   IF(CONTAINS(商品名称, "电脑") || CONTAINS(商品名称, "笔记本"), "电脑",
      IF(CONTAINS(商品名称, "鞋") || CONTAINS(商品名称, "衣服"), "服装", "其他")))
```

### 模式 3：数据验证

```js
// 验证备注是否包含必填关键词
IF(CONTAINS(备注, "已确认"), "✅", "❌ 请在备注中添加'已确认'")
```
