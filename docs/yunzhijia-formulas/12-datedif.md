# 「「云之家」」计算公式之 DATEDIF 函数

## 一、函数作用

`DATEDIF` 函数用来**计算两个日期之间的差值**，简单来说就是：
- 可以按年、月、日、时、分、秒等不同单位计算
- 常用于计算工龄、合同剩余期限、项目耗时等

---

## 二、语法格式

```
DATEDIF(开始日期, 结束日期, 单位)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 开始日期 | 起始日期，可以是日期控件、日期字符串、时间戳 | ✅ 必填 | DATEDIF("2020-01-01", "2023-01-01", "y") |
| 结束日期 | 结束日期，可以是日期控件、日期字符串、时间戳 | ✅ 必填 | DATEDIF("2020-01-01", "2023-01-01", "y") |
| 单位 | 计算单位，默认为"d"（天） | ❌ 可选 | 见下表 |

**单位参数说明：**

| 单位 | 说明 | 示例 |
|------|------|------|
| y | 年 | DATEDIF("2020-01-01", "2023-01-01", "y") = 3 |
| M | 月 | DATEDIF("2023-01-01", "2023-04-01", "M") = 3 |
| d | 天（默认） | DATEDIF("2023-01-01", "2023-01-08", "d") = 7 |
| h | 小时 | DATEDIF("2023-01-01 00:00", "2023-01-01 03:00", "h") = 3 |
| m | 分钟 | DATEDIF("2023-01-01 00:00", "2023-01-01 00:30", "m") = 30 |
| s | 秒 | DATEDIF("2023-01-01 00:00:00", "2023-01-01 00:00:45", "s") = 45 |

### 返回值

- **正常情况**：返回两个日期之间的差值（数字）
- **特殊情况**：如果日期参数无效，返回**空**

---

## 三、实用示例

### 示例 1：基本用法

```js
// 计算天数差
DATEDIF("2023-01-01", "2023-01-08", "d")      // 返回：7

// 计算月数差
DATEDIF("2023-01-01", "2023-04-01", "M")      // 返回：3

// 计算年数差
DATEDIF("2020-01-01", "2023-01-01", "y")      // 返回：3

// 默认为天数
DATEDIF("2023-01-01", "2023-01-08")           // 返回：7
```

### 示例 2：计算员工工龄

假设有【员工档案】表，包含【入职日期】：

```js
DATEDIF(入职日期, TODAY(), "y")
```

### 示例 3：计算请假天数

假设有【请假申请】表：

```js
DATEDIF(开始日期, 结束日期, "d")
```

### 示例 4：计算小时差

```js
// 计算工作时长（小时）
DATEDIF("2023-06-01 09:00", "2023-06-01 17:00", "h")  // 返回：8

// 计算加班时长
DATEDIF("2023-06-01 18:00", "2023-06-01 22:00", "h")  // 返回：4
```

## 四、实际业务场景

### 场景 1：员工工龄计算

在人事管理中，计算员工工作年限：

```js
// 【工作年限】的计算公式
DATEDIF(入职日期, TODAY(), "y")

// 【工作天数】的计算公式
DATEDIF(入职日期, TODAY(), "d")

// 【工作月数】的计算公式
DATEDIF(入职日期, TODAY(), "M")
```

### 场景 2：合同剩余期限

计算合同还有多少天到期：

```js
// 【剩余天数】的计算公式
DATEDIF(TODAY(), 合同到期日, "d")
```

### 场景 3：项目耗时统计

```js
// 【项目耗时（天）】
DATEDIF(项目开始日期, 项目结束日期, "d")

// 【项目耗时（月）】
DATEDIF(项目开始日期, 项目结束日期, "M")
```

### 场景 4：年龄计算

```js
// 【员工年龄】的计算公式
DATEDIF(出生日期, TODAY(), "y")
```

## 五、常见问题

### ❓ 如果日期参数为空会怎样？

如果日期控件没有填写，函数返回**空**，不会报错。

```js
DATEDIF("", "2023-01-01", "d")        // 返回：0
DATEDIF("2023-01-01", 空控件, "d")    // 返回：空
```

### ❓ 开始日期大于结束日期会怎样？

会返回**负数**。

```js
DATEDIF("2023-01-08", "2023-01-01", "d")   // 返回：-7
```

### ❓ 单位参数大小写敏感吗？

是的，必须使用正确的大小写：

```js
// ✅ 正确
DATEDIF("2023-01-01", "2023-04-01", "M")   // 月份（大写M）
DATEDIF("2023-01-01 00:00", "2023-01-01 00:30", "m")  // 分钟（小写m）

// ❌ 错误
DATEDIF("2023-01-01", "2023-04-01", "m")   // 会计算为分钟，不是月份
```

### ❓ 如果不传单位参数会怎样？

默认按天（d）计算。

```js
DATEDIF("2023-01-01", "2023-01-08")   // 返回：7（天）
```

### ❓ 年份计算会四舍五入吗？

会的，返回带小数的年数差。

```js
// 2年零6个月，返回-2.5（带小数的年数差）
DATEDIF("2020-01-01", "2022-07-01", "y")   // 返回：-2.5

// 如果需要精确计算，使用月份
DATEDIF("2020-01-01", "2022-07-01", "M")   // 返回：-30（个月）
```

## 六、搭配使用技巧

### 技巧 1：结合 TODAY 函数计算至今

```js
// 计算从入职到现在的天数
DATEDIF(入职日期, TODAY(), "d")

// 计算距离到期还有多少天
DATEDIF(TODAY(), 到期日期, "d")
```

### 技巧 2：结合 IF 函数判断是否超期

```js
// 判断是否超过30天
IF(DATEDIF(开始日期, TODAY(), "d") > 30, "超期", "未超期")
```

### 技巧 3：计算年龄段

```js
// 根据年龄分段
CASE(
  DATEDIF(出生日期, TODAY(), "y") < 30, "青年",
  DATEDIF(出生日期, TODAY(), "y") < 50, "中年",
  "老年"
)
```

### 技巧 4：组合不同单位

```js
// 计算精确工龄："X年Y个月"
DATEDIF(入职日期, TODAY(), "y") + "年" +
(DATEDIF(入职日期, TODAY(), "M") - DATEDIF(入职日期, TODAY(), "y") * 12) + "个月"
```

## 七、与 DAYS 函数的区别

| 函数 | 作用 | 示例 |
|------|------|------|
| DATEDIF(开始, 结束, "d") | 计算日期差（支持多种单位） | DATEDIF("2023-01-01", "2023-01-08", "d") = 7 |
| DAYS(结束, 开始) | 只计算天数差 | DAYS("2023-01-08", "2023-01-01") = 7 |

**主要区别**：
- DATEDIF 支持多种单位（年、月、日、时、分、秒）
- DAYS 只计算天数，但更简洁

## 八、注意事项

### ⚠️ 单位参数的大小写

务必注意单位参数的大小写：

```js
// ✅ 正确
"y" = 年
"M" = 月
"d" = 天
"h" = 小时
"m" = 分钟（小写）
"s" = 秒

// ❌ 错误
"Y" = 可能不识别
"D" = 可能不识别
```

### ⚠️ 日期顺序

开始日期应该早于结束日期，否则会得到负数：

```js
// ✅ 正确顺序
DATEDIF("2023-01-01", "2023-12-31", "d")   // 返回：364

// ⚠️ 反向顺序会得到负数
DATEDIF("2023-12-31", "2023-01-01", "d")   // 返回：-364
```

### ⚠️ 时间精度

如果只有日期没有时间，小时、分钟、秒会按00:00:00计算：

```js
// 只有日期，按午夜00:00:00计算
DATEDIF("2023-01-01", "2023-01-02", "h")   // 返回：24（小时）
```
