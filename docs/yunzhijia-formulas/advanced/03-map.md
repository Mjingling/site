# 「「云之家」」计算公式之 MAP 函数

## 一、函数作用

`MAP` 函数用来**对明细表或数组的每一项执行表达式运算**，支持：
- 遍历数组中的每一项
- 对每一项执行指定的表达式
- 收集所有非空非false的结果
- 支持按索引获取特定项的结果

常用于明细表的批量计算、数据提取和过滤场景。

---

## 二、语法格式


MAP(明细表数组, 表达式, [索引])


### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 明细表数组 | 明细表控件的数据或数组 | ✅ 必填 | 明细表控件、数组字段 |
| 表达式 | 对每一项执行的表达式 | ✅ 必填 | "数量 * 单价" |
| 索引 | 获取指定索引的结果（从1开始） | ❌ 选填 | 1、2、3 |

### 返回值

- **有索引参数**：返回指定索引位置的结果（单个值）
- **无索引参数**：返回所有结果的数组
- **特殊情况**：
  - 如果明细表为空，返回空数组
  - 如果表达式为空，返回空数组
  - 结果为 null、undefined 或 false 的项会被过滤掉

---

## 三、实用示例

### 示例 1：提取明细表的某一列

假设【订单明细】有多个商品，每行有【商品名称】字段

MAP(订单明细, "商品名称")
返回：商品名称数组

### 示例 2：计算明细表的每行金额

假设每行有【数量】和【单价】字段

MAP(订单明细, "数量 * 单价")
返回：每行的金额数组

### 示例 3：条件过滤

MAP(订单明细, "IF(数量 > 10, 商品名称, false)")
返回：过滤后的商品名称数组

### 示例 4：获取指定索引的结果

获取第一行的金额

MAP(订单明细, "数量 * 单价", 1)
返回：100

获取第二行的金额

MAP(订单明细, "数量 * 单价", 2)
返回：200

### 示例 5：嵌套字段访问

MAP(订单明细, "商品.名称")
返回：商品名称数组

### 示例 6：与其他函数组合

MAP(订单明细, "CONCATENATE(商品名称, '：', 数量, '件')")
返回：格式化后的文本数组

## 四、实际业务场景

### 场景 1：计算明细表总金额


SUM(MAP(订单明细, "数量 * 单价"))


### 场景 2：提取所有商品名称


MAP(订单明细, "商品名称")


### 场景 3：筛选符合条件的明细


MAP(订单明细, "IF(数量 > 10, 商品名称, false)")


### 场景 4：格式化明细数据


MAP(订单明细, "CONCATENATE(商品名称, ' x ', 数量, ' = ', 数量 * 单价, '元')")


### 场景 5：条件统计


COUNT(MAP(订单明细, "IF(状态 == '已完成', 1, false)"))


### 场景 6：获取明细表的最大值


MAX(MAP(订单明细, "数量 * 单价"))

## 五、常见问题

### ❓ 为什么有些结果被过滤掉了？

MAP 会自动过滤掉 `null`、`undefined` 和 `false` 的结果：


MAP(订单明细, "IF(数量 > 10, 商品名称, false)")


如果不想过滤，可以返回空字符串或默认值：


MAP(订单明细, "IF(数量 > 10, 商品名称, '')")


### ❓ 表达式中如何引用当前行的字段？

直接使用字段名即可，表达式在每一行的上下文中执行：


MAP(订单明细, "数量 * 单价")


### ❓ 索引从0还是从1开始？

索引从 1 开始：


MAP(订单明细, "商品名称", 1)  // 第一行
MAP(订单明细, "商品名称", 2)  // 第二行


### ❓ 如何在表达式中使用常量？

直接使用即可，表达式支持常量：


MAP(订单明细, "数量 * 1.2")           // 使用数字常量
MAP(订单明细, "CONCATENATE(name, '元')")  // 使用字符串常量


### ❓ MAP 和循环有什么区别？

MAP 是函数式的遍历，更简洁高效：
- 传统循环：需要手动遍历和收集结果
- MAP：自动遍历和收集结果


MAP(订单明细, "数量 * 单价")



### ❓ 能否对数组控件使用 MAP？

可以，MAP 适用于任何数组数据：


MAP(标签, "CONCATENATE('标签：', name)")

## 六、搭配使用技巧

### 技巧 1：结合 SUM 计算总额


SUM(MAP(订单明细, "数量 * 单价"))


### 技巧 2：结合 COUNT 统计数量


COUNT(MAP(订单明细, "IF(状态 == '已完成', 1, false)"))


### 技巧 3：结合 MAX/MIN 求极值


MAX(MAP(订单明细, "金额"))
MIN(MAP(订单明细, "价格"))


### 技巧 4：多层嵌套处理


MAP(订单明细, "IF(数量 > 10, 数量 * 单价 * 0.9, 数量 * 单价)")


### 技巧 5：提取后去重


UNIQ(MAP(订单明细, "商品类别"))


### 技巧 6：条件求和


SUM(MAP(订单明细, "IF(类别 == '水果', 金额, 0)"))


---

## 七、注意事项

1. **表达式格式**：表达式需要用字符串包裹，例如 `"数量 * 单价"`
2. **字段访问**：表达式中直接使用字段名，无需前缀
3. **过滤机制**：结果为 `null`、`undefined`、`false` 的项会被过滤
4. **索引范围**：索引从 1 开始，超出范围返回空字符串
5. **性能考虑**：明细表数据量大时，注意表达式的复杂度

---

## 八、常见错误

### ❌ 错误用法


MAP(订单明细, 数量 * 单价)  // ❌

MAP(订单明细, "数量 * 单价")  // ✅

MAP(订单明细, "商品名称", 0)  // ❌

MAP(订单明细, "商品名称", 1)  // ✅


---

## 九、对比其他函数

| 函数 | 作用 | 返回值 |
|------|------|--------|
| MAP | 遍历并转换 | 数组或单个值 |
| SUM | 求和 | 数字 |
| COUNT | 计数 | 数字 |
| FILTER | 过滤（如果支持） | 数组 |

MAP 更灵活，可以配合其他函数实现各种复杂操作。
