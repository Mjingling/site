# 「「云之家」」计算公式之 ABS 函数

## 一、函数作用

`ABS` 函数用来**获取数字的绝对值**，简单来说就是：
- 负数变成正数（-5 变成 5）
- 正数保持不变（10 还是 10）

常用于计算差值、偏差等场景，让结果始终为正数。

---

## 二、语法格式

```
ABS(数字)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 数字 | 要取绝对值的数字，可以是数字控件、金额控件、运算控件等 | ✅ 必填 | ABS(-10) |

### 返回值

- **正常情况**：返回数字的绝对值
- **特殊情况**：如果参数不是数字，返回**空**（不会报错）

---

## 三、实用示例

### 示例 1：基本用法

```js
ABS(-5)      // 返回：5
ABS(15)      // 返回：15
ABS(-2.5)    // 返回：2.5
ABS(0)       // 返回：0
```

### 示例 2：计算偏差值

假设有【计划完成数】和【实际完成数】两个字段：

```js
ABS(实际完成数 - 计划完成数)
```

无论实际比计划多还是少，都显示为正数。

### 示例 3：计算温度变化幅度

假设有【早晨温度】和【傍晚温度】：

```js
ABS(早晨温度 - 傍晚温度)
```

### 示例 4：计算金额差异

```js
ABS(预算金额 - 实际支出)
```

如果预算是 5000 元，实际花了 4500 元：
```js
ABS(5000 - 4500) = 500  // 节省了 500 元
```

如果预算是 5000 元，实际花了 5800 元：
```js
ABS(5000 - 5800) = 800  // 超支了 800 元
```

## 四、实际业务场景

### 场景 1：库存盘点差异

在仓库盘点时，计算账面库存与实际库存的差异：

```js
// 【盘点差异】的计算公式
ABS(账面库存 - 实际库存)
```
### 场景 2：销售目标达成差距

```js
// 【目标差距】的计算公式
ABS(实际销售额 - 销售目标)
```

## 五、常见问题

### ❓ 如果参数为空会怎样？

如果控件没有填写，函数返回**空**，不会报错。

```js
ABS("")       // 返回：空
ABS(空控件)   // 返回：空
```

### ❓ 能对文本使用 ABS 吗？

不能。如果传入文本，函数返回**空**。

```js
ABS("abc")    // 返回：空
```

### ❓ 如何判断是增加还是减少？

ABS 只返回绝对值，无法区分正负。如果需要区分，使用原始的减法：

```js
// 判断增减
实际值 - 计划值   // 正数表示增加，负数表示减少

// 只看差异大小
ABS(实际值 - 计划值)  // 只显示差异的数值
```

## 六、搭配使用技巧

### 技巧 1：结合 IF 函数判断超标

```js
IF(ABS(实际值 - 计划值) > 100, "超标", "正常")
```

### 技巧 2：计算偏差率

```js
ABS(实际值 - 计划值) / 计划值 * 100
```

例如：计划 100，实际 120，偏差率 = 20%
