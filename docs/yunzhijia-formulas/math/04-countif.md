# 「「云之家」」计算公式之 COUNTIF 函数

## 一、函数作用

`COUNTIF` 函数用来**按条件计数**，简单来说就是：
- 从一堆数据中筛选出符合条件的数据
- 统计符合条件的记录有多少条
- 常用于明细表中，统计满足某个条件的记录数量

比如：统计有多少个"优品"、计算金额大于100元的订单有几个等。

---

## 二、语法格式

```
COUNTIF(明细数据, 筛选条件)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 明细数据 | 要筛选的明细表，通常使用"明细.控件自身" | ✅ 必填 | 产品明细.控件自身 |
| 筛选条件 | 筛选条件表达式，返回 true 的记录会被计数 | ✅ 必填 | 产品明细.等级 == "优" |

### 返回值

- **正常情况**：返回符合条件的记录数量
- **特殊情况**：如果没有符合条件的记录，返回 **0**

---

## 三、实用示例

### 示例 1：基本用法 - 按等级统计数量

假设有【产品明细】：

| 产品等级 | 数量 |
|---------|------|
| 优      | 10   |
| 良      | 5    |
| 良      | 4    |
| 优      | 8    |

```js
// 统计有多少条"良"品记录
COUNTIF(产品明细.控件自身, 产品明细.产品等级 == "良")
```

**结果：2** （有2条记录是"良"品）

### 示例 2：按金额大小筛选

假设有【费用明细】：

| 费用项目 | 金额  |
|---------|------|
| 交通费  | 150  |
| 餐费    | 80   |
| 住宿费  | 500  |
| 打车费  | 50   |

```js
// 统计金额大于100的费用有多少笔
COUNTIF(费用明细.控件自身, 费用明细.金额 > 100)
```

**结果：2** （交通费和住宿费）

### 示例 3：按开关状态筛选

假设有【任务明细】：

| 任务名称 | 工时 | 是否完成 |
|---------|------|---------|
| 任务A   | 8    | ✅ 是   |
| 任务B   | 5    | ❌ 否   |
| 任务C   | 6    | ✅ 是   |
| 任务D   | 4    | ❌ 否   |

```js
// 统计已完成的任务数量
COUNTIF(任务明细.控件自身, 任务明细.是否完成 == true)
```

**结果：2** （任务A和任务C）

### 示例 4：按文本内容筛选

假设有【订单明细】：

| 订单编号 | 金额  | 状态   |
|---------|------|--------|
| A001    | 1000 | 已付款 |
| A002    | 500  | 未付款 |
| A003    | 800  | 已付款 |
| A004    | 300  | 未付款 |

```js
// 统计已付款的订单数量
COUNTIF(订单明细.控件自身, 订单明细.状态 == "已付款")
```

**结果：2** （A001和A003）

### 示例 5：多个条件组合

```js
// 统计金额大于100且状态为"已审批"的记录数量
COUNTIF(明细.控件自身, 明细.金额 > 100 && 明细.状态 == "已审批")
```

### 示例 6：统计空值数量

假设有【员工信息明细】：

| 姓名   | 手机号      |
|-------|------------|
| 张三  | 13800138000 |
| 李四  | 空          |
| 王五  | 13900139000 |
| 赵六  | 空          |

```js
// 统计手机号为空的员工数量
COUNTIF(员工信息明细.控件自身, 员工信息明细.手机号 == "")
```

**结果：2** （李四和赵六）

## 四、实际业务场景

### 场景 1：产品质量统计

在产品检验表中，统计不同等级产品的数量：

```js
// 【优品数量】
COUNTIF(产品明细.控件自身, 产品明细.产品等级 == "优")

// 【良品数量】
COUNTIF(产品明细.控件自身, 产品明细.产品等级 == "良")

// 【次品数量】
COUNTIF(产品明细.控件自身, 产品明细.产品等级 == "次品")

// 【合格品数量】（优品或良品）
COUNTIF(产品明细.控件自身, 产品明细.产品等级 == "优" || 产品明细.产品等级 == "良")
```

### 场景 2：费用统计

在报销单中，统计不同条件的费用笔数：

```js
// 【超标费用笔数】（金额大于500）
COUNTIF(费用明细.控件自身, 费用明细.金额 > 500)

// 【交通费笔数】
COUNTIF(费用明细.控件自身, 费用明细.费用类型 == "交通费")

// 【需发票的费用笔数】
COUNTIF(费用明细.控件自身, 费用明细.是否需要发票 == true)
```

### 场景 3：任务完成度统计

统计任务的完成情况：

```js
// 【已完成任务数】
COUNTIF(任务明细.控件自身, 任务明细.是否完成 == true)

// 【未完成任务数】
COUNTIF(任务明细.控件自身, 任务明细.是否完成 == false)

// 【总任务数】
COUNT(任务明细.控件自身)

// 【完成率】（配合计算）
COUNTIF(任务明细.控件自身, 任务明细.是否完成 == true) / COUNT(任务明细.控件自身) * 100
```

### 场景 4：订单状态统计

统计不同状态的订单数量：

```js
// 【待处理订单数】
COUNTIF(订单明细.控件自身, 订单明细.状态 == "待处理")

// 【已完成订单数】
COUNTIF(订单明细.控件自身, 订单明细.状态 == "已完成")

// 【大单数量】（金额大于10000）
COUNTIF(订单明细.控件自身, 订单明细.金额 > 10000)
```

## 五、常见问题

### 如果筛选条件没有匹配到任何记录怎么办？

返回 **0**。

```js
// 假设没有任何"次品"
COUNTIF(产品明细.控件自身, 产品明细.产品等级 == "次品")
// 返回：0
```

### 如果明细表为空会怎样？

返回 **0**。

```js
COUNTIF(空明细.控件自身, 空明细.字段 > 100)
// 返回：0
```

### COUNTIF 和 COUNT 有什么区别？

| 函数 | 作用 | 是否需要条件 |
|------|------|-------------|
| **COUNT** | 统计所有记录数量 | ❌ 不需要 |
| **COUNTIF** | 统计符合条件的记录数量 | ✅ 需要 |

```js
// COUNT：统计所有任务（不管是否完成）
COUNT(任务明细.控件自身)  // 返回：4

// COUNTIF：只统计已完成的任务
COUNTIF(任务明细.控件自身, 任务明细.是否完成 == true)  // 返回：2
```

### 筛选条件可以使用哪些运算符？

可以使用以下运算符：
- **比较运算**：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于等于）
- **逻辑运算**：`&&`（并且）、`||`（或者）

### 能统计空值数量吗？

可以，使用空字符串判断：

```js
// 统计空值数量
COUNTIF(明细.控件自身, 明细.字段 == "")
```

## 六、搭配使用技巧

### 技巧 1：计算完成率

```js
// 任务完成率
COUNTIF(任务明细.控件自身, 任务明细.是否完成 == true) / COUNT(任务明细.控件自身) * 100
```

### 技巧 2：计算占比

```js
// 优品占比
COUNTIF(产品明细.控件自身, 产品明细.产品等级 == "优") / COUNT(产品明细.控件自身) * 100
```

### 技巧 3：结合 IF 判断是否达标

```js
// 判断优品数量是否达到10个
IF(COUNTIF(产品明细.控件自身, 产品明细.产品等级 == "优") >= 10, "达标", "未达标")
```

### 技巧 4：统计剩余任务

```js
// 剩余未完成任务数
COUNT(任务明细.控件自身) - COUNTIF(任务明细.控件自身, 任务明细.是否完成 == true)

// 或者直接统计未完成的
COUNTIF(任务明细.控件自身, 任务明细.是否完成 == false)
```

### 技巧 5：计算平均值（配合 SUMIF）

```js
// 计算优品的平均数量
SUMIF(产品明细.控件自身, 产品明细.产品等级 == "优", 产品明细.数量) /
COUNTIF(产品明细.控件自身, 产品明细.产品等级 == "优")
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **COUNT** | 统计所有记录数 | COUNT(明细.控件自身) | 所有记录的数量 |
| **COUNTIF** | 按条件统计记录数 | COUNTIF(明细.控件自身, 明细.等级=="优") | 符合条件的记录数量 |
| **SUMIF** | 按条件求和 | SUMIF(明细.控件自身, 明细.等级=="优", 明细.数量) | 符合条件的数量总和 |
| **LEN** | 统计文本长度 | LEN("hello") | 文本的字符数（5） |

**示例对比**：

假设有3条"优品"记录，数量分别是 10、20、30：

```js
COUNT(产品明细.控件自身)                                    // 返回：3（记录数）
COUNTIF(产品明细.控件自身, 产品明细.等级=="优")            // 返回：3（优品记录数）
SUMIF(产品明细.控件自身, 产品明细.等级=="优", 产品明细.数量)  // 返回：60（优品总数量）
```

**记忆方法**：
- COUNT = 计数（所有记录）
- COUNTIF = 条件计数（IF = 如果）
- SUMIF = 条件求和
