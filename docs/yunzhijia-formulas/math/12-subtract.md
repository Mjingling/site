# 「「云之家」」计算公式之 SUBTRACT 函数

## 一、函数作用

`SUBTRACT` 函数用来**计算差值**，即第一个数依次减去后面的所有数：
- 支持多个参数，从第一个开始连减
- 支持高精度小数运算，避免浮点误差（如 0.3 - 0.1 精确等于 0.2）
- 适用于计算余额、差额、净收入等场景

---

## 二、语法格式

```
SUBTRACT(被减数, 减数1, 减数2, ...减数N)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 被减数 | 第一个数字，作为被减数 | ✅ 必填 | SUBTRACT(100, 30, 20) |
| 减数1, 减数2... | 要减去的数字，可以有多个 | ❌ 可选 | SUBTRACT(100, 30, 20) |

### 返回值

- **正常情况**：返回被减数依次减去所有减数后的差值
- **单参数**：返回该参数自身
- **非数字参数**：返回空字符串

---

## 三、实用示例

### 示例 1：基本减法

```js
SUBTRACT(100, 30)          // 返回：70
SUBTRACT(100, 30, 20)      // 返回：50（100 - 30 - 20）
SUBTRACT(1000, 200, 100, 50) // 返回：650
```

### 示例 2：高精度小数运算

```js
// 普通写法存在浮点精度问题
0.3 - 0.1                  // 返回：0.19999999999999998（有误差）

// 使用 SUBTRACT 函数精确计算
SUBTRACT(0.3, 0.1)         // 返回：0.2（精确）
SUBTRACT(42.6, 42.6)       // 返回：0（精确）
```

### 示例 3：计算余额

假设【预算总额】为 10000，【已用金额1】为 2500，【已用金额2】为 1800：

```js
SUBTRACT(预算总额, 已用金额1, 已用金额2)
// 结果：5700
```

### 示例 4：负数运算

```js
SUBTRACT(-5, 3)            // 返回：-8
SUBTRACT(5, -3)            // 返回：8
SUBTRACT(-1.5, 2)          // 返回：-3.5
```

## 四、实际业务场景

### 场景 1：计算剩余预算

```js
// 【剩余预算】= 总预算 - 各项支出
SUBTRACT(总预算, 办公费, 差旅费, 招待费, 其他支出)
```

### 场景 2：计算净利润

```js
// 【净利润】= 总收入 - 成本 - 税费 - 其他扣减
SUBTRACT(总收入, 总成本, 税费, 其他扣减)
```

### 场景 3：计算折扣后价格

```js
// 【实付金额】= 原价 - 优惠金额
SUBTRACT(商品原价, 满减优惠)
```

## 五、常见问题

### ❓ 和直接写减法有什么区别？

直接写 `A - B` 使用 JavaScript 原生运算，存在浮点精度问题：

```js
// ❌ 可能不精确
42.6 - 42.6                // 返回：0

// ✅ 高精度
SUBTRACT(42.6, 42.6)       // 返回：0
```

### ❓ 只有一个参数会怎样？

返回该参数自身：

```js
SUBTRACT(10)               // 返回：10
```

### ❓ 参数中有非数字怎么办？

返回空字符串：

```js
SUBTRACT(10, "abc")        // 返回：""
```

### ❓ 能和其它高精度函数搭配吗？

可以，组合使用时精度不会丢失：

```js
// 先乘后减，全程高精度
SUBTRACT(42.6, PRODUCT(3, 14.2))   // 返回：0（精确）
```

---

## 六、搭配使用技巧

### 技巧 1：和 SUM 配合

```js
// 总收入 - 总支出
SUBTRACT(总收入, SUM(支出明细.金额))
```

### 技巧 2：和 PRODUCT 配合

```js
// 原价 - 折扣金额（折扣 = 原价 × 折扣率）
SUBTRACT(商品原价, PRODUCT(商品原价, 折扣率))
```

---

## 七、与 SUM 的区别

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| SUM(100, 30, 20) | 求和 | 全部相加 | 150 |
| SUBTRACT(100, 30, 20) | 求差 | 依次相减 | 50 |

---

## 八、注意事项

### ⚠️ 参数顺序很重要

```js
// SUBTRACT 不是交换律，顺序影响结果
SUBTRACT(100, 30, 20)      // 返回：50
SUBTRACT(30, 100, 20)      // 返回：-90
```

### ⚠️ 高精度运算的性能

涉及大量数据时，高精度函数比普通运算符稍慢，但对日常使用影响很小。
