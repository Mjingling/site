# 「「云之家」」计算公式之 MIN 函数

## 一、函数作用

`MIN` 函数用来**找出最小值**，简单来说就是：
- 从多个数字中找出最小的那个
- 可以比较多个单独的数字
- 可以从明细表字段中找出最小值
- 可以从数组中找出最小值

常用于找最低分、最低价格、最少库存等场景。

---

## 二、语法格式

```
MIN(参数1, 参数2, ...参数N)
```

或

```
MIN(明细表.字段)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 参数1, 参数2... | 要比较的数字，可以是：<br>• 直接写数字<br>• 数字控件<br>• 金额控件<br>• 运算控件<br>• 明细表字段<br>• 数组 | ✅ 至少1个 | MIN(80, 90, 70) |

### 返回值

- **正常情况**：返回所有参数中的最小值
- **特殊情况**：如果所有参数都为空，返回 **null**

---

## 三、实用示例

### 示例 1：比较固定数字

```js
MIN(80, 90, 70)              // 返回：70
MIN(100, 200, 150, 180)      // 返回：100
MIN(5, 3, 8, 1, 9, 2)        // 返回：1
MIN(-5, -3, -8)              // 返回：-8（负数中最小的）
```

### 示例 2：找出最低成绩

假设有【语文成绩】【数学成绩】【英语成绩】三个控件：

```js
MIN(语文成绩, 数学成绩, 英语成绩)
```

### 示例 3：明细表中找最小值

假设有【销售记录明细】表：

| 销售员 | 销售额 |
|--------|--------|
| 张三 | 5000 |
| 李四 | 8000 |
| 王五 | 3000 |
| 赵六 | 6500 |

```js
// 找出最低销售额
MIN(销售记录明细.销售额)  // 返回：3000
```

### 示例 4：数组中找最小值

```js
MIN([100, 200, 150, 180])    // 返回：100
MIN([3.5, 2.8, 4.2, 3.9])    // 返回：2.8
```

### 示例 5：混合使用

可以混合数字、控件、明细表：

```js
// 比较本月目标和实际销售额，取较小值
MIN(月度目标, 实际销售额)

// 比较固定值和控件值
MIN(100, 折扣价)  // 确保价格不超过100
```

## 四、实际业务场景

### 场景 1：最低价格查询

找出最便宜的报价：

```js
// 【最低报价】
MIN(供应商A报价, 供应商B报价, 供应商C报价)

// 【历史最低价】
MIN(报价明细.单价)
```

```js
MIN(98.5, 95.0, 102.0)  // 返回：95.0
```

### 场景 2：库存预警

找出最低库存，用于预警：

```js
// 【最低库存量】
MIN(仓库明细.库存数量)

// 【各月最低库存】
MIN(一月库存, 二月库存, 三月库存)
```

### 场景 3：成绩分析

找出学生薄弱科目：

```js
// 【最低分科目分数】
MIN(语文成绩, 数学成绩, 英语成绩, 物理成绩, 化学成绩)

// 【全班最低分】
MIN(成绩明细.总分)
```

### 场景 4：温度监控

```js
// 【当日最低温度】
MIN(温度记录.温度值)

// 【设备最低温度】
MIN(设备A温度, 设备B温度, 设备C温度)
```

### 场景 5：工资核算

```js
// 【部门最低工资】
MIN(员工明细.工资)

// 【保底工资】（底薪和提成取较小值）
MIN(底薪, 提成金额)
```

## 五、常见问题

### 如果某个参数为空怎么办？

空值会被**忽略**，不参与比较。

```js
// 假设【数学成绩】为空
MIN(语文成绩, 数学成绩, 英语成绩)
// 实际只比较：语文成绩 和 英语成绩
```

**示例：**

| 语文 | 数学 | 英语 | 最低分 |
|------|------|------|-------|
| 80 | 90 | 70 | 70（三门中最低） |
| 80 | 空 | 70 | 70（只比较两门） |

### 所有参数都为空会怎样？

返回 **null**。

```js
MIN("", "", "")   // 返回：0
MIN(空明细表.数量)  // 返回：null
```

### 能混合数字和控件吗？

可以！

```js
MIN(100, 数学成绩, 英语成绩)  // ✅ 可以
MIN(0, 库存数量)              // 确保结果不为负数
```

### 如何找出最小值对应的记录？

MIN 只返回数值，不返回对应的记录。如果需要找到对应的供应商，需要配合其他逻辑：

```js
// 先找出最小值
MIN(报价明细.单价)  // 假设返回 95.0

// 然后在明细表中筛选出单价=95.0的记录
```

### 负数比较怎么处理？

负数也正常比较，值越小（越远离0）越小：

```js
MIN(-5, -3, -8)   // 返回：-8
MIN(-10, 5, -2)   // 返回：-10
MIN(0, -5, 3)     // 返回：-5
```

## 六、搭配使用技巧

### 技巧 1：判断是否达标

```js
// 判断最低分是否及格（≥60分）
IF(MIN(语文, 数学, 英语) >= 60, "全部及格", "有不及格")
```

### 技巧 2：计算保底金额

```js
// 确保不低于底薪
MAX(MIN(底薪, 实际工资), 最低工资标准)
```

### 技巧 3：选择最优惠价格

```js
// 选择最低价格
MIN(市场价, 会员价, 促销价)

// 选择折后价和限时价中较低的
MIN(原价 * 折扣, 限时特价)
```

**示例：**

| 商品 | 市场价 | 会员价 | 促销价 | 最低价 |
|-----|--------|--------|--------|-------|
| 商品A | 100 | 95 | 90 | **90** |
| 商品B | 200 | 180 | 195 | **180** |

### 技巧 4：找出短板

```js
// 找出最弱科目的分数
MIN(语文, 数学, 英语, 物理, 化学)

// 配合IF给出建议
IF(MIN(语文, 数学, 英语) < 60, "需要加强薄弱科目", "均衡发展")
```

### 技巧 5：结合 ROUND 格式化

```js
// 找出最低价格并保留2位小数
ROUND(MIN(报价明细.单价), 2)
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **MIN** | 找最小值 | MIN(10, 20, 15) | 10 |
| **MAX** | 找最大值 | MAX(10, 20, 15) | 20 |
| **AVERAGE** | 求平均值 | AVERAGE(10, 20, 15) | 15 |
| **SUM** | 求和 | SUM(10, 20, 15) | 45 |

**详细对比**：

假设销售明细表有以下数据：

| 销售员 | 销售额 |
|--------|--------|
| 张三 | 5000 |
| 李四 | 8000 |
| 王五 | 3000 |

```js
MIN(销售明细.销售额)       // 返回：3000（最小值）
MAX(销售明细.销售额)       // 返回：8000（最大值）
AVERAGE(销售明细.销售额)   // 返回：5333.33（平均值）
SUM(销售明细.销售额)       // 返回：16000（总和）
COUNT(销售明细.销售额)     // 返回：3（记录数）
```

**记忆方法**：
- MIN = 最小值（Minimum）
- MAX = 最大值（Maximum）
- AVERAGE = 平均值（Average）
- SUM = 总和（Sum）

## 八、MIN 和 MAX 的组合使用

### 计算极差（最大值 - 最小值）

```js
// 计算成绩波动范围
MAX(语文, 数学, 英语) - MIN(语文, 数学, 英语)
```

**示例：**

| 语文 | 数学 | 英语 | 极差 |
|------|------|------|------|
| 85 | 92 | 78 | 14（92-78） |
| 90 | 88 | 94 | 6（94-88） |

### 判断成绩稳定性

```js
// 如果极差小于10，说明成绩稳定
IF((MAX(语文, 数学, 英语) - MIN(语文, 数学, 英语)) < 10, "成绩稳定", "成绩波动大")
```

### 计算价格区间

```js
// 显示价格区间
CONCATENATE("价格区间：", MIN(报价明细.单价), " - ", MAX(报价明细.单价))
// 结果示例："价格区间：95.0 - 102.0"
```

### 设置合理范围

```js
// 确保值在合理范围内（10-100之间）
MAX(10, MIN(100, 输入值))
// 如果输入值小于10，返回10
// 如果输入值大于100，返回100
// 否则返回输入值
```
