# 「「云之家」」计算公式之 ROUNDDOWN 函数

## 一、函数作用

`ROUNDDOWN` 函数用来**向下取整（舍去）**，简单来说就是：
- 将数字按照指定的小数位数向下取整
- 直接舍去多余的小数部分，不进位
- 常用于需要确保不超过某个值的场景，如优惠计算、成本控制等

比如：将 3.99 保留1位小数得到 3.9，将 3.11 保留1位小数也得到 3.1。

---

## 二、语法格式

```
ROUNDDOWN(数字, 保留位数)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 数字 | 要向下取整的数字，可以是数字控件、金额控件、运算控件 | ✅ 必填 | ROUNDDOWN(3.99, 1) |
| 保留位数 | 要保留的小数位数，可以是0或正整数 | ⭕ 选填，默认为0 | 1 表示保留1位小数 |

### 返回值

- **正常情况**：返回向下取整后的数字
- **特殊情况**：如果参数不是数字，返回**空**

---

## 三、实用示例

### 示例 1：基本用法

```js
ROUNDDOWN(3.99, 1)     // 返回：3.9
ROUNDDOWN(3.11, 1)     // 返回：3.1
ROUNDDOWN(3.14159, 3)  // 返回：3.141
ROUNDDOWN(5.99, 0)     // 返回：5（向下取整到个位）
ROUNDDOWN(-3.99, 1)    // 返回：-3.9（向零方向舍去）
```

### 示例 2：优惠金额计算

假设给客户9折优惠，向下取整对客户更有利：

```js
// 【优惠价】（元）
ROUNDDOWN(原价 * 0.9, 2)
```

### 示例 3：提成计算

计算销售提成时，向下取整避免多付：

```js
// 【提成金额】
ROUNDDOWN(销售额 * 提成比例, 2)
```

假设销售额 12345.67 元，提成比例 8%：
```js
ROUNDDOWN(12345.67 * 0.08, 2)  // 返回：987.65
```

### 示例 4：库存预警下限

设置库存下限时，向下取整确保不过度预警：

```js
// 【库存下限】
ROUNDDOWN(平均日销量 * 安全天数, 0)
```

假设平均日销量 12.8 件，安全天数 3 天：
```js
ROUNDDOWN(12.8 * 3, 0)  // 返回：38
```

### 示例 5：整数部分提取

```js
// 获取整数部分（保留0位小数）
ROUNDDOWN(123.456, 0)  // 返回：123
ROUNDDOWN(99.99, 0)    // 返回：99
```

### 示例 6：不同精度的向下取整

```js
ROUNDDOWN(3.14159, 1)  // 返回：3.1
ROUNDDOWN(3.14159, 2)  // 返回：3.14
ROUNDDOWN(3.14159, 3)  // 返回：3.141
ROUNDDOWN(3.99999, 0)  // 返回：3
```

## 四、实际业务场景

### 场景 1：客户优惠计算

在促销活动中，计算折后价向下取整对客户有利：

```js
// 【实际收费】（向下舍入避免多收费）
ROUNDDOWN(原价 * 折扣, 2)

// 【会员折扣价】
ROUNDDOWN(商品总额 * 会员折扣, 2)
```

### 场景 2：成本核算

计算成本时向下取整，避免成本高估：

```js
// 【单位成本】
ROUNDDOWN(总成本 / 数量, 2)

// 【预算控制】（向下取整确保不超预算）
ROUNDDOWN(预算金额 * 使用比例, 2)
```

### 场景 3：奖金计算

计算部门奖金分配时：

```js
// 【个人奖金】（向下取整）
ROUNDDOWN(部门总奖金 / 人数, 2)
```

假设部门奖金 10000 元，10 个人：
```js
ROUNDDOWN(10000 / 10, 2)  // 返回：1000.00
```

假设部门奖金 10000 元，3 个人：
```js
ROUNDDOWN(10000 / 3, 2)  // 返回：3333.33
```

### 场景 4：折旧计算

计算设备折旧金额：

```js
// 【月折旧金额】（向下取整）
ROUNDDOWN(设备原值 / 折旧月数, 2)
```

## 五、常见问题

### 如果参数为空会怎样？

返回**空**。

```js
ROUNDDOWN("", 1)      // 返回：空
ROUNDDOWN(空控件, 1)  // 返回：空
```

### 对负数向下取整会怎样？

负数向下取整是向零方向取整（即绝对值变小）：

```js
ROUNDDOWN(-3.14159, 3)  // 返回：-3.141
ROUNDDOWN(-3.99, 1)     // 返回：-3.9（向零舍去）
```

### 保留位数可以省略吗？

可以，默认为0（取整到个位）：

```js
ROUNDDOWN(3.99)    // 返回：3
ROUNDDOWN(5.01)    // 返回：5
ROUNDDOWN(-1.5)    // 返回：-1
```

### ROUNDDOWN 和 ROUND 的区别是什么？

| 函数 | 规则 | 3.99保留1位 | 3.11保留1位 |
|------|------|------------|------------|
| **ROUND** | 四舍五入 | 4.0 | 3.1 |
| **ROUNDDOWN** | 向下取整 | 3.9 | 3.1 |

```js
ROUND(3.99, 1)      // 返回：4.0（四舍五入）
ROUNDDOWN(3.99, 1)  // 返回：3.9（向下取整）
```

## 六、搭配使用技巧

### 技巧 1：计算最大优惠

```js
// 给客户最大优惠，向下取整
ROUNDDOWN(原价 * 0.8, 2)
```

假设原价 99.99 元，8折：
```js
ROUNDDOWN(99.99 * 0.8, 2)  // 返回：79.99（比四舍五入更优惠）
```

### 技巧 2：提取小数部分

```js
// 原数减去整数部分 = 小数部分
原价 - ROUNDDOWN(原价, 0)
```

假设原价 99.99 元：
```js
99.99 - ROUNDDOWN(99.99, 0)  // 返回：0.99
```

### 技巧 3：结合 IF 判断精度

```js
// 金额大于1000时取整，否则保留2位小数
IF(金额 > 1000, ROUNDDOWN(金额, 0), ROUNDDOWN(金额, 2))
```

### 技巧 4：批量折扣计算

```js
// 明细表中每件商品的折后价
ROUNDDOWN(商品明细.单价 * 0.9, 2)
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **ROUND** | 四舍五入 | ROUND(3.99, 1) | 4.0 |
| **ROUNDUP** | 向上取整 | ROUNDUP(3.01, 1) | 3.1 |
| **ROUNDDOWN** | 向下取整 | ROUNDDOWN(3.99, 1) | 3.9 |

**详细对比**：

以 3.14159 保留2位小数为例：

```js
ROUND(3.14159, 2)      // 返回：3.14（四舍五入）
ROUNDUP(3.14159, 2)    // 返回：3.15（向上取整）
ROUNDDOWN(3.14159, 2)  // 返回：3.14（向下取整）
```

以 3.99 保留1位小数为例：

```js
ROUND(3.99, 1)      // 返回：4.0（四舍五入）
ROUNDUP(3.91, 1)    // 返回：4.0（向上取整）
ROUNDDOWN(3.99, 1)  // 返回：3.9（向下取整）
```

**记忆方法**：
- ROUND = 四舍五入（看下一位是否≥5）
- ROUNDUP = 向上（UP，宁可多不少）
- ROUNDDOWN = 向下（DOWN，宁可少不多）

**使用场景建议**：
- **客户优惠**：用 ROUNDDOWN（对客户有利）
- **采购、包装**：用 ROUNDUP（确保数量充足）
- **一般计算**：用 ROUND（公平合理）
