# 「「云之家」」计算公式之 PRODUCT 函数

## 一、函数作用

`PRODUCT` 函数用来**计算乘积**，即所有参数相乘：
- 支持多个参数，全部连乘
- 支持高精度小数运算，避免浮点误差（如 0.1 × 0.2 精确等于 0.02）
- 适用于计算总价、面积、税金等场景

---

## 二、语法格式

```
PRODUCT(参数1, 参数2, ...参数N)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 参数1, 参数2... | 要相乘的数字，可以有多个 | ✅ 至少1个 | PRODUCT(3, 4) |

### 返回值

- **正常情况**：返回所有参数的乘积
- **单参数**：返回该参数自身
- **非数字参数**：返回空字符串

---

## 三、实用示例

### 示例 1：基本乘法

```js
PRODUCT(3, 4)             // 返回：12
PRODUCT(2, 3, 4)          // 返回：24（2 × 3 × 4）
PRODUCT(5, 10, 2)         // 返回：100
```

### 示例 2：高精度小数运算

```js
// 普通写法存在浮点精度问题
0.1 * 0.2                  // 返回：0.020000000000000004（有误差）
1.1 * 1.1                  // 返回：1.2100000000000002（有误差）
3 * 14.2                   // 返回：42.599999999999994（有误差）

// 使用 PRODUCT 函数精确计算
PRODUCT(0.1, 0.2)         // 返回：0.02（精确）
PRODUCT(1.1, 1.1)         // 返回：1.21（精确）
PRODUCT(3, 14.2)          // 返回：42.6（精确）
```

### 示例 3：负数运算

```js
PRODUCT(-3, 14.2)         // 返回：-42.6
PRODUCT(-2, -3)           // 返回：6（负负得正）
PRODUCT(-2, 3, -4)        // 返回：24
```

### 示例 4：与零相乘

```js
PRODUCT(0, 5)             // 返回：0
PRODUCT(100, 0, 50)       // 返回：0
```

## 四、实际业务场景

### 场景 1：计算总价

```js
// 【总价】= 单价 × 数量
PRODUCT(商品单价, 商品数量)
```

### 场景 2：计算含税金额

```js
// 【含税金额】= 未税金额 × (1 + 税率)
PRODUCT(未税金额, SUBTRACT(1, 税率))       // 不含税
PRODUCT(未税金额, SUM(1, 税率))            // 含税
```

### 场景 3：计算面积

```js
// 【面积】= 长 × 宽
PRODUCT(长度, 宽度)
```

### 场景 4：多级折扣

```js
// 【最终价格】= 原价 × 会员折扣 × 活动折扣
PRODUCT(商品原价, 会员折扣率, 活动折扣率)
```

## 五、常见问题

### ❓ 和直接写乘法有什么区别？

直接写 `A * B` 使用 JavaScript 原生运算，存在浮点精度问题：

```js
// ❌ 可能不精确
0.1 * 0.2                  // 返回：0.020000000000000004

// ✅ 高精度
PRODUCT(0.1, 0.2)         // 返回：0.02
```

### ❓ 只有一个参数会怎样？

返回该参数自身：

```js
PRODUCT(5)                // 返回：5
```

### ❓ 参数中有非数字怎么办？

返回空字符串：

```js
PRODUCT(3, "abc")         // 返回：""
```

### ❓ 能和其它高精度函数搭配吗？

可以，组合使用时精度不会丢失：

```js
// 先乘后减，全程高精度
SUBTRACT(42.6, PRODUCT(3, 14.2))   // 返回：0（精确）
```

## 六、搭配使用技巧

### 技巧 1：配合 DIVIDE 计算反向

```js
// 已知总价和数量，求单价
DIVIDE(总价, 数量)

// 等价于反向 PRODUCT
PRODUCT(总价, DIVIDE(1, 数量))
```

### 技巧 2：配合 IF 条件定价

```js
// 会员享受 8 折，非会员原价
IF(是否会员, PRODUCT(原价, 0.8), 原价)
```

## 七、与 SUM 的区别

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| SUM(3, 4, 5) | 求和 | 3 + 4 + 5 | 12 |
| PRODUCT(3, 4, 5) | 求积 | 3 × 4 × 5 | 60 |

---

## 八、注意事项

### ⚠️ 高精度运算不改变数学规则

```js
PRODUCT(0, 任意数)        // 始终为 0
PRODUCT(1, 任意数)        // 始终为任意数
```

### ⚠️ 大数相乘注意结果大小

高精度运算可能产生很大或很小的结果，注意数值范围。
