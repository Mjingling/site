# 「「云之家」」计算公式之 QUARTER 函数

## 一、函数作用

`QUARTER` 函数用来**提取日期中的季度（1-4）**,简单来说就是:
- 根据输入的日期返回该日期所在季度（1-4）
- 1季度（Q1）：1月-3月
- 2季度（Q2）：4月-6月
- 3季度（Q3）：7月-9月
- 4季度（Q4）：10月-12月

常用于按季度统计分析数据。

---

## 二、语法格式

```
QUARTER(日期)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期 | 需要提取季度的日期 | ✅ 必填 | 2024-03-15 |

### 返回值

- **正常情况**:返回季度数字（1、2、3或4）
- **特殊情况**:如果日期无效则返回空值

---

## 三、实用示例

### 示例 1:基本用法

```js
// 1月份属于第1季度
QUARTER("2024-01-15")  // 返回: 1

// 4月份属于第2季度
QUARTER("2024-04-20")  // 返回: 2
```

### 示例 2:提取当前日期季度

```js
// 获取当前日期的季度
QUARTER(NOW())  // 如果当前是3月,则返回: 1
```

### 示例 3:结合其他日期函数使用

```js
// 结合YEAR函数获取年份季度信息
"第" & YEAR("2024-05-20") & "年第" & QUARTER("2024-05-20") & "季度"  // 返回: 第2024年第2季度
```

### 示例 4:季度分类统计

```js
// 判断季度并返回季度名称
IF(QUARTER("2024-02-15") = 1, "第一季度",
   IF(QUARTER("2024-02-15") = 2, "第二季度",
      IF(QUARTER("2024-02-15") = 3, "第三季度", "第四季度")))  // 返回: 第一季度
```

### 示例 5:季度标签生成

```js
// 生成Q1、Q2、Q3、Q4格式的季度标签
"Q" & QUARTER("2024-05-15")  // 返回: Q2
```

### 示例 6:判断上半年和下半年

```js
// 根据季度判断是上半年还是下半年
IF(QUARTER("2024-05-15") <= 2, "上半年", "下半年")  // 返回: 上半年
```

## 五、常见问题

### ❓ QUARTER函数能处理时间戳吗？

可以,但需要先将时间戳转换为日期格式。

```js
// ✅ 正确:先转换时间戳
QUARTER(TEXT([时间戳], "yyyy-mm-dd"))

// ❌ 错误:直接使用时间戳
QUARTER([时间戳])  // 可能无法正确识别
```

### ❓ 如何处理空值日期？

使用IF函数进行空值判断,避免错误结果。

```js
// ✅ 正确:处理空值
IF(ISNULL([日期]), "", QUARTER([日期]))

// ❌ 错误:不处理空值
QUARTER([日期])  // 空值时可能出错
```

### ❓ QUARTER函数能处理文本日期吗？

可以,只要文本日期格式规范。

```js
// ✅ 正确:处理文本日期
QUARTER("2024-03-15")  // 返回: 1
QUARTER("2024/03/15")  // 返回: 1

// ❌ 错误:格式不规范的文本日期
QUARTER("2024年3月15日")  // 可能无法正确解析
```

### ❓ 如何获取季度的开始月份？

结合QUARTER函数和其他函数来计算季度的开始月份。

```js
// ✅ 正确:计算季度开始月份
IF(QUARTER([日期]) = 1, "01",
   IF(QUARTER([日期]) = 2, "04",
      IF(QUARTER([日期]) = 3, "07", "10")))
```

### ❓ QUARTER函数支持不同季度计算方式吗？

标准的QUARTER函数按标准季度计算（1-3月为Q1）,如需其他计算方式需自定义公式。

```js
// ✅ 正确:自定义季度计算（比如以4月为第1季度开始）
IF(MONTH([日期]) >= 4 AND MONTH([日期]) <= 6, 1,  // 4-6月为第1季度
   IF(MONTH([日期]) >= 7 AND MONTH([日期]) <= 9, 2,  // 7-9月为第2季度
      IF(MONTH([日期]) >= 10 AND MONTH([日期]) <= 12, 3, 4)))  // 10-12月为第3季度,1-3月为第4季度
```

### ❓ 如何处理季度数据分组？

结合其他函数进行季度数据分组统计。

```js
// ✅ 正确:按季度分组
"Q" & QUARTER([日期]) & "-" & YEAR([日期])  // 生成Q1-2024、Q2-2024等格式
```

## 六、搭配使用技巧

### 技巧 1:季度与年份组合

将年份和季度组合显示,用于报表展示。

```js
YEAR([日期]) & "年第" & QUARTER([日期]) & "季度"  // 生成"2024年第1季度"格式
```

### 技巧 2:季度数据汇总

结合SUMIF函数按季度汇总数据。

```js
SUMIF(QUARTER([日期列]), 1, [数值列])  // 汇总第1季度的数据
```

### 技巧 3:季度目标完成情况

判断当前季度是否已完成目标。

```js
IF(QUARTER(NOW()) = QUARTER([目标日期]), "本季度", "其他季度")
```

### 技巧 4:季度比较分析

比较不同季度的数据变化。

```js
QUARTER([当前日期]) - QUARTER([历史日期])  // 计算季度差异
```

### 技巧 5:季度计划安排

根据季度自动分配任务。

```js
IF(QUARTER([任务日期]) <= 2, "上半年任务", "下半年任务")
```

## 七、相关函数对比

| 函数 | 作用 | 返回值示例 | 使用场景 |
|------|------|-----------|---------|
| **QUARTER** | 提取日期中的季度 | 1、2、3、4 | 按季度统计数据 |
| **YEAR** | 提取日期中的年份 | 2024、2025 | 按年份统计数据 |
| **MONTH** | 提取日期中的月份 | 1-12 | 按月份统计数据 |
| **WEEKDAY** | 提取日期中的星期 | 1-7 | 按星期统计数据 |

**详细对比:**

```js
// 日期: 2024-05-15 (第2季度,5月,星期三)
QUARTER("2024-05-15")  // 返回: 2
YEAR("2024-05-15")     // 返回: 2024
MONTH("2024-05-15")    // 返回: 5
WEEKDAY("2024-05-15")  // 返回: 3
```

## 八、注意事项

### ⚠️ 日期格式必须规范

确保输入的日期格式规范,否则可能无法正确解析。

```js
// ❌ 错误
QUARTER("2024年3月15日")  // 格式不规范

// ✅ 正确
QUARTER("2024-03-15")    // 规范的日期格式
```

### ⚠️ 注意空值处理

对可能为空的日期字段进行空值判断。

```js
// ❌ 错误
QUARTER([日期字段])  // 如果日期字段为空会出错

// ✅ 正确
IF(ISNULL([日期字段]), "", QUARTER([日期字段]))
```

### ⚠️ 季度计算固定

QUARTER函数的季度计算方式是固定的（1-3月为Q1）,不支持自定义季度计算方式。

```js
// ❌ 错误:认为可以设置自定义季度
QUARTER([日期], 2)  // 这个参数不存在

// ✅ 正确:按标准季度计算
QUARTER([日期])  // 总是按1-3月为Q1计算
```

### ⚠️ 日期范围检查

确保日期在有效范围内,避免超出函数处理范围。

```js
// ❌ 错误
QUARTER("9999-01-01")  // 可能超出有效范围

// ✅ 正确
QUARTER("2024-01-01")  // 使用正常范围内的日期
```

### ⚠️ 文本日期格式

使用文本格式的日期时,要确保格式能被正确识别。

```js
// ❌ 错误:格式不一致
QUARTER("15/03/2024")  // 可能无法正确解析

// ✅ 正确:标准格式
QUARTER("2024-03-15")  // 标准ISO格式
```
