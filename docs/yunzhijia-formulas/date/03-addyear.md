# 「「云之家」」计算公式之 ADDYEAR 函数

## 一、函数作用

`ADDYEAR` 函数用来**在指定日期上增加或减少年份**，简单来说就是：
- 向后推算:加上正数年份（例如：今天加3年 = 3年后）
- 向前推算：加上负数年份（例如：今天减5年 = 5年前）

常用于计算合同到期、员工转正日期、证件有效期等场景。

---

## 二、语法格式

```
ADDYEAR(日期, 年数)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期 | 原始日期，可以是日期控件、日期字符串、时间戳 | ✅ 必填 | ADDYEAR("2020-01-01", 3) |
| 年数 | 要增加的年数，正数表示向后推算，负数表示向前推算 | ✅ 必填 | ADDYEAR("2020-01-01", -1) |

### 返回值

- **正常情况**：返回计算后的新日期（格式与输入日期格式一致）
- **特殊情况**：如果日期参数无效，返回**空**

---

## 三、实用示例

### 示例 1：基本用法

```js
ADDYEAR("2020-01-01", 3)      // 返回：2023-01-01（3年后）
ADDYEAR("2020-01-01", -1)     // 返回：2019-01-01（1年前）
ADDYEAR("2020/05/15", 5)      // 返回：2025/05/15（5年后）
ADDYEAR("2020-01-01", 0)      // 返回：2020-01-01（不变）
```

### 示例 2：计算员工转正日期

假设有【员工档案】表，包含【入职日期】：

```js
ADDYEAR(入职日期, 1)
```

### 示例 3：计算合同到期日期

假设【签约日期】为 2020-03-01，合同期限为3年：

```js
ADDYEAR(签约日期, 3)
```

### 示例 4：计算证件有效期

```js
// 计算身份证有效期（10年）
ADDYEAR(发证日期, 10)

// 计算驾照有效期（6年）
ADDYEAR(领证日期, 6)
```

## 四、实际业务场景

### 场景 1：员工试用期管理

在人事管理中，计算员工转正日期：

```js
// 【转正日期】的计算公式
ADDYEAR(入职日期, 1)
```

**示例：**
- 入职日期：2023-01-01
- 试用期：1年
- 转正日期：ADDYEAR("2023-01-01", 1) = **2024-01-01**

```js
// 【合同到期日】的计算公式
ADDYEAR(签约日期, 合同年限)
```

## 五、常见问题

### ❓ 如果日期参数为空会怎样？

如果日期控件没有填写，函数返回**空**，不会报错。

```js
ADDYEAR("", 3)        // 返回：空
ADDYEAR(空控件, 5)    // 返回：空
```

### ❓ 如果年数为0会怎样？

返回原始日期，日期不变。

```js
ADDYEAR("2020-01-01", 0)   // 返回：2020-01-01
```

### ❓ 会自动处理闰年吗？

会自动处理！

```js
// 闰年 2月29日 + 1年 = 2月28日（下一年不是闰年）
ADDYEAR("2020-02-29", 1)    // 返回：2021-02-28

// 闰年 2月29日 + 4年 = 2月29日（4年后还是闰年）
ADDYEAR("2020-02-29", 4)    // 返回：2024-02-29
```

### ❓ 能计算月份或天数吗？

不能。ADDYEAR 只能按年计算，如需按月或天计算，请使用其他函数。

```js
// ❌ 错误：想计算1.5年后
ADDYEAR("2020-01-01", 1.5)   // 不支持小数

// ✅ 正确：使用 ADDMONTH
ADDMONTH("2020-01-01", 18)   // 18个月 = 1.5年
```

### ❓ 支持负数年份吗？

支持！负数表示向前推算。

```js
ADDYEAR("2023-01-01", -5)    // 返回：2018-01-01（5年前）
ADDYEAR("2023-06-15", -10)   // 返回：2013-06-15（10年前）
```

## 六、搭配使用技巧

### 技巧 1：结合 TODAY 函数计算相对日期

```js
// 计算3年后的日期
ADDYEAR(TODAY(), 3)

// 计算5年前的日期
ADDYEAR(TODAY(), -5)
```

### 技巧 2：结合 IF 函数判断是否到期

```js
// 判断合同是否到期
IF(TODAY() > ADDYEAR(签约日期, 合同年限), "已到期", "未到期")
```

### 技巧 3：计算提前提醒日期

```js
// 到期前3个月提醒
ADDMONTH(ADDYEAR(开始日期, 合同年限), -3)
```

### 技巧 4：结合 DATEDIF 计算剩余年数

```js
// 计算距离到期还有多少年
DATEDIF(TODAY(), ADDYEAR(签约日期, 合同年限), "Y")
```

## 七、与其他日期函数的区别

| 函数 | 作用 | 示例 |
|------|------|------|
| ADDDAY(日期, 天数) | 增加或减少天数 | ADDDAY("2023-01-01", 30) = 2023-01-31 |
| ADDMONTH(日期, 月数) | 增加或减少月份 | ADDMONTH("2023-01-01", 6) = 2023-07-01 |
| ADDYEAR(日期, 年数) | 增加或减少年份 | ADDYEAR("2023-01-01", 1) = 2024-01-01 |

**记忆方法**：
- ADDDAY = 加天（Day）
- ADDMONTH = 加月（Month）
- ADDYEAR = 加年（Year）

## 八、注意事项

### ⚠️ 闰年2月29日的特殊处理

要注意闰年日期的自动调整：

```js
// 闰年2月29日 + 1年 = 2月28日（非闰年没有29日）
ADDYEAR("2020-02-29", 1)    // 返回：2021-02-28

// 闰年2月29日 + 4年 = 2月29日（闰年）
ADDYEAR("2020-02-29", 4)    // 返回：2024-02-29
```

### ⚠️ 年数参数必须是整数

```js
// ✅ 正确
ADDYEAR("2020-01-01", 3)
ADDYEAR("2020-01-01", -5)

// ❌ 错误：不支持小数
ADDYEAR("2020-01-01", 1.5)   // 可能导致错误
```

### ⚠️ 与日期控件结合使用

当使用日期控件时，确保控件已填写：

```js
// ✅ 推荐：先判断是否为空
IF(ISNULL(签约日期), "", ADDYEAR(签约日期, 3))

// ❌ 不推荐：直接使用可能返回空
ADDYEAR(签约日期, 3)
```
