# 「「云之家」」计算公式之 DAYS 函数

## 一、函数作用

`DAYS` 函数用来**计算两个日期之间相差的天数**,简单来说就是:
- 计算日期间隔(例如: 2023-05-01到2023-05-10 = 9天)
- 计算剩余天数或已过天数
- 判断时间长短

常用于请假天数计算、项目工期计算、倒计时提醒等场景。

---

## 二、语法格式

```
DAYS(结束日期, 开始日期)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 结束日期 | 较晚的日期,可以是日期控件、日期字符串、时间戳 | ✅ 必填 | DAYS("2023-05-10", "2023-05-01") |
| 开始日期 | 较早的日期,可以是日期控件、日期字符串、时间戳 | ✅ 必填 | DAYS("2023-05-10", "2023-05-01") |

### 返回值

- **正常情况**: 返回相差的天数(整数)
- **结束日期早于开始日期**: 返回负数
- **特殊情况**: 如果任一日期参数无效,返回**空**

---

## 三、实用示例

### 示例 1: 基本用法

```js
DAYS("2023-05-10", "2023-05-01")        // 返回: 9 (相差9天)
DAYS("2023-06-15", "2023-06-10")        // 返回: 5 (相差5天)
DAYS("2023-05-01", "2023-05-01")        // 返回: 0 (同一天)
DAYS("2023-05-01", "2023-05-10")        // 返回: -9 (结束日期在开始日期之前)
```

### 示例 2: 请假天数计算

假设有【请假申请】表,包含【开始日期】和【结束日期】:

```js
DAYS(结束日期, 开始日期)
```

### 示例 3: 项目工期计算

```js
// 计算项目已经进行了多少天
DAYS(TODAY(), 项目开始日期)

// 计算距离项目截止还有多少天
DAYS(项目截止日期, TODAY())
```

### 示例 4: 跨月跨年计算

DAYS函数会自动处理跨月和跨年:

```js
// 跨月计算
DAYS("2023-06-05", "2023-05-20")        // 返回: 16天

// 跨年计算
DAYS("2024-01-10", "2023-12-25")        // 返回: 16天

// 跨多年计算
DAYS("2025-01-01", "2023-01-01")        // 返回: 731天(包括2024闰年)
```

## 四、实际业务场景

### 场景 1: 考勤请假管理

计算员工请假天数:

```js
// 【请假天数】的计算公式
DAYS(请假结束日期, 请假开始日期)

// 【是否超过3天】
IF(DAYS(请假结束日期, 请假开始日期) > 3, "长假", "短假")
```

### 场景 2: 订单发货时效

计算订单处理时长:

```js
// 【处理时长】的计算公式
DAYS(发货日期, 下单日期)

// 【是否超时】
IF(DAYS(发货日期, 下单日期) > 3, "超时", "正常")
```

**示例:**
- 下单: 2023-05-01,发货: 2023-05-02 → 处理时长: **1天** (正常)
- 下单: 2023-05-01,发货: 2023-05-06 → 处理时长: **5天** (超时)

### 场景 3: 合同剩余天数

计算合同还有多少天到期:

```js
// 【剩余天数】的计算公式
DAYS(合同到期日, TODAY())

// 【到期提醒】
IF(DAYS(合同到期日, TODAY()) <= 30, "即将到期", "正常")
```

**示例:**
- 到期日: 2023-12-31,今天: 2023-12-20 → 剩余: **11天** (即将到期)
- 到期日: 2024-06-30,今天: 2023-12-20 → 剩余: **193天** (正常)

### 场景 4: 账龄分析

计算应收账款逾期天数:

```js
// 【逾期天数】的计算公式
DAYS(TODAY(), 应付日期)

// 【账龄分类】
IF(DAYS(TODAY(), 应付日期) <= 30, "30天内",
   IF(DAYS(TODAY(), 应付日期) <= 60, "30-60天",
      IF(DAYS(TODAY(), 应付日期) <= 90, "60-90天", "90天以上")))
```

## 五、常见问题

### ❓ 如果日期参数为空会怎样?

函数返回**空**,不会报错。

```js
DAYS("", "2023-05-01")                  // 返回: 0
DAYS("2023-05-10", "")                  // 返回: 0
DAYS(空控件, 空控件)                     // 返回: 空
```

### ❓ 参数顺序重要吗?

重要!参数顺序会影响结果的正负:
- **DAYS(结束日期, 开始日期)** → 返回正数(如果结束日期晚于开始日期)
- **DAYS(开始日期, 结束日期)** → 返回负数(如果开始日期早于结束日期)

```js
DAYS("2023-05-10", "2023-05-01")        // 返回: 9 (正数)
DAYS("2023-05-01", "2023-05-10")        // 返回: -9 (负数)
```

### ❓ 返回值包含首尾两天吗?

**不包含**开始日期,只计算中间相差的天数:

```js
DAYS("2023-05-03", "2023-05-01")        // 返回: 2 (5月2日、3日,不含1日)
DAYS("2023-05-02", "2023-05-01")        // 返回: 1 (只有5月2日)
DAYS("2023-05-01", "2023-05-01")        // 返回: 0 (同一天)
```

如果需要包含首尾两天,需要加1:
```js
DAYS("2023-05-03", "2023-05-01") + 1    // 返回: 3 (包含1、2、3号三天)
```

### ❓ 带时间的日期会影响结果吗?

不会。DAYS函数只计算日期部分,忽略时间:

```js
DAYS("2023-05-03 23:59:59", "2023-05-01 00:00:01")  // 返回: 2.999976851851852
DAYS("2023-05-03", "2023-05-01")                    // 返回: 2 (整天计算，结果相同)
```

### ❓ 可以用来计算工作日吗?

不能。DAYS 计算的是**自然日**(包括周末和节假日)。

如果需要计算工作日,需要额外逻辑排除周末和节假日。

```js
// DAYS计算自然日
DAYS("2023-05-08", "2023-05-01")        // 返回: 7天(包括周末)

// 如需工作日,需要自己排除周末
// (这里只是示意,实际需要更复杂的逻辑)
```

### ❓ 如何计算相差多少个月或年?

DAYS只能计算天数。如需月份或年份间隔,使用其他方法:

```js
// 粗略计算月数(不精确)
DAYS("2023-08-01", "2023-05-01") / 30   // 约3个月

// 粗略计算年数(不精确)
DAYS("2025-05-01", "2023-05-01") / 365  // 约2年

// 精确计算需要使用YEAR和MONTH函数组合
```

## 六、搭配使用技巧

### 技巧 1: 结合 TODAY 计算相对天数

```js
// 计算距今天过了多少天
DAYS(TODAY(), 开始日期)

// 计算距今天还有多少天
DAYS(结束日期, TODAY())
```

### 技巧 2: 结合 IF 函数条件判断

```js
// 判断是否超期
IF(DAYS(TODAY(), 截止日期) > 0, "已超期", "未超期")

// 判断时长范围
IF(DAYS(结束日期, 开始日期) <= 3, "短期",
   IF(DAYS(结束日期, 开始日期) <= 7, "中期", "长期"))
```

### 技巧 3: 结合 ABS 函数取绝对值

```js
// 无论参数顺序,都返回正数天数
ABS(DAYS(日期1, 日期2))

// 示例
ABS(DAYS("2023-05-01", "2023-05-10"))   // 返回: 9
ABS(DAYS("2023-05-10", "2023-05-01"))   // 返回: 9 (同样是9)
```

### 技巧 4: 结合 CONCATENATE 生成文本

```js
// 生成天数描述
CONCATENATE("相差", DAYS(结束日期, 开始日期), "天")

// 生成剩余天数提示
CONCATENATE("还剩", DAYS(截止日期, TODAY()), "天")
```

### 技巧 5: 结合 ADDDAY 验证计算

```js
// 验证: 开始日期 + 天数 = 结束日期
ADDDAY(开始日期, DAYS(结束日期, 开始日期)) == 结束日期  // 返回true
```

## 七、与其他日期函数的区别

| 函数 | 作用 | 返回值 | 示例 |
|------|------|-------|------|
| DAYS(结束, 开始) | 计算两个日期相差天数 | 数字 | DAYS("2023-05-10", "2023-05-01") = 9 |
| ADDDAY(日期, 天数) | 在日期上增加天数 | 日期 | ADDDAY("2023-05-01", 9) = 2023-05-10 |
| DAY(日期) | 提取日期的日部分 | 1-31 | DAY("2023-05-20") = 20 |
| TODAY() | 获取今天的日期 | 日期 | TODAY() = 今天的日期时间戳 |

## 八、注意事项

### ⚠️ 参数顺序影响正负

注意参数顺序,避免出现负数:

```js
// ✅ 正确: 结束日期在前,开始日期在后
DAYS("2023-05-10", "2023-05-01")        // 返回: 9

// ⭕ 注意: 参数反了会得到负数
DAYS("2023-05-01", "2023-05-10")        // 返回: -9

// ✅ 使用ABS确保正数
ABS(DAYS("2023-05-01", "2023-05-10"))   // 返回: 9
```

### ⚠️ 返回值不包含起始日

计算天数时不包含起始日:

```js
// 5月1日到5月3日
DAYS("2023-05-03", "2023-05-01")        // 返回: 2 (不包含1号)

// 如需包含首尾,加1
DAYS("2023-05-03", "2023-05-01") + 1    // 返回: 3 (包含1、2、3号)
```

### ⚠️ 计算的是自然日

DAYS计算的是自然日,包括周末和节假日:

```js
// 2023-05-01(周一)到2023-05-07(周日)
DAYS("2023-05-07", "2023-05-01")        // 返回: 6天(包含周末)

// 如需计算工作日,需额外处理周末
```

### ⚠️ 时间戳单位是毫秒

如果使用时间戳,确保单位是毫秒(13位):

```js
// ✅ 正确: 毫秒时间戳
DAYS(1684512000000, 1684425600000)      // 正确

// ❌ 错误: 秒级时间戳(10位)
DAYS(1684512000, 1684425600)            // 错误!需要乘以1000
```

### ⚠️ 与日期控件结合使用

当使用日期控件时,建议先判断是否为空:

```js
// ✅ 推荐: 先判断再计算
IF(ISNULL(开始日期) || ISNULL(结束日期), 0, DAYS(结束日期, 开始日期))

// ⭕ 可以但不推荐: 直接使用
DAYS(结束日期, 开始日期)                // 任一为空时返回空
```
