# 「「云之家」」计算公式之 DATEFORMAT 函数

## 一、函数作用

`DATEFORMAT` 函数用来**将日期格式化为指定的文本格式**,简单来说就是:
- 转换日期显示方式(例如: 2023-05-20 → 2023年05月20日)
- 提取日期的某个部分(例如: 只显示年份2023)
- 统一日期格式便于展示

常用于报表展示、日期标准化、数据导出等场景。

---

## 二、语法格式

```
DATEFORMAT(日期, 格式)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期 | 要格式化的日期,可以是日期控件、日期字符串、时间戳 | ✅ 必填 | DATEFORMAT("2023-05-20 09:54:13", "YYYY-MM-DD") |
| 格式 | 输出格式,指定如何显示日期 | ⭕ 可选 | "YYYY-MM-DD HH:mm:ss" (默认) |

### 格式符号说明

| 格式符号 | 说明 | 示例 |
|---------|------|------|
| YYYY | 四位年份 | 2023 |
| YY | 两位年份 | 23 |
| MM | 两位月份(01-12) | 05 |
| M | 月份(1-12) | 5 |
| DD | 两位日期(01-31) | 20 |
| D | 日期(1-31) | 20 |
| HH | 两位小时(00-23) | 09 |
| H | 小时(0-23) | 9 |
| mm | 两位分钟(00-59) | 54 |
| m | 分钟(0-59) | 54 |
| ss | 两位秒数(00-59) | 13 |
| s | 秒数(0-59) | 13 |

### 返回值

- **正常情况**: 返回格式化后的日期文本
- **特殊情况**: 如果日期参数无效,返回**空**

---

## 三、实用示例

### 示例 1: 基本用法

```js
DATEFORMAT("2023-05-20 09:54:13", "YYYY-MM-DD")        // 返回: "2023-05-20"
DATEFORMAT("2023-05-20 09:54:13", "YYYY年MM月DD日")    // 返回: "2023年05月20日"
DATEFORMAT("2023-05-20 09:54:13", "MM/DD/YYYY")        // 返回: "05/20/2023"
DATEFORMAT("2023-05-20 09:54:13", "HH:mm:ss")          // 返回: "09:54:13"
```

### 示例 2: 提取日期部分

```js
DATEFORMAT("2023-05-20 09:54:13", "YYYY")              // 返回: "2023" (只显示年份)
DATEFORMAT("2023-05-20 09:54:13", "MM")                // 返回: "05" (只显示月份)
DATEFORMAT("2023-05-20 09:54:13", "DD")                // 返回: "20" (只显示日期)
DATEFORMAT("2023-05-20 09:54:13", "YYYY-MM")           // 返回: "2023-05" (年月)
```

### 示例 3: 报表日期显示

假设有【会议记录】表,包含【会议时间】字段:

```js
DATEFORMAT(会议时间, "YYYY-MM-DD HH:mm")
```

### 示例 4: 中文格式显示

```js
DATEFORMAT("2023-06-15 14:30:00", "YYYY年MM月DD日")           // 返回: "2023年06月15日"
DATEFORMAT("2023-06-15 14:30:00", "YYYY年MM月DD日 HH时mm分")  // 返回: "2023年06月15日 14时30分"
DATEFORMAT("2023-06-15 14:30:00", "MM月DD日")                 // 返回: "06月15日"
```

## 四、实际业务场景

### 场景 1: 销售日报显示

在销售报表中统一日期显示格式:

```js
// 【销售日期】的格式化公式
DATEFORMAT(订单创建时间, "YYYY-MM-DD")
```

### 场景 2: 按年月统计

提取年月信息用于数据分组:

```js
// 【统计月份】的计算公式
DATEFORMAT(销售日期, "YYYY-MM")
```

**示例:**
- 销售日期: 2023-05-20 → 统计月份: **"2023-05"**
- 销售日期: 2023-06-15 → 统计月份: **"2023-06"**

### 场景 3: 文件命名

使用日期生成文件名:

```js
// 【文件名】的计算公式
CONCATENATE("报表_", DATEFORMAT(TODAY(), "YYYYMMDD"), ".xlsx")
```

**示例:**
- 今天是2023-05-20 → 文件名: **"报表_20230520.xlsx"**

### 场景 4: 考勤记录显示

格式化考勤打卡时间:

```js
// 【打卡时间显示】的计算公式
DATEFORMAT(打卡时间, "MM月DD日 HH:mm")
```

## 五、常见问题

### ❓ 如果日期参数为空会怎样?

函数返回**空**,不会报错。

```js
DATEFORMAT("", "YYYY-MM-DD")        // 返回: 空
DATEFORMAT(空控件, "YYYY-MM-DD")    // 返回: 空
```

### ❓ 格式参数可以省略吗?

可以。省略格式参数时,默认使用 **"YYYY-MM-DD HH:mm:ss"**。

```js
DATEFORMAT("2023-05-20 09:54:13")   // 返回: "2023-05-20 09:54:13"
```

### ❓ 可以使用时间戳吗?

可以,时间戳(毫秒)会自动转换为日期。

```js
DATEFORMAT(1684548853000, "YYYY-MM-DD")           // 返回: "2023-05-20"
DATEFORMAT(NOW(), "YYYY-MM-DD HH:mm:ss")          // 返回: 当前时间的格式化文本
```

### ❓ 支持自定义分隔符吗?

支持!可以使用任意字符作为分隔符。

```js
DATEFORMAT("2023-05-20", "YYYY.MM.DD")            // 返回: "2023.05.20"
DATEFORMAT("2023-05-20", "YYYY/MM/DD")            // 返回: "2023/05/20"
DATEFORMAT("2023-05-20", "YYYY-MM-DD")            // 返回: "2023-05-20"
DATEFORMAT("2023-05-20", "YYYY年MM月DD日")        // 返回: "2023年05月20日"
```

### ❓ 如何只显示时间部分?

只使用时间相关的格式符号即可。

```js
DATEFORMAT("2023-05-20 14:30:45", "HH:mm")        // 返回: "14:30"
DATEFORMAT("2023-05-20 14:30:45", "HH:mm:ss")     // 返回: "14:30:45"
```

### ❓ 大小写有区别吗?

有!格式符号**区分大小写**:
- **YYYY** = 四位年份,**YY** = 两位年份
- **MM** = 两位月份,**M** = 单位月份
- **DD** = 两位日期,**D** = 单位日期
- **HH** = 24小时制,**mm** = 分钟,**ss** = 秒

```js
DATEFORMAT("2023-05-20", "YYYY")                  // 返回: "2023" (四位年份)
DATEFORMAT("2023-05-20", "YY")                    // 返回: "23" (两位年份)
DATEFORMAT("2023-05-08", "MM")                    // 返回: "05" (补零)
DATEFORMAT("2023-05-08", "M")                     // 返回: "5" (不补零)
```

## 六、搭配使用技巧

### 技巧 1: 结合 TODAY 获取当前日期格式

```js
// 获取今天的日期(YYYY-MM-DD格式)
DATEFORMAT(TODAY(), "YYYY-MM-DD")

// 获取今天的中文日期
DATEFORMAT(TODAY(), "YYYY年MM月DD日")
```

### 技巧 2: 结合 NOW 获取当前时间格式

```js
// 获取当前完整时间
DATEFORMAT(NOW(), "YYYY-MM-DD HH:mm:ss")

// 获取当前时间(精确到分钟)
DATEFORMAT(NOW(), "HH:mm")
```

### 技巧 3: 结合 ADDDAY 格式化计算后的日期

```js
// 格式化30天后的日期
DATEFORMAT(ADDDAY(TODAY(), 30), "YYYY-MM-DD")

// 格式化7天前的日期
DATEFORMAT(ADDDAY(TODAY(), -7), "MM月DD日")
```

### 技巧 4: 结合 CONCATENATE 生成复合文本

```js
// 生成带日期的标题
CONCATENATE("销售报表_", DATEFORMAT(TODAY(), "YYYYMMDD"))

// 生成带时间的记录
CONCATENATE("备注: 提交于", DATEFORMAT(NOW(), "YYYY-MM-DD HH:mm"))
```

### 技巧 5: 结合 IF 函数条件格式化

```js
// 根据日期类型选择不同格式
IF(ISNULL(日期), "无日期", DATEFORMAT(日期, "YYYY-MM-DD"))

// 工作日显示时间,周末只显示日期
IF(WEEKDAY(日期) == 0,
   DATEFORMAT(日期, "MM月DD日"),
   DATEFORMAT(日期, "MM月DD日 HH:mm"))
```

## 七、与其他日期函数的区别

| 函数 | 作用 | 返回类型 | 示例 |
|------|------|---------|------|
| DATEFORMAT(日期, 格式) | 将日期格式化为文本 | 文本 | DATEFORMAT("2023-05-20", "YYYY-MM-DD") = "2023-05-20" |
| TIMESTAMP(日期) | 将日期转换为时间戳 | 数字 | TIMESTAMP("2023-05-20") = 1684512000000 |
| YEAR(日期) | 提取年份 | 数字 | YEAR("2023-05-20") = 2023 |
| MONTH(日期) | 提取月份 | 数字 | MONTH("2023-05-20") = 5 |
| DAY(日期) | 提取日期 | 数字 | DAY("2023-05-20") = 20 |

## 八、注意事项

### ⚠️ 返回值是文本类型

DATEFORMAT 返回的是**文本**,不能直接用于日期计算。

```js
// ✅ 正确: 格式化后用于显示
DATEFORMAT("2023-05-20", "YYYY-MM-DD")                    // 返回: "2023-05-20"

// ❌ 错误: 不能用格式化后的文本进行日期计算
ADDDAY(DATEFORMAT("2023-05-20", "YYYY-MM-DD"), 7)        // 错误!

// ✅ 正确: 先计算再格式化
DATEFORMAT(ADDDAY("2023-05-20", 7), "YYYY-MM-DD")        // 返回: "2023-05-27"
```

### ⚠️ 格式符号区分大小写

确保使用正确的大小写:

```js
// ✅ 正确
DATEFORMAT("2023-05-20", "YYYY-MM-DD")                    // "2023-05-20"

// ❌ 错误: 小写yyyy不识别
DATEFORMAT("2023-05-20", "yyyy-mm-dd")                    // 可能返回非预期结果
```

### ⚠️ 时间戳单位是毫秒

如果使用时间戳,确保单位是毫秒(13位):

```js
// ✅ 正确: 毫秒时间戳
DATEFORMAT(1684548853000, "YYYY-MM-DD")                   // 正确

// ❌ 错误: 秒级时间戳(10位)
DATEFORMAT(1684548853, "YYYY-MM-DD")                      // 错误!需要乘以1000
```

### ⚠️ 与日期控件结合使用

当使用日期控件时,建议先判断是否为空:

```js
// ✅ 推荐: 先判断再格式化
IF(ISNULL(日期控件), "未填写", DATEFORMAT(日期控件, "YYYY-MM-DD"))

// ⭕ 可以但不推荐: 直接使用
DATEFORMAT(日期控件, "YYYY-MM-DD")                        // 为空时返回空字符串
```
