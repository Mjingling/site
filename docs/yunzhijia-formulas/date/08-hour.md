# 「「云之家」」计算公式之 HOUR 函数

## 一、函数作用

`HOUR` 函数用来**从日期时间中提取小时数**,简单来说就是:
- 从完整的时间中取出小时部分
- 返回 0-23 之间的整数(24小时制)
- 例如:下午2点30分 → 返回 14

常用于时间统计、工作时段判断、考勤分析等场景。

---

## 二、语法格式

```
HOUR(日期时间)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期时间 | 要提取小时的日期时间,可以是日期时间控件、时间字符串、NOW()等 | ✅ 必填 | HOUR("2023-10-15 14:30:25") |

### 返回值

- **正常情况**:返回 0-23 之间的整数,表示小时数(24小时制)
- **特殊情况**:如果参数不是有效的时间,返回空或错误

---

## 三、实用示例

### 示例 1:基本用法

```js
HOUR("2023-10-15 14:30:25")    // 返回:14(下午2点)
HOUR("2023-10-15 09:15:30")    // 返回:9(早上9点)
HOUR("2023-10-15 18:45:00")    // 返回:18(下午6点)
HOUR("2023-10-15 00:30:00")    // 返回:0(凌晨0点)
HOUR("2023-10-15 23:59:59")    // 返回:23(晚上11点)
```

### 示例 2:提取当前小时

使用 NOW() 函数获取当前小时:

```js
HOUR(NOW())  // 返回当前的小时数
```

**示例:**

| 当前时间 | HOUR(NOW()) | 说明 |
|---------|------------|------|
| 2023-10-15 09:30:25 | 9 | 早上9点 |
| 2023-10-15 14:30:25 | 14 | 下午2点 |
| 2023-10-15 18:30:25 | 18 | 下午6点 |

### 示例 3:判断工作时段

判断是否在工作时间(9:00-18:00):

```js
IF(HOUR(打卡时间) >= 9 && HOUR(打卡时间) < 18, "工作时段", "非工作时段")
```

### 示例 4:按小时统计数据

提取订单时间的小时数,用于统计:

```js
HOUR(下单时间)
```

可以通过统计发现:14点有2个订单,是高峰时段。

### 示例 5:判断上下午

```js
IF(HOUR(时间) < 12, "上午", "下午")
```

### 示例 6:计算工作时长的小时部分

结合其他时间函数:

```js
// 提取开始时间和结束时间的小时差
HOUR(结束时间) - HOUR(开始时间)
```

**注意**:这只是简化示例,实际计算时长需要考虑跨日等情况。

## 四、实际业务场景

### 场景 1:考勤迟到判断

判断员工是否迟到(9点上班):

```js
// 【考勤状态】的计算公式
IF(HOUR(打卡时间) > 9, "迟到",
   IF(HOUR(打卡时间) == 9 && MINUTE(打卡时间) > 0, "迟到", "正常"))
```

### 场景 2:客服工作时段分析

统计客服咨询的时段分布:

```js
// 【咨询时段】的计算公式
CASE(
  HOUR(咨询时间) >= 9 && HOUR(咨询时间) < 12, "上午时段(9-12)",
  HOUR(咨询时间) >= 12 && HOUR(咨询时间) < 14, "午休时段(12-14)",
  HOUR(咨询时间) >= 14 && HOUR(咨询时间) < 18, "下午时段(14-18)",
  HOUR(咨询时间) >= 18 && HOUR(咨询时间) < 21, "晚间时段(18-21)",
  "非工作时段"
)
```

### 场景 3:设备使用高峰分析

分析设备使用的高峰时段:

```js
// 【使用时段】的计算公式
HOUR(使用开始时间)
```

通过统计各小时的使用次数,找出高峰时段。

### 场景 4:夜间操作提醒

提醒夜间时段的操作:

```js
// 【时段提醒】的计算公式
IF(HOUR(操作时间) >= 22 || HOUR(操作时间) < 6,
   "夜间操作,请注意", "正常时段")
```

## 五、常见问题

### ❓ HOUR 返回的是12小时制还是24小时制?

返回的是**24小时制**(0-23):

```js
HOUR("2023-10-15 14:30:00")  // 返回:14(不是2)
HOUR("2023-10-15 09:30:00")  // 返回:9
HOUR("2023-10-15 00:30:00")  // 返回:0(凌晨)
HOUR("2023-10-15 23:30:00")  // 返回:23(晚上11点)
```

如果需要12小时制,可以转换:

```js
// 转换为12小时制
IF(HOUR(时间) == 0, 12,
   IF(HOUR(时间) > 12, HOUR(时间) - 12, HOUR(时间)))
```

### ❓ 如何判断是上午还是下午?

使用小时数判断:

```js
// 判断上下午
IF(HOUR(时间) < 12, "上午", "下午")

// 更详细的判断
CASE(
  HOUR(时间) < 6, "凌晨",
  HOUR(时间) < 12, "上午",
  HOUR(时间) < 13, "中午",
  HOUR(时间) < 18, "下午",
  "晚上"
)
```

### ❓ 如果只有时间没有日期可以用吗?

可以!HOUR 函数可以处理纯时间:

```js
HOUR("14:30:25")  // 返回:14
HOUR("09:15:00")  // 返回:9
```

### ❓ 如何计算两个时间的小时差?

简单情况可以直接相减:

```js
HOUR(结束时间) - HOUR(开始时间)

// 例如:
HOUR("18:00:00") - HOUR("09:00:00")  // 返回:9
```

**注意**:这只适用于同一天内的时间。如果跨天,需要使用完整的时间差计算。

### ❓ 凌晨0点返回什么?

凌晨0点返回 0:

```js
HOUR("2023-10-15 00:00:00")  // 返回:0
HOUR("2023-10-15 00:30:00")  // 返回:0
```

## 六、搭配使用技巧

### 技巧 1:结合 MINUTE 精确判断时间

```js
// 判断是否在9:30之后
HOUR(时间) > 9 || (HOUR(时间) == 9 && MINUTE(时间) >= 30)

// 示例:判断迟到
IF(HOUR(打卡时间) > 9 || (HOUR(打卡时间) == 9 && MINUTE(打卡时间) > 0),
   "迟到", "准时")
```

### 技巧 2:结合 NOW 判断当前时段

```js
// 判断当前是否在营业时间(9:00-21:00)
IF(HOUR(NOW()) >= 9 && HOUR(NOW()) < 21, "营业中", "已打烊")

// 实时显示时段
CASE(
  HOUR(NOW()) < 9, "准备中",
  HOUR(NOW()) < 21, "营业中",
  "已打烊"
)
```

### 技巧 3:结合 IF 和 CASE 分时段处理

```js
// 不同时段不同的服务费率
CASE(
  HOUR(服务时间) >= 8 && HOUR(服务时间) < 18, 基础费用,
  HOUR(服务时间) >= 18 && HOUR(服务时间) < 22, 基础费用 * 1.5,
  基础费用 * 2
)
```

### 技巧 4:结合 CONCATENATE 生成时段描述

```js
// 生成友好的时段描述
CONCATENATE(
  HOUR(时间), "点",
  IF(MINUTE(时间) > 0, CONCATENATE(MINUTE(时间), "分"), "整")
)

// 返回:"14点30分" 或 "9点整"
```

### 技巧 5:按小时分组统计

```js
// 提取小时用于分组
HOUR(订单时间)

// 配合 COUNTIF 或 SUMIF 统计各小时的订单量
// 例如统计14点的订单数:
COUNTIF(订单列表.订单时间, HOUR(订单时间) == 14)
```

## 七、相关函数对比

| 函数 | 作用 | 返回值示例 | 使用场景 |
|------|------|-----------|---------|
| **HOUR(时间)** | 提取小时(0-23) | 14 | 按小时统计、时段判断 |
| **MINUTE(时间)** | 提取分钟(0-59) | 30 | 精确到分钟的判断 |
| **SECOND(时间)** | 提取秒(0-59) | 25 | 精确到秒的判断 |
| **YEAR(时间)** | 提取年份 | 2023 | 按年统计 |
| **MONTH(时间)** | 提取月份(1-12) | 10 | 按月统计 |
| **DAY(时间)** | 提取日期(1-31) | 15 | 按日统计 |
| **WEEKDAY(时间)** | 提取星期几(0-6) | 0 | 判断工作日/周末 |
| **NOW()** | 获取当前时间 | 2023-10-15 14:30:25 | 获取实时时间 |

**详细对比:**

```js
// 假设时间为:2023-10-15 14:30:25(周日)

HOUR("2023-10-15 14:30:25")      // 返回:14
MINUTE("2023-10-15 14:30:25")    // 返回:30
SECOND("2023-10-15 14:30:25")    // 返回:25
YEAR("2023-10-15 14:30:25")      // 返回:2023
MONTH("2023-10-15 14:30:25")     // 返回:10
DAY("2023-10-15 14:30:25")       // 返回:15
WEEKDAY("2023-10-15 14:30:25")   // 返回:0(周日)

// 组合使用:判断是否工作日的工作时间
WEEKDAY(时间) >= 1 && WEEKDAY(时间) <= 5 &&
HOUR(时间) >= 9 && HOUR(时间) < 18
```

## 八、注意事项

### ⚠️ 返回值是24小时制(0-23)

不是12小时制:

```js
HOUR("14:30:00")  // 返回:14(不是2)
HOUR("20:00:00")  // 返回:20(不是8)

// ❌ 错误理解
IF(HOUR(时间) > 12, "下午", "上午")
// 这样的话20点会被判断为下午,但实际是晚上

// ✅ 正确做法
CASE(
  HOUR(时间) < 12, "上午",
  HOUR(时间) < 18, "下午",
  "晚上"
)
```

### ⚠️ 凌晨0点返回0而不是24

午夜时刻的小时数是0:

```js
HOUR("2023-10-15 00:30:00")  // 返回:0(不是24)
HOUR("2023-10-15 00:00:00")  // 返回:0

// 判断是否凌晨时段
HOUR(时间) >= 0 && HOUR(时间) < 6  // 0点到6点
```

### ⚠️ 只能提取小时,不包含分秒

HOUR 只返回小时部分:

```js
HOUR("14:30:25")  // 返回:14(不包含30分25秒)

// ❌ 不能用于精确时间比较
HOUR(时间1) == HOUR(时间2)
// 14:30 和 14:45 的小时都是14,但不是同一时间

// ✅ 如需精确比较,直接比较时间
时间1 == 时间2
```

### ⚠️ 跨天计算要特别注意

计算小时差时注意跨天情况:

```js
// ❌ 错误:不能简单相减
HOUR("02:00:00") - HOUR("23:00:00")
// 返回:-21,但实际只过了3小时

// ✅ 正确:使用完整时间计算
(时间2 - 时间1) / (1000 * 60 * 60)  // 转换为小时数
```

### ⚠️ 参数必须是有效的时间格式

无效的时间会导致错误:

```js
HOUR("abc")        // 错误或返回空
HOUR("")           // 错误或返回空
HOUR(null)         // 错误或返回空

// ✅ 使用前先判断
IF(ISNULL(时间), 0, HOUR(时间))
```
