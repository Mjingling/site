# 「「云之家」」计算公式之 ADDMONTH 函数

## 一、函数作用

`ADDMONTH` 函数用来**在指定日期上增加或减少月份**，简单来说就是：
- 向后推算：加上正数月份（例如：今天加3个月 = 下季度）
- 向前推算：加上负数月份（例如：今天减6个月 = 半年前）

常用于计算合同到期、保险续期、租赁到期等场景。

---

## 二、语法格式

```
ADDMONTH(日期, 月数)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期 | 原始日期，可以是日期控件、日期字符串、时间戳 | ✅ 必填 | ADDMONTH("2023-01-15", 3) |
| 月数 | 要增加的月数，正数表示向后推算，负数表示向前推算 | ✅ 必填 | ADDMONTH("2023-01-15", -1) |

### 返回值

- **正常情况**：返回计算后的新日期（格式与输入日期格式一致）
- **特殊情况**：如果日期参数无效，返回**空**

---

## 三、实用示例

### 示例 1：基本用法

```js
ADDMONTH("2023-01-15", 3)      // 返回：2023-04-15（3个月后）
ADDMONTH("2023-01-15", -1)     // 返回：2022-12-15（1个月前）
ADDMONTH("2023/06/01", 6)      // 返回：2023/12/01（6个月后）
ADDMONTH("2023-01-15", 0)      // 返回：2023-01-15（不变）
```

### 示例 2：计算合同到期日期

假设有【合同管理】表，包含【签约日期】和【合同期限（月）】：

```js
ADDMONTH(签约日期, 合同期限月数)
```

### 示例 3：计算保险到期日期

假设【投保日期】为 2023-06-01，保险期限为12个月：

```js
ADDMONTH(投保日期, 12)
```

### 示例 4：计算过去的日期

```js
// 计算3个月前的日期
ADDMONTH("2023-06-15", -3)     // 返回：2023-03-15

// 计算1年前的日期（12个月）
ADDMONTH("2023-06-01", -12)    // 返回：2022-06-01
```

## 四、实际业务场景

### 场景 1：租赁管理

在房屋租赁管理中，计算租约到期日：

```js
// 【租约到期日】的计算公式
ADDMONTH(租约开始日期, 租赁期限月数)
```

**示例：**
- 租约开始：2023-01-01
- 租赁期限：12个月
- 租约到期：ADDMONTH("2023-01-01", 12) = **2024-01-01**

### 场景 2：会员到期提醒

计算会员到期日期：

```js
// 【会员到期日】的计算公式
ADDMONTH(会员开通日期, 会员月数)
```

### 场景 3：贷款还款计划

计算分期还款的每月还款日：

```js
// 【第一期还款日】
ADDMONTH(贷款发放日期, 1)

// 【第二期还款日】
ADDMONTH(贷款发放日期, 2)

// 【第三期还款日】
ADDMONTH(贷款发放日期, 3)
```

### 场景 4：季度报表截止日

```js
// 【下季度开始日期】
ADDMONTH(本季度开始日期, 3)

// 【上季度开始日期】
ADDMONTH(本季度开始日期, -3)
```

## 五、常见问题

### ❓ 如果日期参数为空会怎样？

如果日期控件没有填写，函数返回**空**，不会报错。

```js
ADDMONTH("", 3)        // 返回：空
ADDMONTH(空控件, 12)    // 返回：空
```

### ❓ 如果月数为0会怎样？

返回原始日期，日期不变。

```js
ADDMONTH("2023-01-15", 0)   // 返回：2023-01-15
```

### ❓ 会自动处理跨年吗？

会自动处理！不需要担心年份变化。

```js
// 跨年
ADDMONTH("2023-10-15", 5)    // 返回：2024-03-15（自动跨到2024年）

// 多年
ADDMONTH("2023-01-01", 24)   // 返回：2025-01-01（2年后）
```

### ❓ 如果遇到月末日期怎么办？

会智能处理月末日期！

```js
// 1月31日 + 1个月 = 2月28日（2月没有31号）
ADDMONTH("2023-01-31", 1)    // 返回：2023-02-28

// 1月31日 + 1个月 = 2月29日（闰年）
ADDMONTH("2024-01-31", 1)    // 返回：2024-02-29

// 3月31日 + 1个月 = 4月30日（4月只有30天）
ADDMONTH("2023-03-31", 1)    // 返回：2023-04-30
```

### ❓ 能计算具体天数吗？

不能。ADDMONTH 只能按月计算，如需按天计算，请使用 `ADDDAY` 函数。

```js
// ❌ 错误：想计算45天后
ADDMONTH("2023-01-01", 1.5)   // 不支持小数

// ✅ 正确：使用 ADDDAY
ADDDAY("2023-01-01", 45)      // 返回45天后的日期
```

## 六、搭配使用技巧

### 技巧 1：结合 TODAY 函数计算相对日期

```js
// 计算3个月后的日期
ADDMONTH(TODAY(), 3)

// 计算6个月前的日期
ADDMONTH(TODAY(), -6)
```

### 技巧 2：结合 IF 函数判断是否到期

```js
// 判断合同是否到期
IF(TODAY() > ADDMONTH(签约日期, 合同期限), "已到期", "未到期")
```

### 技巧 3：计算提前续费日期

```js
// 到期前1个月提醒续费
ADDMONTH(ADDMONTH(开始日期, 合同期限), -1)

// 等同于
ADDMONTH(开始日期, 合同期限 - 1)
```

### 技巧 4：结合 DATEDIF 计算剩余月数

```js
// 计算距离到期还有多少个月
DATEDIF(TODAY(), ADDMONTH(签约日期, 合同期限), "M")
```

## 七、与其他日期函数的区别

| 函数 | 作用 | 示例 |
|------|------|------|
| ADDDAY(日期, 天数) | 增加或减少天数 | ADDDAY("2023-01-01", 30) = 2023-01-31 |
| ADDMONTH(日期, 月数) | 增加或减少月份 | ADDMONTH("2023-01-01", 2) = 2023-03-01 |
| ADDYEAR(日期, 年数) | 增加或减少年份 | ADDYEAR("2023-01-01", 1) = 2024-01-01 |

**记忆方法**：
- ADDDAY = 加天（Day）
- ADDMONTH = 加月（Month）
- ADDYEAR = 加年（Year）

## 八、注意事项

### ⚠️ 月末日期的特殊处理

要注意月末日期的自动调整：

```js
// 1月31日 + 1个月 = 2月28日（不是3月3日）
ADDMONTH("2023-01-31", 1)    // 返回：2023-02-28

// 如果希望保持"月末"的概念，可以这样理解：
// 1月的最后一天 → 2月的最后一天
```

### ⚠️ 月数参数必须是整数

```js
// ✅ 正确
ADDMONTH("2023-01-01", 3)
ADDMONTH("2023-01-01", -6)

// ❌ 错误：不支持小数
ADDMONTH("2023-01-01", 1.5)   // 可能导致错误
```

### ⚠️ 与日期控件结合使用

当使用日期控件时，确保控件已填写：

```js
// ✅ 推荐：先判断是否为空
IF(ISNULL(签约日期), "", ADDMONTH(签约日期, 12))

// ❌ 不推荐：直接使用可能返回空
ADDMONTH(签约日期, 12)
```
