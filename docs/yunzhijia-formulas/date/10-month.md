# 「「云之家」」计算公式之 MONTH 函数

## 一、函数作用

`MONTH` 函数用来**从日期中提取月份**,简单来说就是:
- 从完整的日期中取出月份部分
- 返回 1-12 之间的整数
- 例如:2023年10月15日 → 返回 10

常用于按月统计、月度报表、季度计算等场景。

---

## 二、语法格式

```
MONTH(日期)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期 | 要提取月份的日期,可以是日期控件、日期字符串、NOW()、TODAY()等 | ✅ 必填 | MONTH("2023-10-15") |

### 返回值

- **正常情况**:返回 1-12 之间的整数,表示月份
- **特殊情况**:如果参数不是有效的日期,返回空或错误

---

## 三、实用示例

### 示例 1:基本用法

```js
MONTH("2023-10-15")    // 返回:10(10月)
MONTH("2023-01-01")    // 返回:1(1月)
MONTH("2023-12-31")    // 返回:12(12月)
MONTH(NOW())           // 返回当前月份
MONTH(TODAY())         // 返回当前月份
```

### 示例 2:提取当前月份

```js
MONTH(TODAY())  // 返回本月
```

### 示例 3:判断是否同一个月

```js
IF(MONTH(日期1) == MONTH(日期2), "同月", "不同月")
```

### 示例 4:按月统计

```js
MONTH(订单日期)
```

### 示例 5:月份显示

```js
CONCATENATE(MONTH(日期), "月")
```

### 示例 6:判断季度

```js
CASE(
  MONTH(日期) <= 3, "第一季度",
  MONTH(日期) <= 6, "第二季度",
  MONTH(日期) <= 9, "第三季度",
  "第四季度"
)
```

## 四、实际业务场景

### 场景 1:月度销售统计

按月统计销售数据:

```js
// 【所属月份】的计算公式
MONTH(销售日期)
```

可以通过 SUMIF 按月份汇总销售额。

### 场景 2:生日提醒

检查员工是否当月生日:

```js
// 【生日提醒】的计算公式
IF(MONTH(生日) == MONTH(TODAY()), "本月生日", "")
```

### 场景 3:合同到期月份检查

检查合同在哪个月到期:

```js
// 【到期月份】的计算公式
CONCATENATE(YEAR(到期日期), "年", MONTH(到期日期), "月")
```

### 场景 4:月度任务完成率

统计当月任务完成情况:

```js
// 【是否本月任务】的计算公式
IF(MONTH(任务日期) == MONTH(TODAY()) &&
   YEAR(任务日期) == YEAR(TODAY()),
   "本月任务", "其他月份")
```

## 五、常见问题

### ❓ MONTH 返回值的范围是什么?

返回 **1-12** 之间的整数:

```js
MONTH("2023-01-15")  // 返回:1
MONTH("2023-06-30")  // 返回:6
MONTH("2023-12-25")  // 返回:12
```

### ❓ 如何判断是否本月?

结合 YEAR 一起判断:

```js
MONTH(日期) == MONTH(TODAY()) && YEAR(日期) == YEAR(TODAY())
```

### ❓ 如何显示中文月份?

```js
CONCATENATE(MONTH(日期), "月")
// 或
CASE(
  MONTH(日期) == 1, "一月",
  MONTH(日期) == 2, "二月",
  // ... 依此类推
  "十二月"
)
```

### ❓ 如何计算季度?

```js
QUARTER(日期)  // 直接使用 QUARTER 函数
// 或
ROUNDUP(MONTH(日期) / 3)  // 通过月份计算
```

### ❓ 如何比较两个月份的前后?

```js
// 需要同时比较年和月
IF(YEAR(日期1) > YEAR(日期2), "日期1较晚",
   IF(YEAR(日期1) < YEAR(日期2), "日期1较早",
      IF(MONTH(日期1) > MONTH(日期2), "日期1较晚",
         IF(MONTH(日期1) < MONTH(日期2), "日期1较早", "同月"))))
```

## 六、搭配使用技巧

### 技巧 1:结合 YEAR 生成年月标识

```js
CONCATENATE(YEAR(日期), "-",
  IF(MONTH(日期) < 10, CONCATENATE("0", MONTH(日期)), MONTH(日期)))
// 返回:"2023-10"
```

### 技巧 2:判断上半年还是下半年

```js
IF(MONTH(日期) <= 6, "上半年", "下半年")
```

### 技巧 3:计算月份差

```js
(YEAR(日期2) - YEAR(日期1)) * 12 + (MONTH(日期2) - MONTH(日期1))
```

### 技巧 4:按季度分组

```js
CONCATENATE("Q", ROUNDUP(MONTH(日期) / 3))
// 返回:"Q1"、"Q2"、"Q3"、"Q4"
```

### 技巧 5:月度进度显示

```js
CONCATENATE(MONTH(TODAY()), "月/12月")
// 返回:"10月/12月"
```

## 七、相关函数对比

| 函数 | 作用 | 返回值示例 | 使用场景 |
|------|------|-----------|---------|
| **MONTH(日期)** | 提取月份(1-12) | 10 | 按月统计 |
| **YEAR(日期)** | 提取年份 | 2023 | 按年统计 |
| **DAY(日期)** | 提取日(1-31) | 15 | 按日统计 |
| **QUARTER(日期)** | 提取季度(1-4) | 4 | 按季度统计 |
| **WEEKDAY(日期)** | 提取星期(0-6) | 0 | 判断星期几 |
| **DATEFORMAT(日期, 格式)** | 格式化日期 | 2023年10月 | 自定义显示格式 |

**详细对比:**

```js
// 假设日期为:2023-10-15(周日)

YEAR("2023-10-15")       // 返回:2023
MONTH("2023-10-15")      // 返回:10
DAY("2023-10-15")        // 返回:15
QUARTER("2023-10-15")    // 返回:4
WEEKDAY("2023-10-15")    // 返回:0
DATEFORMAT("2023-10-15", "YYYY年MM月")  // 返回:"2023年10月"
```

## 八、注意事项

### ⚠️ 返回值范围是1-12

```js
MONTH("2023-01-01")  // 返回:1(不是0)
MONTH("2023-12-31")  // 返回:12(不是13)
```

### ⚠️ 只判断月份可能不够准确

不同年份的同一月份会返回相同值:

```js
MONTH("2023-10-15")  // 返回:10
MONTH("2024-10-15")  // 返回:10(相同)

// ✅ 判断是否同月需要同时比较年份
YEAR(日期1) == YEAR(日期2) && MONTH(日期1) == MONTH(日期2)
```

### ⚠️ 月份数字可能需要补零

显示时可能需要格式化:

```js
MONTH("2023-01-15")  // 返回:1(不是"01")

// 如需"01"格式
IF(MONTH(日期) < 10,
   CONCATENATE("0", MONTH(日期)),
   MONTH(日期))
```

### ⚠️ 计算月份差要考虑年份

```js
// ❌ 错误:只看月份
MONTH("2024-01-15") - MONTH("2023-12-15")
// 返回:-11,但实际只差1个月

// ✅ 正确:考虑年份
(YEAR("2024-01-15") - YEAR("2023-12-15")) * 12 +
(MONTH("2024-01-15") - MONTH("2023-12-15"))
// 返回:1
```

### ⚠️ 参数必须是有效日期

```js
MONTH("abc")  // 错误
MONTH("")     // 错误

// ✅ 安全做法
IF(ISNULL(日期), 0, MONTH(日期))
```
