# 「「云之家」」计算公式之 RIGHT 函数

## 一、函数作用

`RIGHT` 函数用来**从文本右侧提取字符**,简单来说就是:
- 从文本末尾提取指定数量的字符
- 就像从右边"剪切"文本
- 常用于提取编号后缀、文件扩展名、尾号等

---

## 二、语法格式

```
RIGHT(文本, 字符数量)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 文本 | 要提取字符的原始文本,可以是:<br>• 文本字符串<br>• 文本控件<br>• 编号控件 | ✅ 必填 | RIGHT("ORD2023001", 3) |
| 字符数量 | 要提取的字符个数,必须是正整数 | ✅ 必填 | 3 |

### 返回值

- **正常情况**:返回文本右侧指定数量的字符
- **字符数量超过文本长度**:返回完整文本
- **字符数量为0**:返回空字符串
- **文本为空**:返回空字符串

---

## 三、实用示例

### 示例 1:基本用法

```js
RIGHT("云之家", 1)              // 返回:"家"
RIGHT("云之家", 2)              // 返回:"之家"
RIGHT("Hello World", 5)        // 返回:"World"
RIGHT("2023-12-25", 2)         // 返回:"25"
```

### 示例 2:提取订单序号

假设有【订单编号】字段:

| 订单名称 | 订单编号 | 序号 |
|---------|---------|------|
| 订单A | ORD2023001 | RIGHT("ORD2023001", 3) = **"001"** |
| 订单B | ORD2023002 | RIGHT("ORD2023002", 3) = **"002"** |
| 订单C | ORD2023003 | RIGHT("ORD2023003", 3) = **"003"** |

```js
// 提取序号(后3位)
RIGHT(订单编号, 3)

// 提取年份+序号(后7位)
RIGHT(订单编号, 7)  // 例如:"2023001"
```

### 示例 3:提取文件扩展名

```js
// 提取文件扩展名(假设格式固定)
RIGHT("报告.pdf", 3)           // 返回:"pdf"
RIGHT("图片.jpg", 3)           // 返回:"jpg"
RIGHT("文档.docx", 4)          // 返回:"docx"
```

### 示例 4:提取尾号

```js
// 提取手机号后4位
RIGHT("13812345678", 4)        // 返回:"5678"

// 提取身份证后4位
RIGHT("440305199001011234", 4) // 返回:"1234"

// 提取银行卡后4位
RIGHT("6222021234567890", 4)   // 返回:"7890"
```

### 示例 5:提取日期部分

```js
// 从日期编号提取日(后2位)
RIGHT("20231225", 2)           // 返回:"25"

// 提取月日(后4位)
RIGHT("20231225", 4)           // 返回:"1225"
```

## 四、实际业务场景

### 场景 1:隐私保护显示

显示部分信息,保护隐私:

```js
// 【手机号显示】只显示后4位
CONCATENATE("****", RIGHT(手机号, 4))
// "13812345678" -> "****5678"

// 【身份证显示】只显示后4位
CONCATENATE("****************", RIGHT(身份证号, 4))
// "440305199001011234" -> "****************1234"
```

### 场景 2:订单流水号提取

```js
// 【流水号】提取订单编号最后3位
RIGHT(订单编号, 3)  // 从"ORD2023001"提取"001"

// 【当日序号】提取后4位
RIGHT(订单编号, 4)  // 从"20231225-0123"提取"0123"
```

### 场景 3:文件类型判断

```js
// 【文件类型】提取扩展名判断
IF(RIGHT(文件名, 3) == "pdf", "PDF文档",
   IF(RIGHT(文件名, 3) == "jpg", "图片文件",
      IF(RIGHT(文件名, 4) == "docx", "Word文档", "其他")))

// 【是否为图片】
RIGHT(文件名, 3) == "jpg" || RIGHT(文件名, 3) == "png"
```

### 场景 4:年份提取

```js
// 【年份】从日期编码提取年份(后4位)
RIGHT(编码, 4)  // 从"订单-2023"提取"2023"

// 【季度标识】提取最后一位
RIGHT(季度编码, 1)  // 从"2023Q1"提取"1"
```

### 场景 5:编号校验

```js
// 【校验位】提取编号最后一位用于校验
RIGHT(商品编码, 1)

// 【批次号】提取后6位
RIGHT(生产批号, 6)
```

## 五、常见问题

### 如果字符数量超过文本长度会怎样?

返回完整文本,不会报错。

```js
RIGHT("云之家", 10)    // 返回:"云之家"(只有3个字符)
RIGHT("abc", 100)     // 返回:"abc"
```

### 如果字符数量为0或负数?

字符数量为0返回空字符串,负数可能报错或返回空。

```js
RIGHT("云之家", 0)     // 返回:""(空字符串)
```

### 如果文本为空会怎样?

返回空字符串。

```js
RIGHT("", 5)          // 返回:""
RIGHT(空控件, 3)      // 返回:""
```

### 中英文字符计算有区别吗?

没有区别,每个字符都算一个长度。

```js
RIGHT("abc", 2)       // 返回:"bc"(2个字符)
RIGHT("你好", 1)      // 返回:"好"(1个字符)
RIGHT("a中b", 2)      // 返回:"中b"(2个字符)
```

### 如何提取固定分隔符后的内容?

结合 FIND 函数或固定位数:

```js
// 方法1:如果格式固定,直接指定位数
RIGHT("A001-2023", 4)  // 返回:"2023"

// 方法2:配合其他函数动态查找
// 提取最后一个"-"之后的内容
```

## 六、搭配使用技巧

### 技巧 1:结合 IF 判断文件类型

```js
// 根据文件扩展名自动分类
IF(RIGHT(文件名, 3) == "pdf", "文档",
   IF(RIGHT(文件名, 3) == "jpg" || RIGHT(文件名, 3) == "png", "图片",
      IF(RIGHT(文件名, 3) == "mp4", "视频", "其他")))
```

### 技巧 2:隐私信息脱敏

```js
// 手机号脱敏:保留后4位
CONCATENATE("****", RIGHT(手机号, 4))

// 姓名脱敏:保留姓氏,名字用*代替
CONCATENATE(LEFT(姓名, 1), "**")
```

### 技巧 3:提取年月日

```js
// 从"20231225"格式提取日期部分
CONCATENATE(
  LEFT(日期编码, 4), "年",
  RIGHT(LEFT(日期编码, 6), 2), "月",
  RIGHT(日期编码, 2), "日"
)
// 结果:"2023年12月25日"
```

### 技巧 4:验证尾号

```js
// 验证手机号后4位是否匹配
RIGHT(手机号, 4) == "5678"

// 验证序号是否为001
RIGHT(订单编号, 3) == "001"
```

### 技巧 5:组合LEFT和RIGHT

```js
// 提取首尾字符
CONCATENATE(LEFT(文本, 1), RIGHT(文本, 1))
// "云之家" -> "云家"

// 去掉首尾字符(通过长度计算)
// 需要配合其他函数实现
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **LEFT** | 从左侧提取 | LEFT("云之家", 2) | "云之" |
| **RIGHT** | 从右侧提取 | RIGHT("云之家", 2) | "之家" |
| **FIND** | 提取中间内容 | FIND("A-云之家-B", "A-", "-B") | "云之家" |
| **LEN** | 计算长度 | LEN("云之家") | 3 |

**详细对比:**

假设文本为"ORD2023001":

```js
LEFT("ORD2023001", 3)        // 返回:"ORD"(从左边取3个)
RIGHT("ORD2023001", 3)       // 返回:"001"(从右边取3个)
LEN("ORD2023001")            // 返回:10(总长度)
```

**记忆方法:**
- LEFT = 左边(Left)
- RIGHT = 右边(Right)
- LEN = 长度(Length)

## 八、RIGHT 和 LEFT 的组合使用

### 提取中间部分

```js
// 示例:从"2023-12-25"中提取月份"12"
// 方法:先用LEFT提取到月份结束,再用RIGHT提取2位
// LEFT("2023-12-25", 7) -> "2023-12"
// RIGHT("2023-12", 2) -> "12"
```

### 提取首尾字符

```js
// 提取首字符
LEFT(文本, 1)                // "云之家" -> "云"

// 提取尾字符
RIGHT(文本, 1)               // "云之家" -> "家"

// 判断首尾是否相同
LEFT(文本, 1) == RIGHT(文本, 1)
```

### 验证格式

```js
// 验证订单编号格式:ORD开头,001结尾
LEFT(订单编号, 3) == "ORD" && RIGHT(订单编号, 3) == "001"

// 验证文件名:必须以.pdf结尾
RIGHT(文件名, 4) == ".pdf"
```

### 智能显示

```js
// 根据长度智能显示
IF(LEN(手机号) > 7,
   CONCATENATE(LEFT(手机号, 3), "****", RIGHT(手机号, 4)),
   手机号)
// 超过7位才脱敏
```

## 九、实用模板

### 模板 1:身份证脱敏

```js

```

### 模板 2:银行卡脱敏

```js

// "6222021234567890" -> "**** **** **** 7890"
```

### 模板 3:提取文件扩展名

```js
// 判断文件类型
IF(RIGHT(文件名, 4) == ".pdf", "PDF文档",
   IF(RIGHT(文件名, 4) == ".doc", "Word文档",
      IF(RIGHT(文件名, 5) == ".docx", "Word文档",
         IF(RIGHT(文件名, 4) == ".xls", "Excel表格", "其他"))))
```

### 模板 4:序号递增检查

```js
// 检查序号是否连续(配合其他逻辑)
RIGHT(当前编号, 3) == RIGHT(上一编号, 3) + 1
```
