# 「「云之家」」计算公式之 LEN 函数

## 一、函数作用

`LEN` 函数用来**计算文本长度**,简单来说就是:
- 统计文本有多少个字符
- 中英文字符都算1个长度
- 常用于验证输入长度、判断文本是否为空等

---

## ⚠️ 使用限制

- **只接受文本类型**：`LEN(123)` 返回 0，数字不会自动转文本。需写成 `LEN("123")`
- **数字输入框/金额输入框需先用 TEXT 转换**：`LEN(TEXT(数字输入框))`

---

## 二、语法格式

```
LEN(文本)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 文本 | 要计算长度的文本,可以是:<br>• 文本字符串<br>• 文本控件 | ✅ 必填 | LEN("云之家") |

### 返回值

- **正常情况**:返回文本的字符个数(数字)
- **空文本**:返回 0

---

## 三、实用示例

### 示例 1:基本用法

```js
LEN("云之家")              // 返回:3
LEN("Hello World")        // 返回:11(包含空格)
LEN("abc")                // 返回:3
LEN("")                   // 返回:0(空字符串)
```

### 示例 2:中英文混合

```js
LEN("不包含")              // 返回:3
LEN("不包含aa")            // 返回:5
LEN("Hello世界")          // 返回:7(5个英文+2个中文)
LEN("a中b英c")            // 返回:5
```

### 示例 3:数字长度

```js
LEN("123456")             // 返回:6
LEN("2023")               // 返回:4
LEN("13812345678")        // 返回:11
```

### 示例 4:验证输入

假设有【用户名】和【密码】字段:

| 用户名 | 密码 | 用户名长度 | 密码长度 |
|-------|------|----------|---------|
| admin | 123456 | LEN("admin") = **5** | LEN("123456") = **6** |
| user | password | LEN("user") = **4** | LEN("password") = **8** |
| test | abc123 | LEN("test") = **4** | LEN("abc123") = **6** |

```js
// 检查用户名长度
LEN(用户名)

// 检查密码长度是否符合要求
LEN(密码) >= 6
```

### 示例 5:统计明细表数据

```js
// 统计备注字数
LEN(备注)

// 统计商品名称长度
LEN(商品名称)
```

## 四、实际业务场景

### 场景 1:表单验证

验证输入长度是否符合要求:

```js
// 【用户名长度是否合格】3-20个字符
LEN(用户名) >= 3 && LEN(用户名) <= 20

// 【密码长度是否合格】至少6位
LEN(密码) >= 6

// 【手机号是否正确】必须11位
LEN(手机号) == 11

// 【身份证号是否正确】必须18位
LEN(身份证号) == 18
```

### 场景 2:数据完整性检查

```js
// 【备注是否填写】检查备注是否为空
LEN(备注) > 0

// 【地址是否完整】至少10个字符
LEN(详细地址) >= 10

// 【描述是否详细】至少30个字符
LEN(商品描述) >= 30
```

```js

CONCATENATE("标题长度:", LEN(标题), "字")
// 例如:"标题长度:15字"

// 【内容字数】

```

### 场景 4:长度限制提示

```js
// 【超长提示】
IF(LEN(备注) > 200, "备注过长,请控制在200字以内", "")

// 【字数不足提示】

```

### 场景 5:编码验证

```js

LEN(产品编码) == 9

// 【订单号格式】必须10位
LEN(订单号) == 10
```

## 五、常见问题

### 空格算不算长度?

算,空格也是一个字符。

```js
LEN("Hello World")     // 返回:11(包含中间的空格)
LEN("  abc  ")         // 返回:7(包含前后空格)
LEN(" ")               // 返回:1(一个空格)
```

### 中英文字符计算有区别吗?

没有区别,每个字符都算1个长度。

```js
LEN("abc")             // 返回:3
LEN("中文字")           // 返回:3
LEN("a中b文c")          // 返回:5
```

### 如果参数为空会怎样?

返回 0。

```js
LEN("")                // 返回:0
LEN(空控件)             // 返回:0
```

### 数字类型会怎样？

LEN 只接受文本类型，数字不会自动转换为文本：

```js
LEN(123)               // 返回:0（非文本，直接返回0）
LEN(2023)              // 返回:0
LEN(12.5)              // 返回:0
```

如果需要计算数字位数，可以先将数字转为文本：

```js
LEN("123")             // 返回:3（字符串形式）
LEN("2023")            // 返回:4
LEN("12.5")            // 返回:4
```

### LEN 和 COUNT 有什么区别?

在处理文本时,LEN 和 COUNT 功能相同:

```js
LEN("云之家")          // 返回:3
COUNT("云之家")        // 返回:3
```

但 COUNT 功能更多,还可以统计明细表行数和数组长度:

```js
COUNT(订单明细.商品名称)  // 统计明细表行数
COUNT([1, 2, 3])         // 统计数组长度
```

**建议**:
- 计算文本长度用 **LEN**(更语义化)
- 统计明细表行数或数组长度用 **COUNT**

### 换行符算长度吗?

如果文本中包含换行符,换行符也算一个字符。

```js
LEN("第一行\n第二行")   // 返回:7(包含换行符\n)
```

## 六、搭配使用技巧

### 技巧 1:结合 IF 做长度验证

```js
// 验证用户名长度
IF(LEN(用户名) < 3, "用户名至少3个字符",
   IF(LEN(用户名) > 20, "用户名最多20个字符", ""))

// 验证密码强度
IF(LEN(密码) < 6, "密码至少6位",
   IF(LEN(密码) >= 12, "强密码", "中等强度"))
```

### 技巧 2:计算剩余字数

```js
// 显示剩余可输入字数(限制200字)
CONCATENATE("还可输入", 200 - LEN(内容), "字")
// 例如:"还可输入80字"

// 进度提示
CONCATENATE(LEN(内容), "/200字")
// 例如:"120/200字"
```

### 技巧 3:判断是否为空

```js
// 判断字段是否填写
IF(LEN(备注) > 0, "已填写", "未填写")

// 判断是否有效输入
LEN(输入内容) > 0 && LEN(输入内容) <= 500
```

### 技巧 4:格式验证

```js
// 验证手机号格式(11位数字)
LEN(手机号) == 11

// 验证身份证格式(18位)
LEN(身份证号) == 18

// 验证邮政编码(6位)
LEN(邮编) == 6
```

### 技巧 5:字数统计显示

```js
// 显示标题字数
CONCATENATE(标题, " (", LEN(标题), "字)")
// 例如:"产品介绍 (4字)"

// 显示内容摘要和字数
CONCATENATE(LEFT(内容, 20), "...", " 共", LEN(内容), "字")
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **LEN** | 计算文本长度 | LEN("云之家") | 3 |
| **COUNT** | 统计数量(文本/数组/明细) | COUNT("云之家") | 3 |
| **LEFT** | 提取左侧字符 | LEFT("云之家", 2) | "云之" |
| **RIGHT** | 提取右侧字符 | RIGHT("云之家", 2) | "之家" |

**详细对比:**

```js
// LEN:计算长度
LEN("云之家")              // 返回:3

// COUNT:统计数量
COUNT("云之家")            // 返回:3(文本长度)
COUNT(订单明细.商品名称)    // 返回:5(明细表行数)
COUNT([1, 2, 3])          // 返回:3(数组长度)

// LEFT:提取字符
LEFT("云之家", 2)          // 返回:"云之"

// RIGHT:提取字符
RIGHT("云之家", 2)         // 返回:"之家"
```

**记忆方法:**
- LEN = 长度(Length)
- COUNT = 计数(Count)
- LEFT = 左边(Left)
- RIGHT = 右边(Right)

## 八、常见应用模式

### 模式 1:多级长度验证

```js
// 根据长度分级
IF(LEN(内容) == 0, "未填写",
   IF(LEN(内容) < 10, "过短",
      IF(LEN(内容) < 50, "简短",
         IF(LEN(内容) < 200, "适中", "详细"))))
```

### 模式 2:长度限制提示

```js
// 显示输入状态
IF(LEN(备注) == 0, "请输入备注",
   IF(LEN(备注) > 200, "超出字数限制",
      CONCATENATE("已输入", LEN(备注), "字")))
```

### 模式 3:格式校验组合

```js
// 手机号完整验证
LEN(手机号) == 11 && LEFT(手机号, 1) == "1"

// 身份证验证
LEN(身份证号) == 18 && MATCH(身份证号, "^\\d{17}[\\dXx]$")
```

### 模式 4:必填项检查

```js
// 检查多个必填项
LEN(姓名) > 0 && LEN(手机号) == 11 && LEN(地址) >= 10
```

### 模式 5:字数统计仪表盘

```js
// 显示多个字段的字数统计
CONCATENATE(
  "标题:", LEN(标题), "字 ",
  "内容:", LEN(内容), "字 ",
  "备注:", LEN(备注), "字"
)
```

## 九、实用验证模板

### 模板 1:用户名验证

```js
// 用户名必须3-20个字符
IF(LEN(用户名) == 0, "请输入用户名",
   IF(LEN(用户名) < 3, "用户名至少3个字符",
      IF(LEN(用户名) > 20, "用户名最多20个字符", "✓")))
```

### 模板 2:密码强度检查

```js
// 密码强度分级
IF(LEN(密码) < 6, "弱密码",
   IF(LEN(密码) < 10, "中等密码",
      IF(LEN(密码) >= 12, "强密码", "较强密码")))
```

### 模板 3:手机号验证

```js
// 完整的手机号验证
IF(LEN(手机号) == 0, "请输入手机号",
   IF(LEN(手机号) != 11, "手机号必须11位", "✓"))
```

### 模板 4:内容字数提示

```js
// 限制200字的输入提示
IF(LEN(内容) > 200, "超出限制,请删减至200字以内",
   CONCATENATE("已输入", LEN(内容), "字,还可输入", 200 - LEN(内容), "字"))
```

### 模板 5:批量长度检查

```js
// 检查多个字段长度是否符合要求
IF(LEN(标题) == 0, "标题不能为空",
   IF(LEN(标题) > 50, "标题不能超过50字",
      IF(LEN(内容) < 100, "内容至少100字", "✓")))
```
