# 「「云之家」」计算公式之 ADDDAY 函数

## 一、函数作用

`ADDDAY` 函数用来**在指定日期上增加或减少天数**，简单来说就是：
- 向后推算：加上正数天数（例如：今天加7天 = 下周）
- 向前推算：加上负数天数（例如：今天减7天 = 上周）

常用于计算截止日期、还款日期、到期日等场景。

---

## 二、语法格式

```
ADDDAY(日期, 天数)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 日期 | 原始日期，可以是日期控件、日期字符串、时间戳 | ✅ 必填 | ADDDAY("2023-01-01", 30) |
| 天数 | 要增加的天数，正数表示向后推算，负数表示向前推算 | ✅ 必填 | ADDDAY("2023-01-01", -7) |

### 返回值

- **正常情况**：返回计算后的新日期（格式与输入日期格式一致）
- **特殊情况**：如果日期参数无效，返回**空**

---

## 三、实用示例

### 示例 1：基本用法

```js
ADDDAY("2023-01-01", 30)     // 返回：2023-01-31（30天后）
ADDDAY("2023-01-01", -7)     // 返回：2022-12-25（7天前）
ADDDAY("2023/02/01", 15)     // 返回：2023/02/16（15天后）
ADDDAY("2023-01-01", 0)      // 返回：2023-01-01（不变）
```

### 示例 2：计算项目截止日期

假设有【项目计划】表，包含【开始日期】和【工期天数】：

```js
ADDDAY(开始日期, 工期天数)
```

### 示例 3：计算还款日期

假设【借款日期】为 2023-03-15，借款期限为30天：

```js
ADDDAY(借款日期, 30)
```

### 示例 4：计算过去的日期

```js
// 计算7天前的日期
ADDDAY("2023-01-15", -7)     // 返回：2023-01-08

// 计算30天前的日期
ADDDAY("2023-03-01", -30)    // 返回：2023-01-30
```

## 四、实际业务场景

### 场景 1：合同到期提醒

在合同管理中，计算合同到期日：

```js
// 【合同到期日】的计算公式
ADDDAY(合同签订日期, 合同期限天数)
```

**示例：**
- 签订日期：2023-01-01
- 合同期限：365天
- 到期日期：ADDDAY("2023-01-01", 365) = **2023-12-31**

### 场景 2：订单发货时效

计算预计送达日期：

```js
// 【预计送达日期】的计算公式
ADDDAY(下单日期, 物流时长)
```

### 场景 3：任务提前提醒

计算任务开始前的提醒日期：

```js
// 【提醒日期】的计算公式
ADDDAY(任务开始日期, -3)  // 提前3天提醒
```

### 场景 4：保质期计算

计算产品过期日期：

```js
// 【过期日期】的计算公式
ADDDAY(生产日期, 保质期天数)
```

## 五、常见问题

### ❓ 如果日期参数为空会怎样？

如果日期控件没有填写，函数返回**空**，不会报错。

```js
ADDDAY("", 7)        // 返回：空
ADDDAY(空控件, 30)    // 返回：空
```

### ❓ 如果天数为0会怎样？

返回原始日期，日期不变。

```js
ADDDAY("2023-01-01", 0)   // 返回：2023-01-01
```

### ❓ 支持哪些日期格式？

支持常见的日期格式：

```js
ADDDAY("2023-01-01", 7)      // ✅ 支持：YYYY-MM-DD
ADDDAY("2023/01/01", 7)      // ✅ 支持：YYYY/MM/DD
ADDDAY("2023-1-1", 7)        // ✅ 支持：简写格式
ADDDAY(1672531200000, 7)     // ✅ 支持：时间戳（毫秒）
```

### ❓ 会自动处理跨月、跨年吗？

会自动处理！不需要担心月份天数和年份变化。

```js
// 跨月
ADDDAY("2023-01-28", 5)    // 返回：2023-02-02（自动跨到2月）

// 跨年
ADDDAY("2023-12-25", 10)   // 返回：2024-01-04（自动跨到2024年）

// 闰年
ADDDAY("2024-02-28", 1)    // 返回：2024-02-29（2024是闰年）
```

### ❓ 能计算工作日吗？

不能。ADDDAY 计算的是自然日（包括周末和节假日）。

如果需要计算工作日，需要自己排除周末和节假日。

## 六、搭配使用技巧

### 技巧 1：结合 TODAY 函数计算相对日期

```js
// 计算7天后的日期
ADDDAY(TODAY(), 7)

// 计算30天前的日期
ADDDAY(TODAY(), -30)
```

### 技巧 2：结合 IF 函数判断是否超期

```js
// 判断是否已过期
IF(TODAY() > ADDDAY(生产日期, 保质期天数), "已过期", "未过期")
```

### 技巧 3：计算区间

```js
// 计算项目起止区间
// 开始日期
开始日期

// 结束日期
ADDDAY(开始日期, 30)
```

### 技巧 4：结合 DAYS 函数计算剩余天数

```js
// 计算距离到期还有多少天
DAYS(ADDDAY(开始日期, 30), TODAY())
```

## 七、与其他日期函数的区别

| 函数 | 作用 | 示例 |
|------|------|------|
| ADDDAY(日期, 天数) | 增加或减少天数 | ADDDAY("2023-01-01", 7) = 2023-01-08 |
| ADDMONTH(日期, 月数) | 增加或减少月份 | ADDMONTH("2023-01-01", 2) = 2023-03-01 |
| ADDYEAR(日期, 年数) | 增加或减少年份 | ADDYEAR("2023-01-01", 1) = 2024-01-01 |
| DAYS(结束日期, 开始日期) | 计算两个日期间隔的天数 | DAYS("2023-01-08", "2023-01-01") = 7 |

## 八、注意事项

### ⚠️ 日期格式一致性

确保日期格式正确，避免无效日期：

```js
// ✅ 正确
ADDDAY("2023-01-01", 7)

// ❌ 错误格式
ADDDAY("2023/1/1", 7)      // 部分系统可能不支持
ADDDAY("01-01-2023", 7)    // 不推荐的格式
```

### ⚠️ 天数参数必须是数字

```js
// ✅ 正确
ADDDAY("2023-01-01", 7)
ADDDAY("2023-01-01", -7)

// ❌ 错误
ADDDAY("2023-01-01", "7")   // 字符串可能导致错误
```

### ⚠️ 与日期控件结合使用

当使用日期控件时，确保控件已填写：

```js
// ✅ 推荐：先判断是否为空
IF(ISNULL(开始日期), "", ADDDAY(开始日期, 30))

// ❌ 不推荐：直接使用可能返回空
ADDDAY(开始日期, 30)
```
