# 「「云之家」」计算公式之 FIND 函数

## 一、函数作用

`FIND` 函数用来**提取文本中间的内容**,简单来说就是:
- 从文本中提取指定开始和结束字符之间的内容
- 类似于"剪刀",从标记处剪切出中间部分
- 常用于解析格式化文本、提取特定信息

---

## 二、语法格式

```
FIND(文本, 开始字符, 结束字符)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 文本 | 要从中提取内容的原始文本 | ✅ 必填 | FIND("ID:001-NAME:测试", "NAME:", "-") |
| 开始字符 | 提取内容的起始标记,函数会从这个字符**之后**开始提取 | ⭕ 可选 | "NAME:" |
| 结束字符 | 提取内容的结束标记,函数会提取到这个字符**之前**的内容 | ⭕ 可选 | "-" |

### 返回值

- **正常情况**:返回开始字符和结束字符之间的内容
- **开始字符为空**:从文本开头提取到结束字符之前
- **结束字符为空**:从开始字符之后提取到文本末尾
- **都为空**:返回完整文本
- **未找到标记**:返回空字符串

---

## 三、实用示例

### 示例 1:基本用法

```js
// 提取中间内容
FIND("ID:001-NAME:测试订单-AMT:100", "NAME:", "-AMT")
// 返回:"测试订单"

// 从开头提取到指定字符
FIND("2023-01-15", "", "-")
// 返回:"2023"

// 从指定字符提取到结尾
FIND("不包含", "不", "")
// 返回:"包含"
```

### 示例 2:提取订单信息

假设有【订单详情】字段,格式为"ID:ORD001-NAME:测试订单-AMT:100":

| 订单号 | 订单详情 | 订单名称 | 订单金额 |
|-------|---------|---------|---------|
| 001 | ID:ORD001-NAME:测试订单-AMT:100 | FIND(..., "NAME:", "-AMT") = **"测试订单"** | FIND(..., "AMT:", "") = **"100"** |
| 002 | ID:ORD002-NAME:采购订单-AMT:200 | FIND(..., "NAME:", "-AMT") = **"采购订单"** | FIND(..., "AMT:", "") = **"200"** |

```js
// 提取订单ID
FIND(订单详情, "ID:", "-NAME")  // 返回:"ORD001"

// 提取订单名称
FIND(订单详情, "NAME:", "-AMT")  // 返回:"测试订单"

// 提取订单金额
FIND(订单详情, "AMT:", "")  // 返回:"100"
```

### 示例 3:解析日期

```js
// 从"2023-01-15"提取年份
FIND("2023-01-15", "", "-")        // 返回:"2023"

// 从"2023-01-15"提取月份
FIND("2023-01-15", "-", "-")       // 返回:"01"(第一个"-"到第二个"-")

// 从"2023/01/15"提取日
FIND("2023/01/15", "/", "")        // 返回:"01/15"
```

### 示例 4:提取路径信息

```js
// 从路径提取文件名
FIND("/home/user/document.pdf", "/", ".")
// 可能需要配合其他函数

// 从URL提取域名
FIND("https://www.example.com/page", "://", "/")
// 返回:"www.example.com"
```

### 示例 5:提取标签内容

```js
// 从"[重要]会议通知"提取标签
FIND("[重要]会议通知", "[", "]")  // 返回:"重要"

// 从"类别:电子产品"提取类别
FIND("类别:电子产品", ":", "")    // 返回:"电子产品"
```

## 四、实际业务场景

```js
// 【订单数量】
FIND(订单详情, "数量:", "|")  // 返回:"1"

// 【商品价格】
FIND(订单详情, "价格:", "")   // 返回:"5000"
```

```js
// 从"2023-12-25 14:30:00"提取日期部分

// 【年份】
FIND(日期时间, "", "-")  // 返回:"2023"

FIND(日期时间, " ", "")  // 返回:"14:30:00"
```

```js
// 从"user@example.com"提取信息
```

### 场景 5:消息模板解析


## 五、常见问题

### 如果开始字符或结束字符不存在会怎样?

返回空字符串。

```js
FIND("abc", "x", "y")     // 返回:""(找不到"x")
FIND("abc", "a", "x")     // 返回:""(找不到"x")
```

### 如果有多个相同的标记字符?

通常会匹配第一次出现的位置。

```js
FIND("abc+def+ghi", "+", "+")
// 返回:"def"(第一个"+"到第二个"+")
```

### 开始和结束字符都为空会怎样?

返回完整文本。

```js
FIND("云之家", "", "")     // 返回:"云之家"
```

### 只有开始字符,没有结束字符?

从开始字符之后提取到文本末尾。

```js
FIND("ID:ORD001", "ID:", "")   // 返回:"ORD001"
FIND("价格:100元", "价格:", "")  // 返回:"100元"
```

### 只有结束字符,没有开始字符?

从文本开头提取到结束字符之前。

```js
FIND("2023-01-15", "", "-")    // 返回:"2023"
FIND("user@example.com", "", "@")  // 返回:"user"
```

### 如何提取最后一个分隔符之后的内容?

这需要更复杂的逻辑,可能需要配合其他函数:

```js
// 简单情况:如果格式固定
FIND("a+b+c", "+", "")  // 返回:"b+c"(不是最理想)

// 可能需要使用其他方法
```

## 六、搭配使用技巧

### 技巧 1:结合 IF 处理提取结果

```js
// 提取后判断是否有效
IF(LEN(FIND(订单详情, "AMT:", "")) > 0,
   FIND(订单详情, "AMT:", ""),
   "未填写金额")
```

### 技巧 2:多层提取

```js
// 先提取大段,再提取小段
// 从"订单[ID:001,AMT:100]"中提取金额
// 第一步:提取方括号内容
FIND(订单信息, "[", "]")  // 返回:"ID:001,AMT:100"
// 第二步:从结果中提取金额
FIND(FIND(订单信息, "[", "]"), "AMT:", "")  // 返回:"100"
```

### 技巧 3:提取后转换类型

```js
// 提取金额后转为数字
VALUE(FIND(订单详情, "AMT:", ""))

// 提取日期后格式化
DATEFORMAT(FIND(记录, "日期:", "|"), "yyyy-MM-dd")
```

### 技巧 4:组合多个提取结果

```js
// 重组信息
CONCATENATE(
  "客户:", FIND(订单详情, "客户:", "|"),
  " 金额:", FIND(订单详情, "金额:", "")
)
```

### 技巧 5:提取并验证

```js
// 提取邮箱域名并验证
IF(FIND(邮箱, "@", "") == "example.com", "内部邮箱", "外部邮箱")
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **FIND** | 提取中间内容 | FIND("A-云之家-B", "A-", "-B") | "云之家" |
| **LEFT** | 提取左侧字符 | LEFT("云之家", 2) | "云之" |
| **RIGHT** | 提取右侧字符 | RIGHT("云之家", 2) | "之家" |
| **CONTAINS** | 检查是否包含 | CONTAINS("云之家", "之") | true |

**详细对比:**

假设文本为"ID:ORD001-NAME:测试":

```js
// FIND:提取中间内容
FIND("ID:ORD001-NAME:测试", "ID:", "-NAME")  // 返回:"ORD001"
FIND("ID:ORD001-NAME:测试", "NAME:", "")     // 返回:"测试"

// LEFT:提取左侧
LEFT("ID:ORD001-NAME:测试", 2)               // 返回:"ID"

// RIGHT:提取右侧
RIGHT("ID:ORD001-NAME:测试", 2)              // 返回:"测试"

// CONTAINS:检查包含
CONTAINS("ID:ORD001-NAME:测试", "ORD")       // 返回:true
```

**记忆方法:**
- FIND = 查找提取(Find)
- LEFT = 左边(Left)
- RIGHT = 右边(Right)
- CONTAINS = 包含(Contains)

## 八、常见应用模式

### 模式 1:键值对解析

```js
// 格式:"key:value"
// 提取key
FIND(键值对, "", ":")

// 提取value
FIND(键值对, ":", "")
```

### 模式 2:路径分割

```js
// 从"/folder/subfolder/file.txt"提取信息
// 提取文件名(简化版)
FIND(路径, "/", ".")
```

### 模式 3:标签提取

```js
// 从"[标签]内容"提取
FIND(文本, "[", "]")  // 提取标签
FIND(文本, "]", "")   // 提取内容
```

### 模式 4:多字段提取

```js
// 格式:"字段1|字段2|字段3"
FIND(数据, "", "|")        // 第一个字段
FIND(数据, "|", "|")       // 第二个字段(如果有多个|)
FIND(数据, "|", "")        // 最后的字段
```

### 模式 5:提取并计算

```js
// 提取金额并计算
FIND(订单详情, "单价:", "|") * FIND(订单详情, "数量:", "|")
```

```js
// 提取日期
FIND(日期时间, "", " ")  // 返回:"2023-12-25"

// 提取时间
FIND(日期时间, " ", "")  // 返回:"14:30:00"
```

### 模板 3:邮箱分解

```js
// 从"user.name@company.com"提取信息

// 提取用户名
FIND(邮箱, "", "@")  // 返回:"user.name"

FIND(邮箱, "@", "")  // 返回:"company.com"
```

### 模板 4:商品编码解析

```js
// 编码格式:"类别-年份-序号",如"A-2023-001"

FIND(商品编码, "-", "-")  // 返回:"2023"(第一个到第二个"-")
```

```js

// 提取路径
```

## 十、注意事项

### 1. 标记字符的选择

选择不会在内容中出现的标记字符,避免误匹配:

```js
// 不好的例子:用"-"作为分隔符,但内容中也有"-"
FIND("2023-12-25", "-", "-")  // 可能不是期望的结果

// 好的例子:使用明确的标记
FIND("DATE:2023-12-25|TIME:14:30", "DATE:", "|")  // 明确
```

### 2. 处理不存在的标记

提取前先检查标记是否存在:

```js
IF(CONTAINS(文本, "标记:"), FIND(文本, "标记:", "|"), "未找到")
```

### 3. 嵌套使用时的可读性

嵌套过多会降低可读性,建议分步骤:

```js
// 不推荐:嵌套过深
FIND(FIND(FIND(文本, "A", "B"), "C", "D"), "E", "F")

// 推荐:分步骤,或用中间字段
```
