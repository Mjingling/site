# 「「云之家」」计算公式之 ROUND 函数

## 一、函数作用

`ROUND` 函数用来**四舍五入**，简单来说就是：
- 将数字按照指定的小数位数进行四舍五入
- 5及以上进位，5以下舍去
- 常用于价格计算、百分比显示等需要控制精度的场景

比如：将 3.1459 保留2位小数得到 3.15，将 3.1449 保留2位小数得到 3.14。

---

## 二、语法格式

```
ROUND(数字, 保留位数)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 数字 | 要四舍五入的数字，可以是数字控件、金额控件、运算控件 | ✅ 必填 | ROUND(3.1459, 2) |
| 保留位数 | 要保留的小数位数，大于等于0，默认值为0 | ❌ 可选 | 2 表示保留2位小数 |

### 返回值

- **正常情况**：返回四舍五入后的数字
- **特殊情况**：如果参数不是数字，返回**空**；保留位数小于0时视为0

---

## 三、实用示例

### 示例 1：基本用法

```js
ROUND(3.1459, 2)   // 返回：3.15
ROUND(3.1449, 2)   // 返回：3.14
ROUND(2.5, 0)      // 返回：3
ROUND(3.14159, 3)  // 返回：3.142
```

### 示例 2：价格计算

假设有【商品价格】和【折扣】：

| 商品名称 | 原价  | 折扣 |
|---------|------|------|
| 商品A   | 99.99 | 0.85 |
| 商品B   | 158.8 | 0.9  |
| 商品C   | 299  | 0.75 |

```js
// 计算折后价，保留2位小数
ROUND(原价 * 折扣, 2)
```

**结果示例：**
- 商品A：ROUND(99.99 * 0.85, 2) = **84.99**
- 商品B：ROUND(158.8 * 0.9, 2) = **142.92**
- 商品C：ROUND(299 * 0.75, 2) = **224.25**

### 示例 3：百分比计算

```js
// 计算完成率，保留2位小数
ROUND((已完成数 / 总任务数) * 100, 2)
```

假设已完成 23 个，总任务 30 个：
```js
ROUND((23 / 30) * 100, 2)  // 返回：76.67
```

### 示例 4：平均值计算

假设有【学生成绩明细】：

| 学生 | 成绩 |
|-----|------|
| 张三 | 85  |
| 李四 | 92  |
| 王五 | 78  |

```js
// 计算平均分，保留2位小数
ROUND(AVERAGE(成绩明细.成绩), 2)
```

**结果：85.00**

### 示例 5：金额分摊

```js
// 平均分摊金额，保留2位小数
ROUND(总金额 / 人数, 2)
```

假设总金额 1000 元，3 个人分摊：
```js
ROUND(1000 / 3, 2)  // 返回：333.33
```

### 示例 6：不同精度的四舍五入

```js
ROUND(3.14159, 1)  // 返回：3.1
ROUND(3.14159, 2)  // 返回：3.14
ROUND(3.14159, 3)  // 返回：3.142
ROUND(3.14159, 4)  // 返回：3.1416
```

## 四、实际业务场景

### 场景 1：订单金额计算

在订单系统中，计算优惠后的实付金额：

```js
// 【实付金额】的计算公式
ROUND(订单总额 * 折扣, 2)

// 【优惠金额】的计算公式
ROUND(订单总额 * (1 - 折扣), 2)
```

### 场景 2：绩效考核

计算员工绩效得分：

```js
// 【综合得分】保留2位小数
ROUND(AVERAGE(工作态度得分, 业务能力得分, 团队协作得分), 2)

// 【绩效系数】保留3位小数
ROUND(实际完成数 / 目标完成数, 3)
```

### 场景 3：库存周转率

```js
// 【库存周转率】保留2位小数
ROUND(销售数量 / 平均库存, 2)
```

### 场景 4：税费计算

```js
// 【税额】保留2位小数
ROUND(商品总额 * 税率, 2)

// 【含税价】保留2位小数
ROUND(商品总额 * (1 + 税率), 2)
```

## 五、常见问题

### 如果参数为空会怎样？

返回**空**。

```js
ROUND("", 2)      // 返回：0
ROUND(空控件, 2)  // 返回：空
```

### 保留位数可以是0吗？

可以。保留位数为0时，将数字四舍五入到整数。

```js
ROUND(3.14, 0)    // 返回：3
ROUND(3.56, 0)    // 返回：4
ROUND(3.14, -1)   // 返回：3（负数按0处理）
```

### 如何四舍五入到整数？

直接使用 `ROUND(数字, 0)` 即可将数字四舍五入到整数。

```js
ROUND(3.14, 0)   // 返回：3
ROUND(3.56, 0)   // 返回：4
```

### ROUND 和 ROUNDUP、ROUNDDOWN 有什么区别？

| 函数 | 规则 | 示例 | 结果 |
|------|------|------|------|
| **ROUND** | 四舍五入 | ROUND(3.14, 1)<br>ROUND(3.15, 1) | 3.1<br>3.2 |
| **ROUNDUP** | 向上取整（进位） | ROUNDUP(3.14, 1)<br>ROUNDUP(3.11, 1) | 3.2<br>3.2 |
| **ROUNDDOWN** | 向下取整（舍去） | ROUNDDOWN(3.19, 1)<br>ROUNDDOWN(3.11, 1) | 3.1<br>3.1 |

### 对负数四舍五入会怎样？

负数也按照绝对值的规则四舍五入：

```js
ROUND(-3.14, 1)   // 返回：-3.1
ROUND(-3.16, 1)   // 返回：-3.2
```

## 六、搭配使用技巧

### 技巧 1：计算折扣后的总价

```js
// 先求和再打折，保留2位小数
ROUND(SUM(商品明细.单价) * 折扣, 2)
```

### 技巧 2：显示百分比

```js
// 计算合格率并显示为百分比
ROUND(合格数 / 总数 * 100, 2)
```

结果如 85.67，可以在单行文本框中拼接%符号：
```js
ROUND(合格数 / 总数 * 100, 2) + "%"  // 显示为：85.67%
```

### 技巧 3：结合 IF 判断精度

```js
// 金额大于1000时保留整数，否则保留2位小数
IF(金额 > 1000, ROUND(金额, 1), ROUND(金额, 2))
```

### 技巧 4：多步计算保持精度

```js
// 复杂计算时，最后一步才四舍五入
ROUND((收入 - 成本) / 收入 * 100, 2)
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **ROUND** | 四舍五入 | ROUND(3.1459, 2) | 3.15 |
| **ROUNDUP** | 向上取整（进位） | ROUNDUP(3.1459, 2) | 3.15 |
| **ROUNDDOWN** | 向下取整（舍去） | ROUNDDOWN(3.1459, 2) | 3.14 |
| **ABS** | 取绝对值 | ABS(-3.14) | 3.14 |

**详细对比**：

以 3.145 为例：

```js
ROUND(3.145, 2)      // 返回：3.15（四舍五入，5进位）
ROUNDUP(3.141, 2)    // 返回：3.15（向上取整，直接进位）
ROUNDDOWN(3.149, 2)  // 返回：3.14（向下取整，直接舍去）
```

**记忆方法**：
- ROUND = 四舍五入（看下一位是否≥5）
- ROUNDUP = 向上取（UP，永远进位）
- ROUNDDOWN = 向下取（DOWN，永远舍去）
