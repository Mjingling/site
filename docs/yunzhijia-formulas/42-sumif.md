# 「「云之家」」计算公式之 SUMIF 函数

## 一、函数作用

`SUMIF` 函数用来**按条件求和**，简单来说就是：
- 从一堆数据中筛选出符合条件的数据
- 将筛选出的数据进行求和
- 常用于明细表中，按条件统计某个字段的总和

比如：统计所有"优品"的数量总和、计算金额大于100元的订单总额等。

---

## 二、语法格式

```
SUMIF(明细数据, 筛选条件, 求和字段)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 明细数据 | 要筛选的明细表，通常使用"明细.控件自身" | ✅ 必填 | 产品明细.控件自身 |
| 筛选条件 | 筛选条件表达式，返回 true 的记录会被选中 | ✅ 必填 | 产品明细.等级 == "优" |
| 求和字段 | 要求和的字段，必须是数字、金额或运算控件 | ✅ 必填 | 产品明细.数量 |

### 返回值

- **正常情况**：返回符合条件的记录的求和结果
- **特殊情况**：如果没有符合条件的记录，返回 **0**

---

## 三、实用示例

### 示例 1：基本用法 - 按等级统计数量

假设有【产品明细】：

| 产品等级 | 数量 |
|---------|------|
| 优      | 10   |
| 良      | 5    |
| 良      | 4    |
| 优      | 8    |

```js
// 统计所有"良"品的数量总和
SUMIF(产品明细.控件自身, 产品明细.产品等级 == "良", 产品明细.数量)
```

**结果：9** （5 + 4）

### 示例 2：按金额大小筛选

假设有【费用明细】：

| 费用项目 | 金额  |
|---------|------|
| 交通费  | 150  |
| 餐费    | 80   |
| 住宿费  | 500  |
| 打车费  | 50   |

```js
// 统计所有金额大于100的费用总和
SUMIF(费用明细.控件自身, 费用明细.金额 > 100, 费用明细.金额)
```

**结果：650** （150 + 500）

### 示例 3：按开关状态筛选

假设有【任务明细】：

| 任务名称 | 工时 | 是否完成 |
|---------|------|---------|
| 任务A   | 8    | ✅ 是   |
| 任务B   | 5    | ❌ 否   |
| 任务C   | 6    | ✅ 是   |

```js
// 统计已完成任务的工时总和
SUMIF(任务明细.控件自身, 任务明细.是否完成 == true, 任务明细.工时)
```

**结果：14** （8 + 6）

### 示例 4：按单选框筛选

假设有【订单明细】：

| 订单编号 | 金额  | 状态   |
|---------|------|--------|
| A001    | 1000 | 已付款 |
| A002    | 500  | 未付款 |
| A003    | 800  | 已付款 |

```js
// 统计已付款订单的金额总和
SUMIF(订单明细.控件自身, 订单明细.状态 == "已付款", 订单明细.金额)
```

**结果：1800** （1000 + 800）

### 示例 5：多个条件组合

```js
// 统计金额大于100且状态为"已审批"的记录总和
SUMIF(明细.控件自身, 明细.金额 > 100 && 明细.状态 == "已审批", 明细.金额)
```

### 示例 6：按数量范围筛选

假设有【库存明细】：

| 商品名称 | 库存数量 |
|---------|---------|
| 商品A   | 50      |
| 商品B   | 150     |
| 商品C   | 80      |
| 商品D   | 200     |

```js
// 统计库存数量在100以上的商品总库存
SUMIF(库存明细.控件自身, 库存明细.库存数量 >= 100, 库存明细.库存数量)
```

**结果：350** （150 + 200）

## 四、实际业务场景

### 场景 1：产品质量统计

在产品检验表中，自动计算不同等级产品的数量和优秀率：

```js
// 【优品总数】的计算公式
SUMIF(产品明细.控件自身, 产品明细.产品等级 == "优", 产品明细.数量)

// 【良品总数】的计算公式
SUMIF(产品明细.控件自身, 产品明细.产品等级 == "良", 产品明细.数量)

// 【优秀率】的计算公式
SUMIF(产品明细.控件自身, 产品明细.产品等级 == "优", 产品明细.数量) / SUM(产品明细.数量) * 100
```

### 场景 2：费用报销统计

在报销单中，按费用类型统计不同类别的费用总额：

```js
// 【交通费总计】
SUMIF(费用明细.控件自身, 费用明细.费用类型 == "交通费", 费用明细.金额)

// 【餐费总计】
SUMIF(费用明细.控件自身, 费用明细.费用类型 == "餐费", 费用明细.金额)

// 【超标费用总计】（金额大于500的）
SUMIF(费用明细.控件自身, 费用明细.金额 > 500, 费用明细.金额)
```

### 场景 3：销售业绩统计

统计某个销售员的销售总额：

```js
// 【张三的销售总额】
SUMIF(订单明细.控件自身, 订单明细.销售员 == "张三", 订单明细.订单金额)

// 【大单总额】（订单金额大于10000的）
SUMIF(订单明细.控件自身, 订单明细.订单金额 > 10000, 订单明细.订单金额)
```

### 场景 4：考勤统计

统计员工加班时长：

```js
// 【周末加班总时长】
SUMIF(考勤明细.控件自身, 考勤明细.是否周末 == true, 考勤明细.工时)

// 【超过8小时的加班总时长】
SUMIF(考勤明细.控件自身, 考勤明细.工时 > 8, 考勤明细.工时)
```

## 五、常见问题

### 如果筛选条件没有匹配到任何记录怎么办？

返回 **0**。

```js
// 假设没有任何"次品"
SUMIF(产品明细.控件自身, 产品明细.产品等级 == "次品", 产品明细.数量)
// 返回：0
```

### 如果求和字段有空值怎么办？

空值会被当作 **0** 处理，不影响求和。

| 产品等级 | 数量  |
|---------|------|
| 优      | 10   |
| 优      | 空   |
| 优      | 5    |

```js
SUMIF(产品明细.控件自身, 产品明细.产品等级 == "优", 产品明细.数量)
// 返回：15（10 + 0 + 5）
```

### 如果明细表为空会怎样？

返回 **0**。

```js
SUMIF(空明细.控件自身, 空明细.字段 > 100, 空明细.金额)
// 返回：0
```

### 能对非数字字段求和吗？

不能。如果求和字段不是数字类型，会导致计算错误。确保求和字段是数字控件、金额控件或运算控件。

### 筛选条件可以使用哪些运算符？

可以使用以下运算符：
- **比较运算**：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于等于）
- **逻辑运算**：`&&`（并且）、`||`（或者）

## 六、搭配使用技巧

### 技巧 1：计算占比

```js
// 优品占比
SUMIF(产品明细.控件自身, 产品明细.产品等级 == "优", 产品明细.数量) / SUM(产品明细.数量) * 100
```

### 技巧 2：结合 IF 判断是否达标

```js
// 判断优品总数是否达到100
IF(SUMIF(产品明细.控件自身, 产品明细.产品等级 == "优", 产品明细.数量) >= 100, "达标", "未达标")
```

### 技巧 3：多维度统计

```js
// 统计多个等级的总和
SUMIF(产品明细.控件自身, 产品明细.产品等级 == "优", 产品明细.数量) +
SUMIF(产品明细.控件自身, 产品明细.产品等级 == "良", 产品明细.数量)
```

### 技巧 4：计算平均值

```js
// 计算优品的平均数量
SUMIF(产品明细.控件自身, 产品明细.产品等级 == "优", 产品明细.数量) /
COUNTIF(产品明细.控件自身, 产品明细.产品等级 == "优")
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **SUM** | 求所有数据的和 | SUM(明细.数量) | 所有数量的总和 |
| **SUMIF** | 按条件求和 | SUMIF(明细.控件自身, 明细.等级=="优", 明细.数量) | 符合条件的数量总和 |
| **COUNTIF** | 统计符合条件的记录数 | COUNTIF(明细.控件自身, 明细.等级=="优") | 符合条件的记录数量 |
| **AVERAGE** | 求平均值 | AVERAGE(明细.数量) | 所有数量的平均值 |

**记忆方法**：
- SUM = 全部求和
- SUMIF = 条件求和（IF = 如果）
- COUNTIF = 条件计数
