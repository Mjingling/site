# 「「云之家」」计算公式之 TEXTDEPT 函数

## 一、函数作用

`TEXTDEPT` 函数用来**从部门控件数据中提取文本信息**，支持：
- 提取部门名称
- 提取部门ID
- 自动处理部门数据的多种格式

常用于在公式中获取部门控件的显示值或ID值。

---

## 二、语法格式


TEXTDEPT(部门数组, 属性名)


### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 部门数组 | 部门控件的数据（数组格式） | ✅ 必填 | 所属部门控件 |
| 属性名 | 要提取的属性，支持 "name" 或 "id" | ✅ 必填 | "name"、"id" |

### 返回值

- **正常情况**：返回部门的名称或ID
- **特殊情况**：
  - 如果参数为空，返回空字符串
  - 如果属性名为空，返回空字符串
  - 如果部门数组为空，返回空字符串

---

## 三、实用示例

### 示例 1：获取部门名称

TEXTDEPT(所属部门, 'name')
返回：'技术部'

### 示例 2：获取部门ID

TEXTDEPT(所属部门, 'id')
返回：'001'

### 示例 3：处理空值情况

TEXTDEPT()
返回：''（无参数）

TEXTDEPT(null, 'name')
返回：''（部门为空）

TEXTDEPT(所属部门, null)
返回：''（属性名为空）

TEXTDEPT([], 'name')
返回：''（空数组）

## 四、实际业务场景

### 场景 1：在文本中显示部门名称


"申请人所在部门：" + TEXTDEPT(所属部门, 'name')


### 场景 2：作为条件判断


IF(TEXTDEPT(所属部门, 'name') == '技术部', "技术开发", "其他部门")


### 场景 3：部门数据传递

将部门ID和名称传递给其他系统

TEXTDEPT(所属部门, 'id')
TEXTDEPT(所属部门, 'name')

### 场景 4：部门名称截取

如果部门有层级结构，可能只显示最后一级

TEXTDEPT(所属部门, 'name')
返回：'技术部'（最后一级）

## 五、常见问题

### ❓ 如果部门控件选择了多个部门怎么办？

函数只返回第一个部门的名称或ID。


TEXTDEPT(所属部门, 'name')   // 返回：'技术部'（只取第一个）


### ❓ 为什么有时候取不到值？

可能的原因：
1. 部门控件没有选择值
2. 属性名填写错误（必须是 "name" 或 "id"）
3. 部门数据格式异常


TEXTDEPT(所属部门, 'name')   // ✅
TEXTDEPT(所属部门, 'title')  // ❌ 错误的属性名


### ❓ 能否获取部门的完整路径？

可以，部门数据中包含 `longName` 字段，但需要直接访问数据：


GET_PROPERTY(所属部门, 'longName')


### ❓ TEXTDEPT 和 GET_PROPERTY 有什么区别？

- `TEXTDEPT` 专门处理部门控件数据，自动标准化数据格式
- `GET_PROPERTY` 是通用函数，适用于任何对象/数组


TEXTDEPT(所属部门, 'name')
GET_PROPERTY(所属部门, 'name')

## 六、搭配使用技巧

### 技巧 1：结合 IF 函数进行部门判断


IF(TEXTDEPT(所属部门, 'name') == '财务部', 
    SUM(报销金额), 
    0)


### 技巧 2：拼接部门信息


"部门：" + TEXTDEPT(所属部门, 'name') + 
"（ID：" + TEXTDEPT(所属部门, 'id') + "）"


### 技巧 3：与其他控件联动


IF(TEXTDEPT(所属部门, 'name') == '技术部',
    TEXTUSER(技术总监, 'name'),
    TEXTUSER(部门经理, 'name'))


---

## 七、注意事项

1. **单值返回**：只返回第一个部门的信息，不支持多部门
2. **属性名限制**：只支持 "name" 和 "id" 两个属性
3. **数据格式**：部门控件存储的是数组，即使只选择了一个部门
4. **容错处理**：各种异常情况都返回空字符串，不会报错
