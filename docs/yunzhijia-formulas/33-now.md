# 「「云之家」」计算公式之 NOW 函数

## 一、函数作用

`NOW` 函数用来**获取当前的日期和时间**,简单来说就是:
- 返回当前系统的完整时间(包括日期和时间)
- 包含年、月、日、时、分、秒信息
- 每次调用都会返回调用时刻的最新时间

常用于记录操作时间、计算时间差、生成时间戳等场景。

---

## 二、语法格式

```
NOW()
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 无 | 此函数不需要任何参数 | - | NOW() |

### 返回值

- **正常情况**:返回当前系统时间(格式通常为 `YYYY-MM-DD HH:mm:ss`)
- **特殊情况**:返回调用时刻的实时时间,每次调用结果不同

---

## 三、实用示例

### 示例 1:基本用法

```js
NOW()  // 返回:2023-10-15 14:30:25(示例时间)
```

**注意**:每次调用返回的时间都是当前时刻,所以结果会不断变化。

### 示例 2:记录提交时间

假设有【任务提交表】,需要记录提交时间:

```js
// 【提交时间】字段的默认值公式
NOW()
```

### 示例 3:计算距离当前时间的天数

结合 DAYS 函数计算过去了多少天:

```js
// 计算订单创建至今的天数
DAYS(NOW(), 订单创建时间)
```

### 示例 4:判断是否超时

结合 IF 函数判断任务是否超时:

```js
// 判断任务是否在截止时间前完成
IF(NOW() > 截止时间, "已超时", "进行中")
```

## 四、实际业务场景

### 场景 1:自动记录创建时间

在表单提交时自动记录创建时间:

```js
// 【记录创建时间】字段的默认值
NOW()
```

**说明**:当用户提交表单时,系统自动填入当前时间,无需手动输入。

### 场景 2:计算时效性

计算文档距今的时长:

```js
// 【发布至今天数】的计算公式
DAYS(NOW(), 发布时间)
```

### 场景 3:任务逾期提醒

判断任务是否逾期并提醒:

```js
// 【任务状态】的计算公式
IF(NOW() > 截止时间, "逾期",
   IF(DAYS(截止时间, NOW()) <= 3, "即将到期", "正常"))
```

### 场景 4:计算工作时长

计算员工从开始工作到现在的时长:

```js
// 【工作时长(小时)】的计算公式
(NOW() - 开始工作时间) / (1000 * 60 * 60)
```

## 五、常见问题

### ❓ NOW 和 TODAY 有什么区别?

主要区别在于是否包含时间部分:

```js
NOW()    // 返回:2023-10-15 14:30:25(包含时间)
TODAY()  // 返回:2023-10-15 00:00:00(不含具体时间)
```

**使用场景:**
- **NOW**:需要精确到时分秒的场景(如记录提交时间、计算时长)
- **TODAY**:只需要日期的场景(如计算天数、判断日期)

### ❓ 每次调用 NOW 都会变化吗?

是的!NOW 函数返回的是调用时刻的实时时间。

```js
// 第一次调用
NOW()  // 返回:2023-10-15 14:30:25

// 几秒后再次调用
NOW()  // 返回:2023-10-15 14:30:30(时间已变化)
```

**注意**:如果需要固定的时间值,应该使用日期时间控件而不是 NOW 函数。

### ❓ NOW 返回的时间格式是什么?

通常返回标准格式 `YYYY-MM-DD HH:mm:ss`,例如:

```js
NOW()  // 返回:2023-10-15 14:30:25
```

如需自定义格式,可以使用 DATEFORMAT 函数:

```js
DATEFORMAT(NOW(), "YYYY年MM月DD日 HH:mm")
// 返回:2023年10月15日 14:30
```

### ❓ 如何计算两个时间的差值?

使用 DAYS 函数计算天数差:

```js
// 计算从过去某时刻到现在的天数
DAYS(NOW(), "2023-10-01 10:00:00")  // 返回:14(天)

// 计算从现在到未来某时刻的天数
DAYS("2023-10-20 18:00:00", NOW())  // 返回:5(天)
```

### ❓ NOW 会受时区影响吗?

会!NOW 函数返回的是服务器所在时区的时间。

- 如果服务器在中国,返回北京时间(UTC+8)
- 如果服务器在美国,返回相应时区的时间

## 六、搭配使用技巧

### 技巧 1:结合 DATEFORMAT 格式化时间

```js
// 显示友好的时间格式
DATEFORMAT(NOW(), "YYYY年MM月DD日 HH:mm:ss")
// 返回:2023年10月15日 14:30:25

// 显示简短格式
DATEFORMAT(NOW(), "MM/DD HH:mm")
// 返回:10/15 14:30
```

### 技巧 2:结合 IF 判断时间范围

```js
// 判断当前是否在工作时间(9:00-18:00)
IF(HOUR(NOW()) >= 9 && HOUR(NOW()) < 18, "工作时间", "非工作时间")

// 判断是否为工作日
IF(WEEKDAY(NOW()) >= 1 && WEEKDAY(NOW()) <= 5, "工作日", "周末")
```

### 技巧 3:结合 DAYS 计算剩余天数

```js
// 计算距离截止日期还有多少天
DAYS(截止日期, NOW())

// 带提示的剩余天数
CONCATENATE("还剩 ", DAYS(截止日期, NOW()), " 天")
// 返回:"还剩 5 天"
```

### 技巧 4:结合 ADDDAY 计算未来时间

```js
// 计算7天后的时间
ADDDAY(NOW(), 7)

// 计算30天前的时间
ADDDAY(NOW(), -30)
```

### 技巧 5:生成时间戳标识

```js
// 生成唯一编号:时间戳+序号
CONCATENATE(DATEFORMAT(NOW(), "YYYYMMDDHHmmss"), "-", 序号)
// 返回:"20231015143025-001"
```

## 七、相关函数对比

| 函数 | 作用 | 返回值示例 |
|------|------|-----------|
| **NOW()** | 获取当前日期和时间 | 2023-10-15 14:30:25 |
| **TODAY()** | 获取当前日期(不含时间) | 2023-10-15 00:00:00 |
| **DATEFORMAT(NOW(), 格式)** | 格式化当前时间 | 2023年10月15日 |
| **YEAR(NOW())** | 获取当前年份 | 2023 |
| **MONTH(NOW())** | 获取当前月份 | 10 |
| **DAY(NOW())** | 获取当前日期(几号) | 15 |
| **HOUR(NOW())** | 获取当前小时 | 14 |
| **MINUTE(NOW())** | 获取当前分钟 | 30 |

**详细对比:**

```js
// 当前时间:2023-10-15 14:30:25

NOW()                           // 返回:2023-10-15 14:30:25
TODAY()                         // 返回:2023-10-15 00:00:00
YEAR(NOW())                     // 返回:2023
MONTH(NOW())                    // 返回:10
DAY(NOW())                      // 返回:15
HOUR(NOW())                     // 返回:14
MINUTE(NOW())                   // 返回:30
DATEFORMAT(NOW(), "YYYY-MM-DD") // 返回:2023-10-15
```

## 八、注意事项

### ⚠️ NOW 返回值会实时变化

每次调用都返回调用时刻的时间:

```js
// ❌ 错误理解:认为 NOW() 会返回固定值
创建时间 = NOW()  // 每次计算都会更新

// ✅ 正确做法:使用日期时间控件存储固定时间
// 在【创建时间】控件的默认值中设置 NOW()
// 提交后该值就固定了
```

### ⚠️ 与日期控件的区别

```js
// ✅ NOW() - 公式字段
// 每次打开表单都会显示当前时间,值会变化

// ✅ 日期时间控件 - 固定值
// 一旦填写或设置默认值,就不会自动变化
```

### ⚠️ 时区问题

不同地区的服务器返回的时间可能不同:

```js
// 中国服务器(UTC+8)
NOW()  // 返回:2023-10-15 14:30:25

// 美国服务器(UTC-5)
NOW()  // 返回:2023-10-15 01:30:25
```

### ⚠️ 性能考虑

如果大量使用 NOW 函数,可能影响性能:

```js
// ❌ 不推荐:在列表中大量使用
// 每条记录都实时计算,性能开销大

// ✅ 推荐:在关键位置使用
// 如表单提交时记录时间,使用日期控件存储
```
