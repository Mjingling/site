# 「「云之家」」计算公式之 ROUNDUP 函数

## 一、函数作用

`ROUNDUP` 函数用来**向上取整（进位）**，简单来说就是：
- 将数字按照指定的小数位数向上取整
- 无论小数部分是多少，都向上进位
- 常用于需要确保不低于某个值的场景，如材料用量、人数统计等

比如：将 3.01 保留1位小数得到 3.1，将 3.00001 保留1位小数得到 3.1。

---

## 二、语法格式

```
ROUNDUP(数字, 保留位数)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 数字 | 要向上取整的数字，可以是数字控件、金额控件、运算控件 | ✅ 必填 | ROUNDUP(3.01, 1) |
| 保留位数 | 要保留的小数位数，可以是0或正整数 | ⭕ 选填，默认为0 | 1 表示保留1位小数 |

### 返回值

- **正常情况**：返回向上取整后的数字
- **特殊情况**：如果参数不是数字，返回 **null**

---

## 三、实用示例

### 示例 1：基本用法

```js
ROUNDUP(3.01, 1)     // 返回：3.1
ROUNDUP(3.0001, 1)   // 返回：3.1
ROUNDUP(3.14159, 3)  // 返回：3.142
ROUNDUP(2.1, 0)      // 返回：3（向上取整到个位）
ROUNDUP(-3.14, 1)    // 返回：-3.2（远离零方向进位）
```

### 示例 2：材料用量计算

假设每件产品需要 1.2 米布料，制作 5 件产品：

```js
// 【布料用量】（米）
ROUNDUP(1.2 * 5, 1)  // 返回：6.0
```

实际需要 6.0 米布料（因为不能买半米布）

### 示例 3：人员分组

假设有 23 个人，每组最多 5 人：

```js
// 【需要分组数】
ROUNDUP(23 / 5, 0)  // 返回：5
```

需要分成 5 组（23÷5=4.6，向上取整为5）

### 示例 4：包装箱数量

假设每箱装 12 件产品，共有 50 件产品：

```js
// 【需要箱数】
ROUNDUP(50 / 12, 0)  // 返回：5
```

需要 5 个箱子（50÷12=4.17，向上取整为5）

### 示例 5：价格向上取整

```js
// 【零售价】向上取整到角（保留1位小数）
ROUNDUP(进货价 * 1.2, 1)
```

假设进货价 8.33 元，加价20%：
```js
ROUNDUP(8.33 * 1.2, 1)  // 返回：10.0
```

### 示例 6：不同精度的向上取整

```js
ROUNDUP(3.14159, 1)  // 返回：3.2
ROUNDUP(3.14159, 2)  // 返回：3.15
ROUNDUP(3.14159, 3)  // 返回：3.142
ROUNDUP(3.14159, 0)  // 返回：4
```

## 四、实际业务场景

### 场景 1：采购数量计算

在采购管理中，计算需要采购的材料数量：

```js
// 【采购数量】（向上取整，确保材料充足）
ROUNDUP(实际需求量 * 损耗率, 0)

// 【采购批次】（按整箱采购）
ROUNDUP(需求数量 / 每箱数量, 0)
```

### 场景 2：运费计算

按重量计算运费时，不足1公斤按1公斤计算：

```js
// 【计费重量】（公斤）
ROUNDUP(实际重量, 0)

// 【运费】
ROUNDUP(实际重量, 0) * 每公斤单价
```

### 场景 3：人员排班

计算需要的值班人数：

```js
// 【所需班次】
ROUNDUP(总工作时长 / 每班工作时长, 0)

// 【所需人数】
ROUNDUP(总任务数 / 每人处理数, 0)
```

### 场景 4：库存预警

设置库存安全线时，向上取整确保充足：

```js
// 【安全库存】（向上取整）
ROUNDUP(平均日销量 * 安全天数, 0)
```

## 五、常见问题

### 如果参数为空会怎样？

返回 **null**。

```js
ROUNDUP("", 1)      // 返回：null
ROUNDUP(空控件, 1)  // 返回：null
```

### 对负数向上取整会怎样？

负数向上取整是远离零方向取整（即绝对值变大）：

```js
ROUNDUP(-3.14159, 3)  // 返回：-3.142（不是-3.141）
ROUNDUP(-3.14, 1)     // 返回：-3.2（不是-3.1）
```

### 保留位数可以省略吗？

可以，默认为0（取整到个位）：

```js
ROUNDUP(3.14)    // 返回：4
ROUNDUP(3.01)    // 返回：4
ROUNDUP(-1.5)    // 返回：-2
```

### ROUNDUP 和 ROUND 的区别是什么？

| 函数 | 规则 | 3.14保留1位 | 3.01保留1位 |
|------|------|------------|------------|
| **ROUND** | 四舍五入 | 3.1 | 3.0 |
| **ROUNDUP** | 向上取整 | 3.2 | 3.1 |

```js
ROUND(3.01, 1)    // 返回：3.0（四舍五入）
ROUNDUP(3.01, 1)  // 返回：3.1（向上取整）
```

## 六、搭配使用技巧

### 技巧 1：计算最小包装数

```js
// 按整盒采购，每盒10个
ROUNDUP(需求数量 / 10, 0) * 10
```

假设需要 23 个，每盒10个：
```js
ROUNDUP(23 / 10, 0) * 10  // 返回：30（需要买3盒）
```

### 技巧 2：计算页数

```js
// 每页显示20条记录，总共有123条
ROUNDUP(123 / 20, 0)  // 返回：7页
```

### 技巧 3：分摊金额（确保不少收）

```js
// 100元分3份，向上取整确保总额不少
ROUNDUP(100 / 3, 2)  // 返回：33.34
```

### 技巧 4：结合 IF 判断

```js
// 金额超过100时向上取整到十位，否则保留2位小数
IF(金额 > 100, ROUNDUP(金额, 0), ROUNDUP(金额, 2))
```

## 七、相关函数对比

| 函数 | 作用 | 示例 | 结果 |
|------|------|------|------|
| **ROUND** | 四舍五入 | ROUND(3.14, 1) | 3.1 |
| **ROUNDUP** | 向上取整 | ROUNDUP(3.01, 1) | 3.1 |
| **ROUNDDOWN** | 向下取整 | ROUNDDOWN(3.99, 1) | 3.9 |

**详细对比**：

以 3.14159 保留2位小数为例：

```js
ROUND(3.14159, 2)      // 返回：3.14（四舍五入）
ROUNDUP(3.14159, 2)    // 返回：3.15（向上取整）
ROUNDDOWN(3.14159, 2)  // 返回：3.14（向下取整）
```

以 3.15 保留1位小数为例：

```js
ROUND(3.15, 1)      // 返回：3.2（四舍五入）
ROUNDUP(3.15, 1)    // 返回：3.2（向上取整）
ROUNDUP(3.11, 1)    // 返回：3.2（向上取整）
ROUNDDOWN(3.19, 1)  // 返回：3.1（向下取整）
```

**记忆方法**：
- ROUND = 四舍五入（看下一位是否≥5）
- ROUNDUP = 向上（UP，宁可多不少）
- ROUNDDOWN = 向下（DOWN，宁可少不多）

**使用场景建议**：
- **采购、包装**：用 ROUNDUP（确保数量充足）
- **价格优惠**：用 ROUNDDOWN（对客户有利）
- **一般计算**：用 ROUND（公平合理）
