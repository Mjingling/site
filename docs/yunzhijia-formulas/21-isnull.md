# 「「云之家」」计算公式之 ISNULL 函数

## 一、函数作用

`ISNULL` 函数用来**判断一个值是否为空**,简单来说就是:
- 检查字段或表达式是否没有填写内容
- 返回布尔值:空值返回 true,有值返回 false
- 空值包括:null、undefined、空字符串("")

常用于数据验证、条件判断、默认值处理等场景。

---

## ⚠️ 使用限制

- **0 和 false 不是空值**：`ISNULL(0)` 返回 false
- **空格字符串 `" "` 不算空**：`ISNULL("   ")` 返回 false，需配合 TRIM 使用
- **不适用于开关控件（Sw_）**：开关控件天生非空（总是 true/false），使用 ISNULL 没有意义

---

## 二、语法格式

```
ISNULL(值)
```

### 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|------|------|----------|------|
| 值 | 要判断是否为空的值,可以是字段、文本、数字等任意类型 | ✅ 必填 | ISNULL(姓名) |

### 返回值

- **正常情况**:如果值为空返回 true,有值返回 false
- **特殊情况**:数字 0、布尔值 false 不被视为空值,返回 false

---

## 三、实用示例

### 示例 1:基本用法

```js
ISNULL("")          // 返回:true(空字符串)
ISNULL(null)        // 返回:true(null值)
ISNULL("你好")      // 返回:false(有内容)
ISNULL(0)           // 返回:false(数字0不是空)
ISNULL(false)       // 返回:false(布尔值不是空)
```

### 示例 2:检查字段是否填写

假设有【客户信息表】,检查电话是否填写:

```js
ISNULL(电话号码)
```

### 示例 3:结合 IF 提供默认值

当字段为空时显示默认值:

```js
IF(ISNULL(备注), "无备注", 备注)
```

### 示例 4:判断必填字段

检查多个字段是否都已填写:

```js
IF(ISNULL(姓名) || ISNULL(电话), "信息不完整", "信息完整")
```

### 示例 5:数据清洗

统计空值数量:

```js
IF(ISNULL(地址), 1, 0)
```

然后使用 SUM 函数统计所有记录中地址为空的数量。

## 四、实际业务场景

### 场景 1:客户信息完整度检查

检查客户资料是否填写完整:

```js
// 【资料完整度】的计算公式
IF(ISNULL(公司名称) || ISNULL(联系人) || ISNULL(电话) || ISNULL(地址),
   "资料不完整", "资料完整")
```

### 场景 2:审批意见默认提示

当审批意见为空时显示提示信息:

```js
// 【审批意见显示】的计算公式
IF(ISNULL(审批意见), "(审批人未填写意见)", 审批意见)
```

### 场景 3:销售业绩提醒

检查销售人员是否有业绩数据:

```js
// 【业绩状态】的计算公式
IF(ISNULL(本月销售额), "本月暂无业绩",
   IF(本月销售额 >= 目标金额, "已达标", "未达标"))
```

### 场景 4:库存预警

检查库存数量是否已录入:

```js
// 【库存状态】的计算公式
IF(ISNULL(库存数量), "未录入库存",
   IF(库存数量 < 安全库存, "库存不足", "库存正常"))
```

## 五、常见问题

### ❓ 数字 0 会被判断为空吗?

不会!数字 0 是一个有效的数值,不是空值:

```js
ISNULL(0)      // 返回:false(0不是空)
ISNULL("")     // 返回:true(空字符串才是空)
```

**实际应用:**

| 库存数量 | ISNULL(库存数量) | 说明 |
|---------|----------------|------|
| 0 | false | 库存为0,但已录入数据 |
| (空) | true | 未录入库存数据 |

### ❓ 空格字符串算不算空?

纯空格的字符串不算空值:

```js
ISNULL("   ")   // 返回:false(有空格内容)
ISNULL("")      // 返回:true(完全为空)
```

如果要把空格也判断为空,需要结合 TRIM 函数:

```js
ISNULL(TRIM(字段))  // 先去除空格再判断
```

### ❓ 如何判断多个字段都不为空?

使用逻辑与运算符 &&:

```js
// 所有字段都不为空
!ISNULL(姓名) && !ISNULL(电话) && !ISNULL(地址)

// 或者使用 IF 嵌套
IF(ISNULL(姓名), false,
   IF(ISNULL(电话), false,
      IF(ISNULL(地址), false, true)))
```

### ❓ 如何判断至少有一个字段为空?

使用逻辑或运算符 ||:

```js
// 至少有一个字段为空
ISNULL(姓名) || ISNULL(电话) || ISNULL(地址)
```

### ❓ ISNULL 和直接判断有什么区别?

ISNULL 更安全,能处理多种空值情况:

```js
// ❌ 直接判断可能有问题
字段 == ""          // 只能判断空字符串

// ✅ 使用 ISNULL 更全面
ISNULL(字段)       // 能判断 null、undefined、空字符串
```

## 六、搭配使用技巧

### 技巧 1:结合 IF 设置默认值

```js
// 为空时使用默认值
IF(ISNULL(折扣率), 0, 折扣率)

// 示例:计算实际价格
单价 * (1 - IF(ISNULL(折扣率), 0, 折扣率))
```

### 技巧 2:结合 CONCATENATE 组合非空内容

```js
// 只显示有内容的字段
CONCATENATE(
  IF(ISNULL(省), "", 省),
  IF(ISNULL(市), "", 市),
  IF(ISNULL(区), "", 区),
  详细地址
)
```

### 技巧 3:结合 CASE 多条件判断

```js
CASE(
  ISNULL(状态), "未开始",
  状态 == "进行中", "执行中",
  状态 == "完成", "已完成",
  "未知状态"
)
```

### 技巧 4:数据完整度评分

```js
// 统计已填写字段数量
(IF(ISNULL(字段1), 0, 1) +
 IF(ISNULL(字段2), 0, 1) +
 IF(ISNULL(字段3), 0, 1) +
 IF(ISNULL(字段4), 0, 1)) / 4 * 100

// 返回完整度百分比
```

### 技巧 5:必填项验证提示

```js
// 生成友好的提示信息
CONCATENATE(
  "请检查以下信息:",
  IF(ISNULL(姓名), " [姓名]", ""),
  IF(ISNULL(电话), " [电话]", ""),
  IF(ISNULL(地址), " [地址]", "")
)
```

## 七、相关函数对比

| 函数 | 作用 | 返回值 | 使用场景 |
|------|------|--------|---------|
| **ISNULL(值)** | 判断是否为空 | true/false | 检查字段是否填写 |
| **NOT_NULL(值)** | 判断是否不为空 | true/false | 检查字段已填写 |
| **IF(条件, 值1, 值2)** | 条件判断 | 值1或值2 | 根据条件返回不同值 |
| **TRIM(文本)** | 去除首尾空格 | 处理后的文本 | 清理文本前后空格 |
| **LEN(文本)** | 获取文本长度 | 数字 | 检查文本是否有内容 |

**详细对比:**

```js
// 假设字段值为空字符串 ""

ISNULL("")              // 返回:true(判断为空)
NOT_NULL("")            // 返回:false(判断为不为空,即为空)
LEN("")                 // 返回:0(长度为0)
TRIM("")                // 返回:""(去除空格后仍为空)
IF(ISNULL(""), "空", "非空")  // 返回:"空"

// 假设字段值为 "  "(纯空格)

ISNULL("  ")            // 返回:false(有内容,虽然是空格)
LEN("  ")               // 返回:2(长度为2)
TRIM("  ")              // 返回:""(去除空格后为空)
ISNULL(TRIM("  "))      // 返回:true(去除空格后为空)
```

## 八、注意事项

### ⚠️ 数字 0 不是空值

不要把数字 0 当作空值:

```js
ISNULL(0)       // 返回:false

// ❌ 错误用法
IF(ISNULL(数量), "未填写", "已填写")
// 当数量为0时,会显示"已填写",这可能不是你想要的

// ✅ 正确做法
IF(ISNULL(数量) || 数量 == 0, "未填写或为0", "有数量")
```

### ⚠️ 空格字符串不算空

纯空格的内容不被判断为空:

```js
ISNULL("   ")   // 返回:false

// ✅ 如需判断空格为空,使用 TRIM
ISNULL(TRIM(备注))  // 先去除空格再判断
```

### ⚠️ 与 NOT_NULL 的关系

ISNULL 和 NOT_NULL 是相反的:

```js
ISNULL(值)       // 为空返回true
NOT_NULL(值)     // 不为空返回true

// 以下两种写法等价
!ISNULL(值) == NOT_NULL(值)
```

### ⚠️ 批量判断时注意短路逻辑

使用 || 判断多个字段时,只要有一个为空就返回 true:

```js
// 只要有一个字段为空就提示
IF(ISNULL(字段1) || ISNULL(字段2) || ISNULL(字段3),
   "有字段未填写", "全部已填写")

// 所有字段都不为空才通过
IF(!ISNULL(字段1) && !ISNULL(字段2) && !ISNULL(字段3),
   "全部已填写", "有字段未填写")
```
